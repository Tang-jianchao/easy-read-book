# 速查表 Cheatsheet

> 遇到情境，先查动作；少讲定义，多做判断。

## 情境 → 动作

| 情境 | 动作 | 依据 |
|---|---|---|
| 觉得“没时间了” | 不问怎么挤时间，问“我现在能控制哪个行为” | 时间不可管理 (ch00) |
| 想找速成/捷径 | 先算阶段与学习时间，按侯世达法则加时 | 速成不可能 (ch02/03) |
| 任务估不准 | 先判熟悉/陌生；陌生任务按“比想象长得多”估 | 侯世达法则 (ch03) |
| 迟迟不开始 | 现在开始；允许“到时候能做多好就做多好” | 及时行动 (ch03) |
| 很忙却没成果 | 检查是否只做简单部分，困难部分有没有推进 | 直面困难 (ch03) |
| 计划坚持不了 | 缩到一周；任务极简单或尚无能力时，干脆不做计划 | 计划能力 (ch03) |
| 列表总想改 | 新主意写进“下一阶段任务列表”，不中途改当前列表 | 列表系统 (ch03) |
| 重复任务总出错 | 完整做一次→总结流程→加核对列表 | 流程化 (ch03) |
| 待办太多 | 只保留一个“真的重要”的任务，其余降级 | 真重要/显得重要 (ch03) |
| 学习卡住 | 记下未知，继续前行；用后续知识回头解释 | 未知永远存在 (ch02) |
| 看到相关就想下因果 | 过三问：是不是理由、唯一理由、最重要理由 | 因果三层 (ch05) |
| 对方要你“证明他错” | 谁主张谁举证；不能证伪≠成立 | 举证责任 (ch05) |
| 听到成功经验 | 先分“感悟”还是“道理”；找可复制条件 | 感悟/道理 (ch05) |
| 讨论变争吵 | 对照三条原则；对方不守则立即停止 | 讨论原则 (ch06) |
| 不确定是否听懂 | 复述：“你的意思是……，我理解得对吗？” | 正确复述 (ch06) |
| 经验与事实冲突 | 把经验当假设，用记录/观察/阅读/类比校验 | 经验局限 (ch04/06) |

## 默认值与阈值

| 项目 | 默认值 |
|---|---|
| 每日时间预算 | 15–30 分钟 |
| 专注时间片 | 20 分钟工作 + 5 分钟休息 |
| 计划起点 | 1 周；能坚持后再延长 |
| 任务权重 | 1–3 分，或只分“重要/不重要” |
| 重要任务准备量 | 实际所需的 2 倍以上 |
| 专业技能周期 | 约 10 年 / 10000 小时（作者引述） |
| 因果检查 | 3 问 |
| 讨论原则 | 3 条 |
| 验收标准 | 动手前写下，完成后逐条对照 |

## 判断树：总觉得时间不够

1. **任务是熟悉还是陌生？**
   - 陌生 → 加入“从陌生到熟悉”的学习时间，按侯世达法则加码。
   - 熟悉 → 进入下一步。
2. **困难部分有没有被推进？**
   - 没有 → 你可能在用简单任务逃避；先做困难部分。
   - 有 → 进入下一步。
3. **有没有记录真实开销？**
   - 没有 → 先做一周事件-时间日志，再谈预算。
   - 有 → 用预算重排：只留一个真正重要的任务。
4. **计划是否超过一周？**
   - 是 → 缩短；长期计划能力要靠实践习得。
   - 否 → 检查验收标准是否写下。

## 信号（Tells）

| 看到 | 大概率 |
|---|---|
| 忙到没时间，却拿不出成果 | 回避困难，用忙碌自欺 |
| 总在找“更好的方法” | 用寻找替代练习 |
| 清单长达几页 | 目标过高、不会取舍 |
| 讨论开始人身攻击 | 已不是讨论，立即停止 |
| “每个人都该有自己的看法” | 关闭对话的挡箭牌 |
| “难道没有一点可取之处吗？” | 用“可取之处”回避判断 |
| “要是……就好了！” | 后悔，最浪费时间 |
| 只记结果、不记过程 | 无法定位时间漏点 |

## 一句话

时间不可管理，管理自己；记录 → 预算 → 拆解 → 执行 → 验收；接受现实、持续积累、独立思考、有效倾听。
