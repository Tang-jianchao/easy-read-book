# 术语表 Glossary

> 《把时间当作朋友》（李笑来），按拼音排序，标注章节。

- **并行/串行** — 两个任务可同时推进为并行，必须按先后顺序为串行；只有主动可控的并行才提高效率。(ch03)
- **道理/感悟** — 道理应普适，感悟只来自个体经验；二者混淆会误己误人。(ch05)
- **独立思考** — 得到结论后自己重走推理，检查前提、漏洞与适用范围。(ch05)
- **复利** — 长期持续投入产生的指数效应；早期差距小，时间越久越由积累拉开。(ch07)
- **复述** — 听完后用自己的话复述并请对方确认，以校验解码是否正确。(ch06)
- **概念不清** — 概念边界模糊，把不同事物混为一谈；思维陷阱的两大根源之一。(ch05)
- **共生状态** — 分不清自己与外界、他人或观点的边界；婴儿早期状态，成年人也可能退回。(ch06)
- **侯世达法则** — 完成任务的真实时间总会超过计划，即使计划时已考虑该法则。(ch03)
- **积累** — 一切成长唯一的通路；时间只对接受现实、持续积累的人友好。(ch00)
- **计划** — 从现实可行的目标倒推步骤；长期计划能力靠实践习得，宜从一周计划开始。(ch03)
- **记录开销** — 逐日记录时间实际花在哪里，是感知时间、校准估算的第一步。(ch03)
- **经验主义** — 把个体或群体的有限经验当作普遍规律；学习与沟通的最大障碍。(ch04)
- **举证责任** — 谁主张谁举证；不能因对方无法证否就认定主张成立。(ch05)
- **恐惧** — 阻碍行动与思考的底层情绪；勇气减去恐惧才是“强”的分值，恐惧永远大于零。(ch05)
- **类比** — 用已知经验跨越未知的主要手段；当新知识与旧经验相悖时会失效。(ch04)
- **理性讨论基本原则** — 无证据不判断、有证据就接受、错了就改、对事不对人、谁有道理听谁的。(ch06)
- **灵感** — 长期积累后的产物，不是等来的；持续输入与练习才会出现。(ch07)
- **列表** — 把任务外化到纸面的组织工具；纸笔优先、随手可及、不必工整。(ch03)
- **流程** — 重复性任务完整做一次后总结出的固定步骤，用于提速与减少失误。(ch03)
- **滤网** — 由判定类知识构成的筛选机制，决定信息进入理解的质量。(ch06)
- **模式拼接** — 大脑用旧模式补全零散信息，产生“我懂了”的幻觉。(ch06)
- **逆命题** — 把“若 p 则 q”倒成“若 q 则 p”；原命题真，逆命题不一定真。(ch05)
- **平台期** — 学习曲线中长时间进展缓慢的阶段；是积累期，不是失败。(ch04)
- **倾听** — 主动获取信息的过程；有效交流往往更取决于听者。(ch06)
- **人脉** — 建立在自身可交换价值上；先成为能提供价值的人，而不是经营关系。(ch07)
- **任务拆解** — 按 What/Why/How 不断细分，直到每个小任务可由一个人独立完成。(ch03)
- **三思而行** — 做事前考虑内容（What）、原因（Why）、方法（How），其中方法最关键。(ch03)
- **时间不可管理** — 时间自顾自流逝；可管理的只有自己的行为、注意力与选择。(ch00)
- **时间片** — 把长时段切成短工作块逐块推进，如“20 分钟工作 + 5 分钟休息”。(ch03)
- **时间预算** — 一天开始前用 15–30 分钟列任务、估时、标权重，并留出意外与休息。(ch03)
- **事件-时间日志** — 在事件后记录耗时，做基于过程的记录，而非只记结果。(ch03)
- **双盲测试** — 被试与发药者都不知分组，以排除安慰剂效应。(ch05)
- **速成** — 不劳而获、少劳多获、马上看到结果的欲望；现实中不存在。(ch02)
- **体验/试错/观察/阅读** — 获取知识的四级阶梯；阅读能突破个体与群体的经验局限。(ch04)
- **痛苦** — 会扭曲对其他事物的感知，让人把自己想象成最痛苦的人；先处理情绪再判断。(ch07)
- **完美主义** — 常与脆弱同现；能力越差越容易不现实地追求完美，并把它当作不做的借口。(ch02)
- **未知** — 永远存在；分“永远不能解决”和“可预见未来也许能解决”两类，后者应记录后带着走。(ch02)
- **物极必反** — 过度投入、过度用力会反噬；长期投入需要可持续的节奏。(ch07)
- **稀缺** — 资源有限且分布不均；是经济学前提，也是“绝大多数人觉得不够多”的根源。(ch02)
- **现状** — 过去的结果、未来的原因；无法立刻摆脱，只能接受后逐步改变。(ch02)
- **心智** — 过往知识、经验及其思考方法的总和；可发展、可重建，也可能停滞倒退。(ch01)
- **兴趣的顺序** — 先有能力做好，才产生兴趣；把“没兴趣”当作不做的理由会陷入循环。(ch07)
- **学习曲线** — 进展与时间非线性；长期平台后可能突飞猛进，整体像进两步退一步。(ch04)
- **验收机制** — 动手前定义“怎样才算做好”，完成后逐条对照。(ch03)
- **元认知** — 把思考方式和思考结果当作思考对象的能力。(ch01)
- **运气** — 不可控因素；专注可控的积累，不把结果全部归因于运气。(ch07)
- **知识获取阶梯** — 体验→试错→观察→阅读→思考；越往后越能突破个体经验。(ch04)
- **直面困难** — 迅速做完简单部分，把时间留给困难部分；回避困难是效率低下的根本原因。(ch03)
- **自我管理** — 管理自己的行为、注意力与选择，而非管理时间。(ch00)
- **自学能力** — 阅读理解、检索、写作、实践、开放心态与反刍的组合。(ch04)
- **真重要/显得重要** — 判断任务只看是否有利于目标实现，而非是否有趣、紧急或好看。(ch03)
