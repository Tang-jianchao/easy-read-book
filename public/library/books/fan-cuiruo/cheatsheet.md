# 速查表 Cheatsheet

> 反脆弱决策指南，帮助你在不确定性中像塔勒布一样行动。以一页为限。

## 核心判断

- **面对波动** → 你是"火"还是"蜡烛"？从冲击中受益=反脆弱；被冲击熄灭=脆弱。
- **判断一个系统** → 不对称测试：得到的有利结果>不利结果=反脆弱；反之=脆弱。
- **配置资产/职业** → 杠铃：两个极端（90%保守+10%冒险），摈弃中间；先消灭毁灭性风险。
- **面对未来** → 别预测事件，识别脆弱、在下注崩溃中获利（胖子托尼模型）。
- **评估事物** → 林迪过滤器：经久者更可信，警惕新事物狂热症。
- **做决策** → 否定法：知道不该做什么>知道该做什么，用减法改善。
- **选择结构** → 凸性（下行有限、上行无限）>凹性；警惕规模带来的脆弱。
- **委托他人** → 切身利害：决策者须承担后果，警惕代理问题（收益自取、损失外化）。

## 三元结构速查

| 类别 | 隐喻 | 对冲击 | 特征 |
|---|---|---|---|
| 脆弱 | 达摩克利斯 | 受击毁灭 | 不利结果>有利结果 |
| 强韧 | 凤凰 | 保持原状 | 免疫、不受影响 |
| 反脆弱 | 九头蛇怪 | 变得更好 | 有利结果>不利结果 |

## 关键信号（Tells）

| 信号 | 判断 |
|---|---|
| 收益自取、损失外化（代理） | 脆弱转移，道德风险 |
| 过度干预/监管/保护 | 医源性损伤，压制反脆弱 |
| "中等风险"配置 | 骗人的把戏，受测量误差影响 |
| 规模庞大而复杂 | 非线性放大误差，脆弱 |
| 新事物狂热（追新） | 违背林迪效应 |
| 病重者拒绝治疗 / 健康者过度治疗 | 凸/凹错配 |
| 预测模型自认精确 | 预测者脆弱，承担更多风险 |

## 全书一句话(Bottom Line)

> 反脆弱性是从波动、混乱与压力中受益的能力，超越"保持原状"的强韧——用不对称测试识别它，用杠铃策略（两端极端、摈弃中间）配置它，用否定法与林迪效应筛选它，用可选择性让它在无知中生长；警惕现代化对系统波动性的剥夺（医源性损伤）与"置身事外不担后果"的代理脆弱转移，坚持切身利害——如此，在不可预测的黑天鹅世界里，你不仅能存活，还能变得更好。
