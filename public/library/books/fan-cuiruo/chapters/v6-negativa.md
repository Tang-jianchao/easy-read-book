# 第六卷：否定法（第20-22章）

## Core Idea
**否定法（via negativa）：知道不该做什么，比知道该做什么更重要。** 通过排除（减法）而非增加来改善事物；时间（林迪效应）是最可靠的过滤器。对医疗、技术、人生，"不做什么"常比"做什么"更反脆弱。

## Frameworks Introduced
- **林迪效应（Lindy effect）**：**旧事物的预期剩余寿命与它已存活的寿命成正比**——能活300年的东西会再活300年；经得起时间考验的技术/制度/公司更反脆弱。新事物狂热症（盲目追新）违背林迪效应。
- **否定法**：通过"不该做什么"展望未来与做决策——减少伤害（不利因素）比增加收益更有效。如"不吸烟、不负债、不做某事"的排他规则。
- **减法医疗**：医疗中的"不必要治疗"常造成医源性损伤；对病重者有凸性回报（治疗收益大），对健康人有凹性风险（过度治疗伤害大）。决策规则：病重→凸性（获益），健康→凹性（风险）。
- **恩培多克勒的瓷砖**：非理性认知（经验、传统）有时比理性认知更经得起时间（因为存活下来本身就筛过）。
- **活得长寿但不要太长**：匹配个体与环境随机性；追求"太长寿"可能违背反脆弱（过度医疗）。

## Key Concepts
- **时间是最严苛的过滤器**：能存活久的事物=通过现实检验=更反脆弱。
- **否定性知识 > 肯定性知识**：知道什么会杀死你（避免）比知道什么让你发财更可靠。
- **凸性/凹性医疗决策**：取决于你的脆弱状态——病重时治疗是凸性（值得冒险），健康时治疗是凹性（风险大于收益）。

## Mental Models
- "林迪过滤器"：旧而经久的事物比新事物更可信。
- "减法优先"：通过减少坏东西改善，而非增加好东西。
- "不做什么清单"：用否定法决策，避免致命风险。

## Anti-patterns
- 新事物狂热症：盲目追新，忽视林迪效应。
- 过度医疗/干预（健康人也被治疗→凹性伤害）。
- 追求"一定活得最长"违背自然随机性匹配。

## Worked Example
医疗决策：病得很重的人→治疗有凸性回报（可能治愈，收益大）；健康的人→不必要治疗有凹性风险（伤害>收益）。因此"减法"（少干预）对健康人更反脆弱——这也是医源性损伤的规避。

## Key Takeaways
1. 否定法：知道不该做什么>知道该做什么。
2. 林迪效应：旧事物预期寿命与已存活寿命成正比，经久者更可信。
3. 用减法（排除）改善，而非不断增加。
4. 医疗/干预视脆弱状态：病重凸性、健康凹性。
5. 时间是最可靠过滤器，别盲目追新。

## Connects To
- **V1**：反脆弱；**V2**：医源性损伤；**V5**：凸性/凹性。
