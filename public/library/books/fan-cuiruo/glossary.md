# 术语表 Glossary

> 《反脆弱》(塔勒布)，按拼音排序，标注卷。

- **反脆弱性（Antifragile）** — 能从波动、随机、混乱、压力中受益；超越强韧性（v1）
- **三元结构** — 脆弱类–强韧类–反脆弱类，好比达摩克利斯–凤凰–九头蛇怪（v1）
- **不对称性（Asymmetry）** — 有利结果>不利结果=反脆弱；反之=脆弱；塞内加"保留好剔除坏"（v1、v3）
- **杠铃策略（Barbell）** — 两个极端、摈弃中间；最大损失已知、收益无上限（v3）
- **非预测性（Non-prediction）** — 识别脆弱比预测事件容易；黑天鹅的解决方案（v1、v2）
- **医源性损伤（Iatrogenics）** — 干预造成的伤害，现代化最易被忽视的产物（v2）
- **天真的干预** — 过度干预/保护，伤害系统（v2）
- **平均斯坦 vs 极端斯坦** — 物理量 vs 社会量；极端斯坦个体影响整体（v2）
- **苏联-哈佛派谬见** — 自认为可由专家自上而下设计优化复杂系统的谬见（v2）
- **塞内加/斯多葛** — 情绪驯化（恐惧→谨慎、痛苦→信息）；"一无所失"簿记（v3）
- **可选择性（Optionality）** — 允许在无知中受益（泰勒斯）；下行有限上行无限（v4）
- **试错（Tinkering）** — 技术进步靠试错与经验积累，而非设计预测（v4）
- **绿色木材谬误** — 理论理解≠实操知识（v4）
- **凸性 / 凹性（Convex/Concave）** — 从波动中受益 vs 受波动伤害；非线性（v5）
- **规模脆弱** — 越大越因非线性放大误差而脆弱（v5）
- **炼金石 / 反炼金石** — 识别利用凸性 vs 制造脆弱（v5）
- **林迪效应（Lindy）** — 旧事物预期寿命与已存活寿命成正比；经久者更可信（v6）
- **否定法（Via negativa）** — 知道不该做什么>知道该做什么；减法优先（v6）
- **切身利害（Skin in the game）** — 决策者承担自己决策的后果（v7）
- **代理问题/脆弱性转移** — 代理人获利自取、损失外化，转嫁脆弱（v7）
- **黑天鹅（Black Swan）** — 不可预知、后果广泛的罕见事件（v1）
- **汉谟拉比法则** — 以眼还眼的对称责任原则（v7，伦理呼应）
