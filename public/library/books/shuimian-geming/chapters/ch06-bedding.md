# 第6章：改造你的床铺——寝具套装

## Core Idea
床垫要合身，不是越贵越好。用胎儿睡姿、体型和“6厘米空隙”自测软硬；把预算优先给床垫，而不是床架；用可分层、可清洗的寝具套装替代“一张用十年”的昂贵床垫。

## Frameworks Introduced
- **胎儿睡姿**：躺向非主要的身体一侧，膝盖自然弯曲，手臂放在身前轻轻交叠，颈部、脊柱、臀部成一条直线。
  - When to use：每晚入睡、测试床垫、与伴侣分床侧。
  - How：右撇子向左睡，左撇子向右睡；用较强壮的一侧保护身体；床垫应让你更容易保持这个姿势。
- **床垫自测法**：用身体而不是销售话术判断软硬。
  - When to use：买新床垫、怀疑现有床垫不合适、伴侣抱怨睡不好。
  - How：先站成“站立胎儿姿势”，再侧躺在地板上，观察头与地板之间的空隙；然后以同样姿势躺到光床垫上。头与床垫之间仍有约6厘米（双手交叠高度）空隙=太硬；臀部陷进去、头被垫高=太软；头颈脊柱成直线=合适。
- **体型三分类**：外胚层（瘦长、臀窄）、中胚层（适中、肩胸宽于臀）、内胚层（魁梧、臀宽）；伴侣体型不同时，按体型较大者选床垫。
  - When to use：选购床垫、判断“为什么同床两人感受不同”。
  - How：先判断体型，再用自测法验证；不要相信“一种床垫适合所有人”。
- **寝具套装**：多层床垫（5—8厘米层）+ 床垫套/保护罩 + 薄枕头 + 可分层羽绒被 + 低过敏、透气、速干的床品。
  - When to use：预算有限、想逐步升级、需要经常清洗、对尘螨过敏。
  - How：先买合适的基础床垫，再叠加层；每几年更换最上层，而不是十年换整张；床架可省，床垫不可省。
- **床垫与枕头的关系**：枕头是床垫的“鞋垫”，用来补偿床垫，而不是独立主角。
  - When to use：需要两个以上枕头才舒服、醒来颈肩痛。
  - How：床垫合适时，一个薄枕头即可；多个枕头往往说明床垫太硬。

## Key Concepts
- **外胚层/中胚层/内胚层体型**：三种基本体型，床垫需求不同，且存在过渡体型。
- **非主要身体一侧**：惯用右手者向左睡，惯用左手者向右睡。
- **床垫套/保护罩**：可拆卸清洗，防止汗液、皮屑与尘螨进入床垫。
- **低过敏性**：减少过敏原，帮助鼻呼吸，间接减少打鼾与睡眠呼吸暂停。
- **尘螨**：以皮屑为食，排泄物是过敏原；喜欢潮湿、旧床垫与床上用品。
- **特大号床（super king）**：约180厘米宽，是两个成年人并肩睡的最小合理尺寸；“双人床”只适合一个人。

## Mental Models
- “床垫像鞋子”：合身比价格、弹簧数量、品牌更重要。
- “枕头是床垫的鞋垫”：先修床垫，再谈枕头。
- “床架是装饰，床垫是工具”：预算100%给床垫也不过分。
- “双人床只适合一个人”：空间不足会通过翻身、抢被子、呼吸干扰偷走深睡眠。
- “分层更换比十年一换更卫生”：汗液、皮屑、尘螨不会等你用满十年。

## Anti-patterns
- **按弹簧数量或价格买床垫**：2000支弹簧不一定比50支更适合你。
- **相信“一种床垫适合所有人”**：体型与睡姿差异被忽略。
- **床垫太硬或太软**：太硬压迫肩臀，太软让脊柱弯曲。
- **用多个枕头补偿硬床垫**：越垫越偏离直线。
- **把一半预算花在床架上**：床架主要是装饰。
- **十年不换床垫**：汗液、皮屑、尘螨与老化会累积。
- **伴侣体型差异大却各买各的**：同床时按较大体型选，或分床。

## Worked Example
一对年轻夫妇把一半预算花在床架上，进店后被销售员从2000英镑一路带到1500英镑的“矫形”床垫；他们躺了几分钟，觉得“第二张不错、也够结实”，就比预算多花500英镑买下——但他们没有做任何合身测试。正确做法：先站成胎儿姿势，侧躺地板，记下头与地板之间的空隙；再以同样姿势躺到光床垫上。若头与床垫间仍有6厘米空隙，说明太硬；若臀部下陷、头被抬高，说明太软；只有头颈脊柱成直线才合格。伴侣体型不同时，按较大体型选择；床垫合适后，一个薄枕头就够。作者为天空车队做的便携寝具套装只有2—3层黏弹泡沫、可拆洗外罩、薄枕头和羽绒被，威金斯与霍伊在奥运会期间睡的就是这类定制寝具，而不是昂贵弹簧床。

## Key Takeaways
1. 先学胎儿睡姿，再用6厘米空隙法测床垫。
2. 床垫按体型与睡姿选，不按价格、弹簧数或品牌选。
3. 伴侣体型不同，按较大体型选；床越大越好，特大号是底线。
4. 预算优先给床垫，床架可以省，甚至可以只用床垫。
5. 用分层床垫、可洗保护罩、低过敏透气床品，逐步升级。
6. 枕头是补偿工具；需要多个枕头，先怀疑床垫太硬。
