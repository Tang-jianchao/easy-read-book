# 第3章：90分钟睡眠法——睡眠周期

## Core Idea
用90分钟一个的睡眠周期衡量睡眠，而不是用“每晚8小时”。固定起床时间是整个R90方案的铁锚；从起床时间倒推入睡点，以一周35个周期为目标，允许个别夜晚不足，但避免连续三晚短缺。

## Frameworks Introduced
- **R90睡眠周期**：一个周期约90分钟，由4个（有时5个）阶段组成——N1打瞌睡、N2浅睡眠、N3/N4深睡眠、REM快速眼动睡眠。
  - When to use：安排入睡时间、判断睡醒后的状态、向教练或伴侣解释睡眠。
  - How：把周期想成下楼梯（N1→N2→深睡眠）再上楼梯坐滑梯（REM）；深睡眠约20%，REM约20%，婴儿REM可达50%。
- **固定起床时间（铁锚）**：选择一个每天都能做到、且比上班或上学早至少90分钟的最早起床时间，周末也坚持。
  - When to use：每次调整作息、跨时区、轮班、伴侣同住。
  - How：回顾过去两三个月，找出“必须起床的最早时间”；设闹钟，训练到自然醒；晚睡型不要让起床时间离日出太远。
- **周周期预算**：5个周期/晚=7.5小时，一周35个；28—30个也可接受；至少4晚达到理想值；避免连续3晚不足。
  - When to use：评估一周睡眠、决定是否需要补偿、安排特殊事件。
  - How：用90分钟为单位加减；一晚不足不灾难化；看7天总量与连续短缺。
- **睡眠调度**：入睡时间可变，但必须从固定起床时间倒推。
  - When to use：加班、聚会、比赛、临时早班。
  - How：7:30起床→午夜入睡（5周期）；晚归→1:30（4周期）；再晚→3:00（3周期，太少）；上床前留出15分钟入睡时间。

## Key Concepts
- **非眼动睡眠（NREM）**：N1似睡似醒、易被惊醒；N2心率体温下降、整合信息与运动技能；N3/N4深睡眠，生长激素分泌、身体修复。
- **快速眼动睡眠（REM）**：做梦、身体暂时不能动、有益创造力；后半夜占比更高。
- **睡眠惯性**：从深睡眠被强行唤醒后的昏沉感；安排小睡和起床时要考虑。
- **睡眠压力**：清醒越久积累越强；与昼夜节律的睡眠冲动共同决定困意。
- **生长激素**：深睡眠中分泌，促进细胞生长与组织修复。
- **8小时睡眠神话**：8小时是人均值，不是人人适用的推荐值；强迫躺够会制造焦虑。

## Mental Models
- “下楼梯再坐滑梯”：睡眠不是一条平线，而是阶段循环；被吵醒等于被推回楼梯顶端。
- “固定起床，倒推入睡”：起床时间是锚，入睡时间是可调的变量。
- “按周结算，不按夜结算”：一晚没睡好不决定一切；看35个周期的总账。
- “失去的睡眠补不回来，但身体会补救”：大脑会在后续周期优先插入REM。
- “3个周期是底线，不是常态”：短期权宜可以，长期不足会亮红灯。

## Anti-patterns
- **执着于每晚8小时**：在床上焦虑计算时间，反而更难入睡。
- **半夜看钟表**：越算越清醒；不如起床做点睡前程序，赶下一个周期。
- **不困就上床**：把床变成清醒与焦虑的场所。
- **周末大睡懒觉**：破坏固定起床铁锚，制造社交时差。
- **试图靠早睡或晚起“补觉”**：失去的睡眠无法原样补回。
- **长期只睡3个周期**：短期应急可以，长期会损害健康与表现。

## Worked Example
固定起床7:30，想要5个周期，就应在午夜睡着；若需要15分钟入睡，23:45上床。某天回家已晚，无法午夜入睡，就等到1:30（4个周期）；如果更晚，3:00入睡只剩3个周期，作者认为“有点太少了”。一周目标35个周期；如果某晚只有2个周期，接下来一两晚安排完整睡眠，避免连续三晚短缺。运动员的比赛夜：比赛22:00结束，采访、肾上腺素、交通都会推迟入睡，不能强求5个周期，而是在赛后一两晚补回完整安排。

## Key Takeaways
1. 用90分钟周期计数，不数小时；5周期/晚、35周期/周是理想值。
2. 固定起床时间是第一优先级，周末也不例外。
3. 入睡时间从起床时间倒推，按90分钟加减。
4. 一晚不足不灾难化；避免连续三晚不足，争取每周4晚达标。
5. 不困不上床；半夜醒来不要在床上硬熬。
6. 深睡眠负责身体修复，REM负责记忆与创造力，两者都不可少。
