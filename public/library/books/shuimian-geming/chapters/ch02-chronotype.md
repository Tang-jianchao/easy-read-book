# 第2章：走慢与走快——睡眠类型

## Core Idea
睡眠类型（chronotype）是遗传决定的生理倾向，不是自律问题。云雀、猫头鹰与中间型最多相差约两小时；与其对抗，不如把重要工作、训练和决策放到自己状态最好的时段，并用光照与咖啡因做小幅校准。

## Frameworks Introduced
- **睡眠类型（chronotype）**：身体希望何时履行昼夜节律功能。早起型生物钟偏快，晚睡型偏慢；可用慕尼黑大学问卷判断。
  - When to use：安排一天的工作顺序、训练时间、会议与出行。
  - How：记录自然醒与困倦时间；把最费脑的工作放在个人高峰；晚睡型不要选太早的固定起床时间。
- **社交时差**：工作与社会时间要求晚睡型按早起型的节奏生活，等于每天飞到一个相邻时区。
  - When to use：晚睡型被迫早起、周末补觉后周一更难受时。
  - How：固定起床时间；早晨用日光或模拟日出灯前移生物钟；周末不睡懒觉。
- **咖啡因作为表现增强剂**：不是日常饮料，而是关键节点的工具。
  - When to use：重要会议、比赛、需要专注的短时任务。
  - How：按体重3—6毫克/千克用于运动表现；日常总量不超过400毫克；记住半衰期约6小时，下午晚些时候后不再摄入。
- **光照管理**：早晨的光对晚睡型最有效；办公室可用日光灯，冬天尤其重要。
  - When to use：晚睡型需要适应早班、冬季情绪低落、下午困倦。
  - How：起床后尽快见光；会议室与办公桌配日光灯；早晨让晚睡型靠窗，下午让早起型靠窗。

## Key Concepts
- **云雀（早起型）**：自然醒、吃早餐、白天不易疲惫、晚上早睡；凌晨2—3点已获得较多深睡眠。
- **猫头鹰（晚睡型）**：需要闹钟、常不吃早餐、白天想午睡、周末想补觉；晚上状态更好。
- **中间型**：真正居中的人不少，但多数人过着“中间型时间表”，靠闹钟与咖啡因掩盖真实类型。
- **咖啡因半衰期**：约6小时；一杯大杯现磨咖啡可含330毫克，单份浓缩约75毫克，茶25—100毫克，可乐约35毫克。
- **模拟日出自然唤醒灯**：在固定起床前逐渐亮起，帮助晚睡型前移生物钟。

## Mental Models
- “在状态最佳时做最重要的事”：把写作、决策、训练放在高峰，把归档、寄件放在低谷。
- “咖啡因是工具，不是习惯”：为关键时刻保留效果，别让自己“喝了咖啡也只是达到平常水平”。
- “周末不补觉是晚睡型的纪律”：补觉会把生物钟拨回原点，制造更难受的周一。
- “团队排班看类型，不看道德”：迟到、早上梦游可能不是态度问题，而是生物钟问题。

## Anti-patterns
- **把晚睡型贴上“懒散”标签**：会误判其能力与动机，也会错过其夜间高峰。
- **把关键决策放在错误时段**：点球大战、重要谈判、精密操作都应考虑参与者的类型。
- **晚睡型周末大睡懒觉**：周一时社交时差更严重。
- **全天候靠咖啡因硬撑**：耐受性上升，睡眠被侵蚀，表现反而平庸。
- **忽视伴侣的类型差异**：起床、入睡、晚间家务分工都需要协商。

## Worked Example
世界杯半决赛进入点球大战。选手A是早起型，比赛踢到深夜已明显力不从心；选手B是晚睡型，虽然早上训练常迟到、看起来散漫，但此刻依然敏捷。主教练凭“职业态度”想选A，作者的建议是选B：晚睡型在夜间的灵敏度更高。另一个例子是一对伴侣：他6:30起床，她8:00起床。折中是7:00一起起；他做早餐并给她留出日光下缓醒的空间，晚上则由她多做晚饭和洗碗，因为早起型这时已经累了。办公室同理：早晨把晚睡型安排在窗边，下午把早起型安排在窗边。

## Key Takeaways
1. 先判断类型，再安排日程；不要把生理差异道德化。
2. 重要工作放在个人高峰，低耗任务放在低谷。
3. 咖啡因按需使用，总量不超过400毫克，注意6小时半衰期。
4. 晚睡型改善社交时差的关键是固定起床加早晨光照，而不是周末补觉。
5. 伴侣与团队要按类型协商分工，而不是要求所有人同一节奏。
6. 冬天和下午困倦时，日光灯是低成本的表现工具。
