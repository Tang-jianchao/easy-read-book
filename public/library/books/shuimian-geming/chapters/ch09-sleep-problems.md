# 第9章：与敌同眠——各种睡眠问题

## Core Idea
大多数睡眠问题不是“缺一颗药”，而是节律、行为与环境错位。用R90做诊断：固定起床、按周期安排、用睡眠限制疗法重置失眠，用光线重置时差与夜班，用日光灯应对冬季低落。安眠药不是常规解法；慢性失眠或精神健康问题必须看医生。

## Frameworks Introduced
- **睡眠限制疗法**：先把卧床时间压缩到“实际能睡着的窗口”，用连贯睡眠重建信心，再逐步扩展。
  - When to use：躺很久睡不着、半夜频繁醒来、越想睡越清醒。
  - How：例：目标23:00—05:00但夜里常醒→推迟到00:30（3个周期），固定05:00起床；坚持7天；若仍醒，推迟到02:00；稳定后再逐步提前到4个周期。短期措施，不是长期少睡。
- **时差光线重置**：用光把生物钟“拨”到目的地时间。
  - When to use：跨3个以上时区、商务旅行、赛后返程。
  - How：向东飞（如纽约→伦敦5小时）提前几天早睡早起、早晨见光、晚上避光；向西飞则相反，晚关灯、晚睡晚起；飞行中按目的地白天/黑夜决定见光或遮光；补水、避免酒精；每1小时时差约需1天适应。
- **夜班重置**：把夜班当成“搬到另一个时区”，而不是硬扛。
  - When to use：医护、工厂、保安、客服、线上工作。
  - How：下班后不要直接倒床；先吃一顿“晚餐”、放松、遮光，再按目标时间睡；固定傍晚起床；用模拟日出灯/日光灯唤醒；在凌晨2—3点插入30或90分钟可控修复期；白天睡眠利用午后与傍晚窗口；咖啡因不超过400毫克；长期轮班要评估健康代价。
- **季节性情绪失调的光照策略**：冬季缺乏日光→血清素下降、褪黑素增多。
  - When to use：每年秋冬情绪低落、嗜睡、想吃碳水、动力下降。
  - How：早晨户外见光；办公室/家里用日光灯；傍晚小睡后开15分钟日光灯；尽量在白天出门。
- **失眠分诊**：短期失眠（压力、丧亲、工作）vs 慢性失眠（无明显诱因、长期）。
  - When to use：判断“自己调”还是“看医生”。
  - How：短期先用R90、睡眠限制、光照、运动；慢性或伴随抑郁/焦虑/躁郁/精神症状→就医；不要自行长期吃安眠药。

## Key Concepts
- **失眠**：难以入睡或难以熟睡，并影响白天功能；艾德辛科斯基称其为“过度清醒”。
- **睡眠限制疗法**：用减少卧床时间换取更高的睡眠效率，再逐步扩展。
- **唑吡坦/安眠药**：可诱导睡眠，但易依赖、记忆丧失、梦游、次日反应下降；研究显示比安慰剂仅快约22分钟入睡；NHS建议连续使用不超过4周。
- **时差反应**：跨时区后生物钟与新光暗循环不同步；向东通常比向西更难。
- **社交时差**：晚睡型被迫按早起型时间生活，本质是“日常版时差”。
- **季节性情绪失调**：冬季反复出现的抑郁样症状，与光照不足有关。
- **日光灯**：冬季与夜班的光照工具，可提升灵敏度、情绪与警觉。

## Mental Models
- “醒来就起床，别在床上挣扎”：床只与睡眠联结，清醒时离开。
- “把一周当单位”：一晚睡不好不代表治疗失败；看7天趋势。
- “光线是最强工具”：比咖啡因和安眠药更根本，也更便宜。
- “睡眠限制是重置，不是长期节食”：目标是找回连贯睡眠，然后扩展。
- “先诊断，再用药”：短期、情境性失眠与慢性失眠的处理不同。

## Anti-patterns
- **把安眠药当长期方案**：依赖、耐受、次日残留、梦游风险。
- **半夜看钟表算时间**：越算越焦虑，肾上腺素与皮质醇上升。
- **睡不着还硬躺**：把床变成清醒与挫败的场所。
- **轮班者周末按白天作息生活**：不断在时区之间来回切换。
- **用酒精助眠**：入睡快，但后半夜碎片化。
- **靠过量咖啡因撑夜班**：超过400毫克，白天也睡不好。
- **慢性失眠只靠自助**：伴随抑郁、焦虑、躁郁等必须就医。
- **一次性把作息改太多**：身体无法适应，失败后更焦虑。

## Worked Example
丽贝卡是早起型，因通勤放弃晨练，睡眠变差、夜间常醒。作者把她的固定起床定在05:00，按90分钟倒推：03:30、02:00、00:30、23:00。她仍夜醒，于是把入睡推迟到00:30（3个周期），保持05:00起床；白天保持活动、见光、必要时小睡。坚持7天若仍醒，再推迟到02:00；若02:00—05:00睡得连贯，说明她可能本就需要较少睡眠，之后再逐步扩展回4个周期。另一个例子：纽约→伦敦向东5小时，出发前几天逐日提前睡/起，早晨见光、晚上避光；到达后白天见光、晚上避光，每1小时时差约用1天恢复。夜班则把“下班”当“傍晚”：先吃晚餐、放松、遮光，再睡到固定傍晚起床。

## Key Takeaways
1. 先判断问题类型：情境性、节律性、慢性，处理方式不同。
2. 失眠优先用行为与节律工具，睡眠限制疗法是核心之一。
3. 时差用光“拨表”：向东提前、向西推迟；每1小时约1天。
4. 夜班要整体重置：固定起床、遮光、日间窗口、光照、咖啡因上限。
5. 冬季低落先用日光与户外活动，别只靠意志力。
6. 安眠药只适合短期、特定情境；慢性失眠与精神健康问题看医生。
