# 第8章：把握先机——利用R90修复方案

## Core Idea
R90不是一套夜间技巧，而是一周运行的系统：固定起床作铁锚，90分钟周期作预算，睡前/醒后程序、日间小睡、修复室与寝具共同积累“边际增益”。睡眠是健康三驾马车之一，与饮食、锻炼并列；记录周期，按周调整，别让追踪器替你下判断。

## Frameworks Introduced
- **R90周计划**：把一天拆成90分钟周期，按周结算。
  - When to use：安排工作、训练、社交、出差与恢复。
  - How：固定起床6:30→5个周期则23:00入睡；晚睡→00:30（4周期）或02:00（3周期）；一周目标35个，28—30可接受；至少4晚达标；避免连续3晚不足。
- **睡眠日志**：只记少量可测数据：每晚周期数、一周总数、主观状态、异常事件。
  - When to use：调整作息、怀疑睡不够、与教练/医生沟通。
  - How：每天起床后记一行；周末合计；用“本周几晚达标、是否连续短缺、白天状态”做判断，而不是逐夜焦虑。
- **健康三驾马车**：睡眠+饮食+锻炼；睡眠应被视为健康生活方式的第三大支柱。
  - When to use：想提升精力、恢复、体重管理、运动表现。
  - How：每周150分钟中等强度锻炼；规律进餐；色氨酸食物（鸡肉、火鸡、奶酪、鱼、香蕉、牛奶、坚果）；最后一次正餐在目标睡眠前约3小时，最后零食在睡前90分钟前；睡前补水适量。
- **可穿戴设备的边界**：加速计≠脑电图；它把“不动”当深睡眠，把“动”当浅睡眠，还会记录伴侣或宠物的动作。
  - When to use：想用睡眠App/手环、训练过度、怀疑睡眠呼吸暂停。
  - How：把它当趋势工具和教学工具，而不是每晚裁判；不要一醒来就被分数影响心情；真正诊断靠多导睡眠脑电图；预算优先给寝具、遮光、模拟日出灯。
- **边际增益**：像天空车队一样，把每个1%的改进叠加起来：寝具、房间、光线、 routine、饮食、训练恢复。
  - When to use：追求表现、备赛、长期健康管理。
  - How：一次只改一两个变量；用日志看趋势；可控的做到极致，不可控的接受。

## Key Concepts
- **睡眠日志**：用周期数而不是小时数记录一周睡眠。
- **睡眠周期预算**：35周期/周为理想，28—30可接受，连续短缺是红线。
- **三驾马车**：睡眠、饮食、锻炼相互放大；缺一项，另外两项效果打折。
- **色氨酸**：血清素与褪黑素的前体，富含于蛋白质食物。
- **蒙特莫伦西酸樱桃**：研究显示可能促进褪黑素分泌、改善睡眠时长与质量；属于补充剂，不是必需品。
- **多导睡眠脑电图**：监测脑波、眼动、肌肉活动，是睡眠分期的金标准。
- **加速计**：靠动作推断睡眠阶段，精度有限。

## Mental Models
- “按周结算，不按夜结算”：一晚的分数不决定一周，趋势才决定。
- “固定起床是铁锚”：其他所有安排都围绕它转。
- “睡眠是健康第三支柱”：不要只练和吃，睡是同等重要的变量。
- “追踪器是教学工具，不是裁判”：你醒来感觉如何，比App说你睡得好不好更可靠。
- “先控制可控的”：里约的寨卡、政治、酒店床垫都不可控；能控的是自己的寝具、房间、光线与 routine。

## Anti-patterns
- **用周末睡懒觉补偿**：破坏固定起床，制造社交时差。
- **不困就提前上床**：把床变成清醒与焦虑的场所。
- **被睡眠App的分数牵着走**：数据不准，却制造真实的焦虑。
- **只买追踪器，不改寝具与环境**：花错预算。
- **训练过量、恢复不足**：睡眠是训练的一部分，不是训练的敌人。
- **晚餐太晚、睡前喝酒**：消化与酒精都会破坏后半夜睡眠。
- **把睡眠当“剩下的时间”**：它不是可挤压的边角料，而是表现的基础。

## Worked Example
杰丝的理想是一周35个周期。这一周她只拿到31个，周六晚上只有2个；周日早上6:30按固定时间醒来，当然困。她的处理是：照常起床、吃早餐、散步，午后拉上窗帘、设闹钟，睡90分钟可控修复期。她这一周有四晚达到5个周期，且在连续两晚不足后第三晚睡足；作者认为这份日志没有特别需要担心的地方。若她周末仍觉得比平时累，就回看日志：是否可以取消周日电影、换更早的场次，或更频繁地利用日间小睡。另一个例子是2016年里约奥运会：作者提前数月把30套寝具运到里约，明知酒店床垫硬、可能没空调、寨卡与政治不可控，但把寝具、遮光、房间控制做到极致——这就是“把握先机”。

## Key Takeaways
1. 把R90当周系统：固定起床、周期预算、 routines、小睡、环境一起用。
2. 用睡眠日志记录周期与状态，按周调整，不逐夜焦虑。
3. 睡眠与饮食、锻炼是三驾马车；只改一项，效果有限。
4. 最后一次正餐在目标睡眠前约3小时，最后零食在睡前90分钟前。
5. 可穿戴设备看趋势可以，别让它当每晚裁判。
6. 边际增益的关键是控制可控项，并长期叠加。
