# 第7章：修复室——睡眠环境

## Core Idea
卧室不是生活空间的延伸，而是身心修复室。先把它清空，再只放回睡眠必需的东西；用遮光、16—18°C、清洁空气、噪声控制与安全感，让大脑把房间只和睡眠联系起来。

## Frameworks Introduced
- **修复室（sleep sanctuary）**：把卧室重新命名为“修复室”，功能单一化。
  - When to use：卧室里有电视、游戏机、办公桌、杂物，或伴侣睡眠习惯不同。
  - How：先清空（实际或想象中），只放回床、闹钟和必需品；墙面中性、无刺激图片；把工作、学习、娱乐移出去。
- **空壳法**：把房间当成一块空白画布，再逐项添加。
  - When to use：重新布置卧室、搬家、装修。
  - How：白墙、无装饰→遮光→控温→清洁→噪声→安全感物品；每加一件都问“它帮助睡眠吗”。
- **光线控制**：黑暗促进褪黑素，光线是修复室的第一环境变量。
  - When to use：路灯、窗帘漏光、待机灯、手机充电灯、夏季早亮。
  - How：遮光卷帘/厚窗帘；缝隙用胶带或魔术贴；夜间贴黑色垃圾袋（作者在环法时的做法）；起床后立即拉开窗帘见光。
- **温度控制**：16—18°C最理想；关键是“从温暖到凉爽”的过渡。
  - When to use：中央供暖、夏热、伴侣怕冷/怕热。
  - How：睡前关掉卧室取暖器或开窗；温水澡后进入较凉卧室；夏季用空调、风扇+冰水、只盖被套。
- **噪声与白噪声**：噪声易把浅睡眠者吵醒；稳定白噪声可遮盖突发噪声。
  - When to use：临街、合租、公寓隔音差、伴侣打鼾。
  - How：双层玻璃；耳塞（有不适trade-off）；白噪声App/设备；不要整晚开吸尘器或吹风机。
- **安全感**：修复室最重要的功能是让大脑确认“这里安全”。
  - When to use：焦虑、独居、出差、陌生环境。
  - How：睡前检查门窗；放爱人照片、熟悉的毯子或泰迪熊；保留能带来安全感的物品。

## Key Concepts
- **待机灯**：电视、充电器、路由器的小灯也会抑制褪黑素；能关就关，能移就移。
- **模拟日出自然唤醒灯**：起床前30分钟逐渐亮起，比突然闹钟更符合节律；遮光房间尤其有效。
- **白噪声**：稳定、低强度的背景声，遮盖高低起伏的环境噪声。
- **尘螨**：地毯、寝具、旧床垫中的过敏原；清洁与低过敏材质可减少。
- **安全感**：大脑在确认环境安全后才允许进入深睡眠与REM。

## Mental Models
- “卧室只与睡眠关联”：工作、争吵、刷剧、吃饭都在别处。
- “空白画布”：先移除，再添加；每件物品都要通过“是否帮助睡眠”的测试。
- “安全感优先于明暗和温度”：再黑再凉，如果大脑觉得不安全，也睡不好。
- “先控制可控的”：酒店、出差、合租无法全控，但眼罩、耳塞、白噪声、遮光贴可以带走。
- “卧室不是仓库”：整洁不是审美问题，而是减少大脑待处理事项。

## Anti-patterns
- **卧室放电视、游戏机、办公桌**：把刺激源与睡眠场所绑定。
- **用手机当闹钟**：通知、蓝光、半夜刷手机都由此而来。
- **忽视待机灯与门缝漏光**：小光源也足以干扰褪黑素。
- **卧室温度过高**：25°C的卧室会让体温难以下降。
- **床头放水杯**：会暗示大脑“半夜要喝水”，也可能让你喝多起夜。
- **用眼罩代替遮光**：眼罩不适会干扰睡眠；先修窗帘。
- **卧室挂刺激图片、堆恐怖小说**：睡前给大脑增加唤醒。
- **把杂物堆在卧室**：视觉杂乱会刺激大脑。

## Worked Example
作者去足球运动员罗伊·雷斯家做睡眠环境审计：卧室25°C、床脚有巨大的弹出式电视、游戏机、多个充电设备、明亮的备用灯、漏光的百叶窗、门缝透光、床头一堆松软枕头、西伯利亚羽绒被——对两个人来说太热。建议不是“买更贵的东西”，而是移除电视与游戏机、遮光、把温度降到16—18°C、只留一个薄枕头、把充电器与手机移出卧室。另一个例子是2004年欧洲杯：英格兰队住在同一家酒店，作者把房间当成空白画布，带上定制床垫、遮光、控制温度与噪声；可控的环境本身就是边际增益。

## Key Takeaways
1. 把卧室改造成“修复室”，只保留睡眠必需的东西。
2. 遮光是第一优先级；待机灯、门缝、窗帘缝隙都要处理。
3. 16—18°C，比家里其他房间略凉；关键是睡前从温暖到凉爽。
4. 噪声用隔音、耳塞或白噪声处理；稳定白噪声优于突发噪声。
5. 安全感是修复室的核心功能：检查门窗、放熟悉物品。
6. 酒店与合租无法全控时，带遮光贴、耳塞、白噪声，控制能控制的部分。
