# 第5章：暂停片刻，该休息了！——日间小睡

## Core Idea
修复是24小时的过程，不只发生在夜里。白天有两个天然窗口：午后1—3点（首选）和傍晚5—7点（次选）。把打盹变成主动安排的“可控修复期”，用30分钟或90分钟补周期；即使睡不着，闭眼休息也算数。

## Frameworks Introduced
- **可控修复期（controlled recovery period）**：不是随机打瞌睡，而是有计划地利用白天窗口恢复身心。
  - When to use：夜间缺了一个周期、当晚可能晚睡、午后效率下降、轮班或带娃。
  - How：午后优先；30分钟最实用；90分钟是一个完整周期，但需留出时间克服睡眠惰性；睡不着就闭眼放松30分钟。
- **午后睡眠时机（1—3点）**：一天中次优的修复窗口，与夜间凌晨2—3点相对应。
  - When to use：弥补前一晚缺失的周期，或为当晚可能晚睡做预补偿。
  - How：设30分钟闹钟；在沙发、躺椅、空会议室、安静角落；不要在床上睡；醒后补水、见光。
- **傍晚修复期（5—7点）**：睡眠需求处于峰值，适合短睡；晚睡型可稍向后延。
  - When to use：错过午后小睡、下班后精疲力尽、晚上还有安排。
  - How：最多30分钟，不要睡90分钟，以免影响夜间睡眠。
- **咖啡因小睡（coffee nap）**：小睡前喝一杯浓缩咖啡，咖啡因约20分钟后起效，在醒来时接手。
  - When to use：需要快速恢复警觉、且当天咖啡因未接近上限。
  - How：睡前喝浓缩咖啡（不要拿铁，起效太慢）；30分钟闹钟；计算当天总量不超过400毫克。
- **90分钟大脑休息**：每工作90分钟离开办公环境几分钟，不刷手机。
  - When to use：办公室、会议、长时间专注工作。
  - How：倒水、上厕所、走动、聊天、冥想；5—20分钟；可睁着眼睛在会议中“退居幕后”。

## Key Concepts
- **午后倦怠**：下午1—3点的天然困倦，全球普遍；不是意志力问题。
- **多相睡眠**：一天中分多个时段睡眠；采集狩猎部落与历史上许多名人都有此习惯。
- **睡眠惰性**：从深睡眠醒来后的昏沉；90分钟小睡后更明显，30分钟通常较轻。
- **26分钟NASA小睡**：研究称可提升飞行员表现34%、灵敏度54%。
- **可控修复期计入周周期**：30分钟或90分钟都可以算进一周总睡眠。

## Mental Models
- “你若不打盹儿，就会输得很惨”：把休息当表现工具，而不是懒惰。
- “睡不着也没关系”：闭眼、脱离世界30分钟，本身就有恢复价值。
- “小睡补周期，不替代夜间”：白天小睡是补充，夜间仍是主战场。
- “把休息写进日程”：不要等有空，而是像会议一样预约。
- “先看下一个日程，再决定睡多久”：30分钟适合大多数工作日；90分钟只留给时间充裕、且之后能缓过来的人。

## Anti-patterns
- **傍晚睡90分钟**：容易影响夜间入睡。
- **在家午睡直接上床**：削弱床与夜间睡眠的联结；用沙发或躺椅。
- **休息时刷手机**：没有脱离工作刺激，达不到修复效果。
- **把午睡者当懒汉**：会错过低成本的表现提升。
- **咖啡因已接近400毫克还喝**：增加焦虑与夜间失眠风险。
- **婴儿睡2—3个周期，父母跟着睡那么久**：打乱自己的周期；只取30或90分钟。

## Worked Example
运动员晚上有比赛：若比赛较早，安排30分钟小睡，或干脆不睡；若比赛在晚上，可安排90分钟完整周期，但必须留出足够时间克服睡眠惰性。作者的具体做法是：小睡前喝一杯浓缩咖啡，设30分钟闹钟，醒来时咖啡因刚好起效；如果当天已经接近400毫克上限，就不再喝。办公室版本：午饭后设26分钟闹钟，在安静角落闭眼；即使没睡着，也闭眼30分钟，醒后喝水和见光。带娃版本：婴儿下午1点睡，父母只睡30或90分钟，不要跟着睡2—3个周期。

## Key Takeaways
1. 白天修复是R90的一部分，不是夜间睡眠的替代品。
2. 午后1—3点是首选窗口；傍晚5—7点只睡30分钟。
3. 30分钟最实用；90分钟要在时间允许时用，并考虑睡眠惰性。
4. 咖啡因小睡可加速恢复，但要计入每日400毫克上限。
5. 睡不着就闭眼休息30分钟；“脱离世界”本身有价值。
6. 每90分钟给大脑一次短休息，能叠加成全天的效率优势。
