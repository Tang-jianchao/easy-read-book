# 第4章：热身与舒缓——睡眠前后的例行程序

## Core Idea
睡前90分钟和醒后90分钟与实际睡着的时段同等重要，而且完全可控。睡前程序负责“结束今天”，醒后程序负责“开启今天”；它们决定你能否顺利进入第一个周期，以及白天的效率。

## Frameworks Introduced
- **睡前例行程序（90分钟）**：在目标入睡时间前开始，逐步降低刺激，让身体进入第一个睡眠周期。
  - When to use：每晚固定执行；尤其在想晚睡、吃得太晚、压力大时。
  - How：关闭电子产品与工作消息；从温暖到凉爽（温水澡、凉爽卧室）；从明亮到昏暗（暖色灯、蜡烛、遮光）；整理房间；把担忧写成“我在想什么”清单（“下载一天”）；检查门窗；做轻运动或瑜伽；用鼻呼吸。
- **睡后例行程序（90分钟）**：从固定起床时间开始，帮助从睡眠过渡到清醒，并为下一晚打好基础。
  - When to use：每个工作日早晨；晚睡型尤其需要。
  - How：先不要看手机（至少15分钟，理想90分钟）；拉开窗帘见光；吃早餐并补水；散步或轻运动；做一点需要脑力的事（听广播、读新闻）。
- **偷懒假**：想赖床时，仍按固定时间起床，完成简版醒后程序（上厕所、见光、吃早餐），再回床上休息。
  - When to use：周末、加班后、特别疲惫的早晨。
  - How：保留固定起床与光照，删掉锻炼等可选项；把“回笼觉”当成奖励，而不是对节律的破坏。
- **90分钟约见缓冲**：固定起床7:30，就尽量把约见放在9:00；8:30勉强可以，8:00则要牺牲一个周期、6:00起床。
  - When to use：安排会议、航班、面试、送机。
  - How：优先争取9:00；若无法改变，就明确选择“少一个周期”还是“仓促出门”。

## Key Concepts
- **睡眠前例行程序**：为确保进入准备入睡状态而进行的一系列准备工作。
- **睡眠后例行程序**：确保睡眠时间没有被浪费、顺利过渡到清醒状态的一套动作。
- **下载一天**：用纸笔列“我在想什么”，把当天经历与担忧归档，交给睡眠中的大脑处理。
- **鼻呼吸**：夜间用鼻而非口呼吸，可减少打鼾与睡眠呼吸暂停；口干、床边放水常是口呼吸信号。
- **睡眠呼吸暂停**：夜间反复呼吸停止，大脑缺氧并唤醒身体；伴侣常最先发现。
- **皮质醇**：醒来后本就处于高位；一睁眼就处理压力消息会让它进一步飙升。

## Mental Models
- “不做好准备，就准备好失败”：睡前状态不是偶然，而是被前面的90分钟塑造的。
- “睡前程序结束今天，醒后程序开启今天”：两段都是修复的一部分，不是浪费。
- “手机不是闹钟”：把手机拿出卧室，用独立闹钟或模拟日出灯。
- “床只用于睡眠和性”：工作、吃饭、刷剧都在别处，保住床与睡眠的联结。
- “先完成能完成的部分”：偷懒假不是全有或全无，保留固定起床比完全放弃好。

## Anti-patterns
- **深夜大餐后立刻上床**：消化会干扰昼夜节律与睡眠质量。
- **靠酒精助眠**：酒精带来昏沉感，但会破坏后半夜睡眠。
- **睡前处理工作邮件**：把压力带进床，入睡前还在等回复。
- **在刺眼卫生间灯下刷牙**：破坏已经建立的昏暗环境。
- **醒来第一件事看手机**：在状态最差时处理最需要判断的信息。
- **跳过早餐**：错过唤醒身体与稳定白天饥饿节奏的信号。
- **睡前剧烈运动**：心率、体温、肾上腺素上升，需要很久才能平复。
- **用嘴呼吸、打鼾不管**：会反复打断睡眠周期，也影响伴侣。

## Worked Example
作者的固定起床是6:30。若某晚11点才回家，而11点本是获得5个周期的理想入睡时间，他不会进门刷牙就倒床，而是等到下一个周期12:30再睡，这一晚争取4个周期；如果是在普通夜晚计划11点入睡，则9:30开始睡前程序：吃点小零食、最后一次喝水、排空膀胱、关屏幕、调暗灯光、写“我在想什么”清单。另一个例子：固定起床7:30的人被要求8:30开会，可以礼貌改到9:00；如果对方坚持8:00，就明确选择6:00起床、少一个周期，而不是仓促起床后靠大量咖啡硬撑。

## Key Takeaways
1. 睡前与醒后各留90分钟，视为睡眠修复的一部分。
2. 睡前程序的核心是降刺激：关屏幕、降温、调暗、清空大脑、确认安全。
3. 醒后程序的核心是见光、补水、进食、轻运动，并延迟看手机。
4. 晚睡型的醒后程序尤其重要，不要用“再睡一会儿”把它挤掉。
5. 想赖床时用“偷懒假”：固定起床、简版程序、再回床。
6. 约见与航班要按90分钟周期做取舍，别让起床变成每天的战斗。
