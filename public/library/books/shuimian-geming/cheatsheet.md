# 速查表 Cheatsheet

> R90睡眠决策规则。一页为限：先定铁锚，再算周期，最后用光照、环境和日间小睡微调。

## 1. 先定固定起床时间

| 情况 | 选择 |
|---|---|
| 平时7:00必须出门 | 起床不晚于5:30（留90分钟） |
| 最早会议8:00 | 要么6:00起床少一个周期，要么把会议改到9:00 |
| 晚睡型 | 不要选离日出太远的起床时间 |
| 周末 | 仍按固定时间起床；困就偷懒假，不睡懒觉 |
| 有伴侣 | 尽量统一起床时间；不能统一就协商谁先起、谁后起 |

## 2. 每晚周期数速查（起床→入睡）

| 周期 | 睡眠 | 7:30起床→入睡 | 6:30起床→入睡 |
|---|---|---|---|
| 5 | 7.5h | 00:00（23:45上床） | 23:00（22:45上床） |
| 4 | 6h | 01:30 | 00:30 |
| 3 | 4.5h | 03:00（太少，仅应急） | 02:00（太少，仅应急） |

## 3. 一周红灯

- 目标35周期；28—30可接受。
- 至少4晚达标。
- **避免连续3晚不足**。
- 一晚只睡2个周期：接下来一两晚补完整，不逐夜恐慌。
- 一周有5晚不足且不是临时安排 → 重做计划。

## 4. 小睡怎么选

| 场景 | 时长 | 注意 |
|---|---|---|
| 工作日下午1—3点 | 30分钟 | 最实用；沙发/躺椅，不上床 |
| 当晚比赛/聚会可能晚睡 | 90分钟 | 留时间克服睡眠惰性 |
| 傍晚5—7点 | 30分钟 | 不要90分钟，以免影响夜间 |
| 睡不着 | 30分钟闭眼 | 脱离世界本身就有恢复价值 |
| 需要快速清醒 | 30分钟+咖啡因小睡 | 咖啡因≤400mg/天 |

## 5. 咖啡因规则

- 半衰期约6小时；下午晚些时候后不再摄入。
- 日常总量≤400毫克。
- 大杯现磨约330mg；单份浓缩约75mg；茶25—100mg；可乐约35mg。
- 把它当关键节点的表现增强剂，不当习惯饮料。
- 已接近上限，不再喝；小睡咖啡因也要计入。

## 6. 床垫软硬判断

| 现象 | 判断 | 处理 |
|---|---|---|
| 头与床垫间约6厘米空隙 | 太硬 | 加5—8厘米软层/换床垫 |
| 臀部陷进去、头被垫高 | 太软 | 换更支撑的床垫 |
| 头颈脊柱成直线 | 合适 | 一个薄枕头即可 |
| 需要两个以上枕头 | 多半太硬 | 先修床垫，别加枕头 |
| 伴侣体型不同 | 按较大体型选 | 或分床/分房 |

## 7. 睡眠问题分诊

| 症状 | 先做什么 | 何时就医 |
|---|---|---|
| 偶尔压力大睡不着 | 睡前程序、固定起床、离床 | 持续数周且影响白天 |
| 半夜醒来 | 别看钟；起床做睡前程序，赶下一个周期 | 长期夜醒、伴随情绪问题 |
| 躺很久睡不着 | 睡眠限制疗法（短期） | 慢性失眠、抑郁/焦虑/躁郁 |
| 跨时区 | 光照前移/后移、补水、避酒精 | 持续超过预期恢复时间 |
| 夜班 | 固定傍晚起床、遮光、日间窗口 | 长期轮班且健康亮红灯 |
| 冬季低落 | 早晨户外光、日光灯 | 明显抑郁、影响生活 |
| 打鼾/呼吸暂停 | 侧睡、鼻呼吸、减重 | 伴侣目击呼吸停止、白天嗜睡 |

## 8. 快速决策

- **今晚睡不够** → 按90分钟选下一个周期，别硬躺。
- **明天有大事** → 今晚不追求完美；本周至少4晚达标即可。
- **下午困** → 30分钟可控修复期，不靠第三杯咖啡。
- **晚上不困** → 不困不上床；做睡前程序，等下一个周期。
- **伴侣打鼾/抢被子** → 特大号床、独立被子、床侧调整；仍不行就分床。
- **想买睡眠追踪器** → 先把钱花在床垫、遮光、模拟日出灯上；追踪器只看趋势。
- **长期失眠** → 行为与节律工具优先；药物只短期；慢性问题看医生。
