# 术语表 Glossary

> 《睡眠革命》（尼克·利特尔黑尔斯），按拼音排序，标注章节。

- **安眠药** — 诱导或维持睡眠的药物；易依赖、记忆丧失、梦游与次日残留，只适合短期特定情境（ch09）
- **8小时睡眠神话** — 把人均8小时误当成人人适用的推荐值；强迫躺够会制造焦虑（ch03）
- **白噪声** — 稳定低强度的背景声，用来遮盖突发环境噪声（ch07）
- **鼻呼吸** — 夜间用鼻腔而非口腔呼吸；可减少打鼾与睡眠呼吸暂停（ch04）
- **边际增益** — 把每个1%的改进长期叠加，追求整体表现提升（ch08）
- **床垫自测法** — 用胎儿姿势侧躺，以头与床垫间约6厘米空隙判断太硬、臀部下陷判断太软（ch06）
- **打鼾** — 呼吸道变窄引起的振动声；常与口呼吸、仰卧和睡眠呼吸暂停相关（ch04）
- **多导睡眠脑电图** — 监测脑波、眼动与肌肉活动，是睡眠分期的金标准（ch08）
- **多相睡眠** — 一天中分多个时段睡眠，而非只在夜间连续睡一觉（ch05）
- **固定起床时间** — 每天（含周末）在同一时间起床，是R90方案的铁锚（ch03）
- **季节性情绪失调** — 秋冬反复出现的抑郁样症状，与日光不足、血清素下降和褪黑素增多有关（ch09）
- **加速计** — 靠身体动作推断睡眠阶段的传感器；精度有限，不等于脑电图（ch08）
- **健康三驾马车** — 睡眠、饮食、锻炼三者并列、相互放大（ch08）
- **咖啡因** — 神经刺激物与表现增强剂；半衰期约6小时，每日建议不超过400毫克（ch02）
- **咖啡因小睡** — 小睡前摄入咖啡因，让其在醒来时起效的短睡方法（ch05）
- **可控修复期** — 主动安排、按周期使用的日间小睡或休息，而非随机打盹（ch05）
- **快速眼动睡眠（REM）** — 做梦、身体暂时不能动、有益创造力的睡眠阶段；后半夜占比更高（ch03）
- **垃圾睡眠** — 受干扰、不充足、质量不达标的睡眠（ch01）
- **蓝光** — 白天有助于设定生物钟，入夜后抑制褪黑素、推迟睡眠（ch01）
- **模拟日出自然唤醒灯** — 在起床前30分钟逐渐亮起，模拟日出、帮助自然醒来的灯（ch07）
- **内胚层体型** — 身材魁梧、肩膀与臀部较宽；床垫需求与外胚层不同（ch06）
- **浅睡眠（N2）** — 心率体温下降、整合信息与运动技能的阶段；占比最高（ch03）
- **寝具套装** — 多层床垫、床垫套、薄枕头与可分层羽绒被组成的可携带/家用睡眠系统（ch06）
- **日光灯** — 高亮度、接近日光的光照设备；用于冬季低落、晚睡型与夜班（ch02）
- **色氨酸** — 血清素与褪黑素的前体，富含于蛋白质食物（ch08）
- **社交时差** — 晚睡型被迫按早起型时间生活，等于每天经历一次小时差（ch02）
- **深睡眠（N3/N4）** — 生长激素分泌、身体修复的主要阶段；约占夜间睡眠20%（ch03）
- **生长激素** — 深睡眠中分泌、促进细胞生长与组织修复的激素（ch03）
- **时差反应** — 跨时区后生物钟与新光暗循环不同步，导致失眠、白天疲劳（ch09）
- **睡后例行程序** — 醒后90分钟内见光、补水、进食、轻运动，并延迟看手机（ch04）
- **睡眠冲动** — 由昼夜节律制造的“想睡”窗口，与睡眠压力共同决定困意（ch01）
- **睡眠惰性** — 从深睡眠被唤醒后的昏沉感；90分钟小睡后更明显（ch03）
- **睡眠呼吸暂停** — 夜间反复呼吸停止、大脑缺氧并唤醒身体；伴侣常最先发现（ch04）
- **睡眠环境** — 卧室的光线、温度、噪声、清洁与安全感，是修复室的核心变量（ch07）
- **睡眠阶段** — N1、N2、N3/N4与REM，组成一个约90分钟的睡眠周期（ch03）
- **睡眠类型（chronotype）** — 遗传决定的早起/晚睡倾向，分云雀、猫头鹰与中间型，最多相差约2小时（ch02）
- **睡眠日志** — 记录每晚周期数、一周总数与主观状态的简易表格（ch08）
- **睡眠限制疗法** — 先压缩卧床时间以换取连贯睡眠，再逐步扩展；用于失眠重置（ch09）
- **睡眠压力** — 清醒越久积累越强的睡眠需求，与昼夜节律共同作用（ch01）
- **睡眠周期** — 约90分钟、由多个睡眠阶段组成的循环，是R90的计量单位（ch03）
- **睡前例行程序** — 入睡前90分钟的降刺激流程：关屏幕、降温、调暗、整理、下载一天（ch04）
- **胎儿睡姿** — 侧躺向非主要身体一侧，膝盖弯曲、手臂交叠，颈背臀成直线（ch06）
- **褪黑素** — 松果腺在黑暗中分泌、帮助入睡的激素；光会抑制它（ch01）
- **外胚层体型** — 身材瘦长、臀窄、四肢长；需要更贴合体型的床垫（ch06）
- **午后倦怠** — 下午1—3点的天然困倦窗口，与凌晨2—3点相对应（ch05）
- **下载一天** — 睡前把想法、担忧与待办写下来，交给睡眠中的大脑处理（ch04）
- **修复室** — 把卧室功能单一化为身心修复场所，只保留睡眠必需物（ch07）
- **血清素** — 日光增强时分泌、提升情绪的神经递质，与褪黑素此消彼长（ch01）
- **夜班** — 与昼夜节律错位的工作安排；需用光照、遮光与日间睡眠整体重置（ch09）
- **中胚层体型** — 身材适中、骨骼肌肉厚实、肩胸宽于臀（ch06）
- **昼夜节律** — 约24小时的内循环，由生物钟管理，主要靠日光校准（ch01）
