# 第三章：用结果倒推法让每一步清晰可见

## Core Idea
制订计划的核心是**从两方面彻底地逆向推导**：时间上从期限反推中间目标，领域上把目标拆成可量化的子目标。中间目标是倒推的根本，是逐个跨越的里程碑。同时要"要有所为，也要有所不为"，并把目标**公开**以激发潜意识、断掉后路、获得帮助。

## Frameworks Introduced
- **结果倒推法（两步）**
  - 时间倒推：从最终期限反推中间里程碑（3个月减5kg→前2月减4kg→第1月减2kg→第一周读卡路里书）。
  - 领域倒推：拆成具体可量化子目标（日减200卡摄入、日多耗300卡→周一次肌训两次慢跑）。
  - 复杂目标先分成几个领域，再逐域倒推。
- **计划行动而非计划结果**：为"只要去做就一定能成功"的事制订行动计划；提升行动计划精度。
- **方案B（应对意外）**：悲观计划预留"方案B"——一周可喝两次酒但一次限应酬；不能慢跑就改游泳或控制饮食。一切计划不可能都按理想执行。
- **要有所不为**：明确写下"不做的事"，用肯定的形式表达(如"为了不再熬夜，晚上11点后不用手机")。

## Key Concepts
- **中间目标**：由目标反推设立的小里程碑；超越中间目标(而非遥望终极目标)是持续行动的动力。
- **公开目标清单(7项)**：①要完成的目标 ②完成期限(含星期) ③会为你高兴的人 ④里程碑/中间目标细分 ⑤行动计划 ⑥决定"不做的事" ⑦公开目标(写下来)。
- **告知周围人=断后路**：公开目标后潜意识被激活，完成的概率提高；别人会主动相助(只要目标利于他人)。

## Mental Models
- "行动计划如试卷反复检查"：像对待试卷一样反复检查行动计划的每个环节是否成立。
- "彻底考虑过程"（稻盛）：看到结果之前先彻底考虑过程。

## Anti-patterns
- 只倒推时间不拆领域，或反之→计划落不了地。
- 计划只plan结果不plan行动→无法执行。
- 计划没有方案B→一遇意外即崩溃；不写"不做的事"→被旧习惯拖回。

## Worked Example
减肥倒推：目标3个月瘦5kg→前2月瘦4kg→第1月瘦2kg→按日拆解(日减200卡+日耗300卡)→周计划(周一次肌训、两次慢跑)→预设备选(不喝酒改应酬一次、下雨改游泳)→写下"不做的事"(工作日不喝酒)。全程都是"一定能做到"的行动。

## Key Takeaways
1. 结果倒推=时间上反推中间目标 + 领域上拆成可量化子目标。
2. 中间目标是持续行动的动力，逐个跨越而非仰望终点。
3. 计划行动而非计划结果；为"一定能做到"的事列计划。
4. 悲观计划=预留方案B，应对所有可能的意外。
5. 明确"不做的事"+公开目标，激发潜意识、断后路、获帮助。
