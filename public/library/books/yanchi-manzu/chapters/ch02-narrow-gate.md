# 第二章：敢进窄门，愿走远路

## Core Idea
目标不是"设定可实现的"，而是"设定想实现的"。跨越内心阻碍只有一个诀窍——**与他人商谈并公开目标**：商谈能大幅提高实现概率、让人更乐观、注意到自己意识不到的可能性、得到帮助；和已完成目标的人商谈效果最好。**目标≠梦想**：目标是可验证的，且必须有期限。

## Frameworks Introduced
- **目标设定原则**
  - 设定"想做到的目标"而非"能做到的目标"——令人跃跃欲试、愿意为之延迟满足。
  - 可以被验证的才是目标（与梦想区别）；设立目标必须设定期限，否则无法实施行动计划。
  - 不要设定过高、让人毫无动力的目标；目标过高=自我挫败。
  - 目标数字化：3个月前就要定下目标。
- **与他人商谈的力量**：商谈让目标从"自己的事"变"大家的事"；能获得信息、激励、协助，改变自我形象。
- **和延迟满足感在同一量级的人结伴**：写下实现目标后会为你高兴的人（尽可能多），为他人的同时也会得到他人协助——目标越多人受益，越多人帮忙。

## Key Concepts
- **期限要具体到星期几**：把完成期限设在一年以内并越短越好；期限中加入"星期"，认真程度会一下子提升。
- **梦想 vs 目标**：梦想可以被无限畅想，但目标必须能被验证（数字、期限、可观察结果）。

## Mental Models
- "窄门=高门槛目标"：敢进窄门(选择更难但对的选择)，愿走远路(长期主义、延迟满足)。
- "商谈放大目标"：把目标说出来、和人对齐，完成概率与获得的帮助都提升。

## Anti-patterns
- 目标过高→毫无动力、直接放弃；目标过低→漫不经心。
- 目标无限期→无法倒推计划；不公开→失去外部监督与协助。
- 把梦想当目标→无验证标准、无法行动。

## Worked Example
和目标达成者商谈：与已经完成类似目标的人商谈，能学到具体方法、获得"这件事确实可行"的信心、结识助力资源；商谈对象最好是延迟满足感与自己同量级的人，避免被劝退或带偏。

## Key Takeaways
1. 设"想实现"的目标，不是"能实现"的目标。
2. 目标必须可验证、必须设定期限，期限具体到星期几。
3. 与他人商谈、公开目标能大幅提高实现概率。
4. 和已经完成目标、延迟满足感同量级的人结伴。
5. 目标要数字化、提前3个月启动设定。
