# 第四章：静下心来做有长期价值的事

## Core Idea
实施阶段要**从易到难**，用"兴奋→压力→驯化→习惯"度过最初两周；进展不顺时**量先于质**、增加可控制的行动量；用 **PDCA 循环**把期待结果与实际结果数字化、逐环节定位瓶颈并改善；随时调整中间策略确保目标持续向前。

## Frameworks Introduced
- **从易到难起步**：最简单的行动计划=行动方法清楚、确实可行、绝对不会失败。目标是跑马拉松，第一步是买鞋(而非直接跑)。先积累成功体验，避免开头受挫打击动力。
- **习惯周期(两周定律)**：新习惯经历 兴奋(第1天)→压力(第3天左右)→驯化(第7天)→习惯(第14天)。最初障碍在完成期约5%处，熬过最初一周、两周后"不做反而有压力"。告诉周围人自己已完成的事，形成报告压力。
- **量先于质**：进展不顺时别管那么多，先增加行动量；成功的反面不是失败而是不行动。把注意力放在自己可控制的事上(失败的销售员改数"被拒绝次数")。
- **PDCA 循环**：plan→do→check→action 不断循环；善于达成目标的人频繁穿梭在执行与调整之间。把期待结果与实际结果"数字化"，比较后瓶颈一目了然，马上找到改善方案。

## Key Concepts
- **无法完成中间目标的两种情况**：①做了行动计划但没达标→不轻易改目标，让计划跑PDCA；②无法执行计划→分析原因(没动力/怀疑不安/没时间/被更轻松的事取代)，必要时下调目标数值或延长期限。
- **修正目标两法**：修改数值(下调)适用于固定期限(销售预算、考试)；延长完成期限适用于有延展余地者(研发、减肥)。
- **PDCA 数字化案例**：保险销售链条"参加交流会→收60名片→邀50人→30人出席→8人约谈→5人介绍→3人签单"，把每环节期望概率(83%/60%/27%/63%/60%)与实际对比，精确锁定是哪个环节不达标、针对性补量或改法。

## Mental Models
- "为不为做加法"：成功者看似做乘法，实际只是以数倍速度持续做加法。
- "天才不宣传失败史"：被称天才的运动员/艺术家只是付出数倍努力、经历数次失败仍不屈——别被"天赋叙事"吓退。

## Anti-patterns
- 开头设太难任务→一受挫就放弃；不积累成功体验→动力耗尽。
- 结果不顺只凭感觉→无法定位瓶颈；计划没有数字化→不知道卡在哪一环。
- 一板一眼死守计划→遇挫折不修正→半途而废；进展不顺时还在纠结"质"。

## Worked Example
保险销售 PDCA 修正：若实际"研讨会出席率40%"而计划60%→对策：邀约人数50→70、改邮件+电话为寄邀请函、锤炼电话措辞和邀请文；若"介绍商品率38%"而计划63%→对策：每月多约(8→10位)、优先约对公司产品有需求的、改变邀约顺序。每环节按实际数字补量或换法。

## Key Takeaways
1. 从"一定会成功"的最小行动开始，先买鞋再跑马拉松。
2. 熬过最初一周/两周，新习惯才能巩固(兴奋→压力→驯化→习惯)。
3. 进展不顺时量先于质：增加可控的行动量。
4. PDCA+数字化：把期望与实际结果逐环节对比，精准定位瓶颈。
5. 无法执行计划时，重新回到起点，必要时下调数值或延长期限。
