# 第六章：实现目标的路上，一边努力，一边等待

## Core Idea
团队目标比个人目标更难——需要汇集全体力量。领导者要**创造休戚与共的一体感**：目标既自上而下也自下而上、讲清"为什么"、传达期待与头衔；要成为**深得信任的领导**(倾听/一致/感谢/为公/引咎自责)，并用**5件小事**维持团队积极性。

## Frameworks Introduced
- **团队目标三步**(对应个人三步但更复杂)
  - 第一步设目标：设全体跃跃欲试的目标、自上而下×自下而上结合、让大家明白为什么必须实现。
  - 第二步订计划：让成员完全明确目标、分配跳出"维持现状偏差"的角色、和成员一起考虑职务。
  - 第三步不达目标誓不罢休：管理每个成员进度、及时修正、保持高积极性、创造同舟共济一体感。
- **自上而下 × 自下而上**：自上而下(易设高目标但像强加)、自下而上(有主人翁感但目标偏低)各有弊，应结合——让员工先报数字，领导对可进步者说"不是设能达到的数字，而是设想达到的数字"，往返磋商到一致。年度销售目标最晚提前3个月开始讨论。
- **讲清"为什么"**：说明目标对①成员的好处②公司的贡献③客户/社会的意义。稻盛"目标要众所周知"，反复传达目标与行动计划直到全员记住。
- **传达期待与头衔**：给成员分配任务时结合"你是最优秀的""希望靠你"，授予"营销部第一科长""项目组长"等头衔；说明分派职务的理由(尤其针对员工自己没注意到的优点)。

## Key Concepts
- **可信赖领导的5共同点**：①细心倾听别人讲话(听完再答、肯定发言)；②一贯性原则(言行一致、对人一致、状态一致)；③经常表示感谢(把"理所应当"程度下调、克服面子)；④一心为公(动机至善、摒弃私心、己欲立而立人)；⑤善于引咎自责(功劳归团队、责任自己扛)。
- **提高积极性5件小事**：赞美员工(常找值得表扬处)、关注过程与努力、告知任务的意义、授权赋能(让员工自己思考方案)、共享成果与庆祝。
- **理性脑 vs 情感脑**：员工不服从=理性脑不接受(领导话有误→客观解释任务必要性、用数据佐证)或情感脑不接受(不想听→根本是缺乏信赖)。

## Mental Models
- "优秀运动员不一定是好教练"：擅长做事≠擅长领导，教和学是两码事。
- "积极性跨越维持现状偏差"：积极性是让自己持续待在学习区的精神能量；球队排名不是能力差距而是积极性影响。

## Anti-patterns
- 用地位等级压制("我是领导你必须听我的")→员工理性脑/情感脑都不接受。
- 领导设了目标却不共享(调查：约八成总经理定了明年的目标，但只有约三成与员工共享)→目标形同虚设。
- 只谈涨薪提成、不传达更大意义→年轻员工无感、不认真。
- 功劳归己、过错推人→失去信任；对客户客气对下属颐指气使→失信赖。

## Worked Example
垃圾回收公司Y总经理：对员工说"我们的工作是为子孙后代留下美好环境，营业额每增一分就多保护地球一分，大家一起努力"——用超越个人利益的意义凝聚团队。保险代理S总经理同样把销售目标升华为"让千家万户安心生活"。

## Key Takeaways
1. 团队目标要令全体跃跃欲试，自上而下与自下而上结合设定。
2. 领导必须反复讲清"为什么"、传达期待并授予头衔。
3. 深得信任的5原则：倾听、一致、感谢、为公、引咎自责。
4. 提高积极性5件小事：赞美、关注过程、告知意义、授权、共享成果。
5. 别用地位压人；员工不服从多是理性或信赖问题，对症解决。
