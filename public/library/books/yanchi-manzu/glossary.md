# 术语表 Glossary

> 《延迟满足》(三谷淳)，按拼音排序，标注章节。

- **PDCA 循环** — plan→do→check→action 不断循环；把期望与实际结果数字化对比定位瓶颈（ch4）
- **三步法** — 设立目标→制订计划→实施计划；全书目标达成骨架（ch1）
- **三区理论** — 舒适区/学习区/恐慌区；实现目标关键是持续待在学习区（ch1）
- **乐观地构思，悲观地计划，乐观地实施** — 稻盛和夫哲学，对应三步心态（ch1）
- **量先于质** — 进展不顺时先增加行动量，牺牲一点质换取进度（ch4）
- **中间目标/里程碑** — 由目标反推的小节点，逐个跨越获得动力（ch3）
- **维持现状偏差** — 人类规避变化的心理本能，是实现目标最大障碍（ch1、ch3）
- **达成之脑** — 把自我形象认知改变为"能完成目标的人"的思维方式（ch5）
- **结果倒推法** — 从时间与领域两方面彻底逆向推导制订计划（ch3）
- **影响偏差** — 高估失败心理打击的偏差；实际行动了不会后悔、没行动才后悔（ch5）
- **学习区** — 舒适区外、恐慌区内的适当压力区，效率与潜能最高（ch1）
- **恐慌区** — 不堪重负、思维停滞的区域；目标过高会把人推进这里（ch1）
- **舒适区** — 得心应手、易懈怠的区域；长期待在里面会停止成长（ch1）
- **方案B** — 悲观计划预留的备选行动，应对不可预测的意外（ch3）
- **口号 vs 目标** — 口号无具体方法不可验证；目标可验证且须有期限（ch1、ch2）
- **行为维持热情** — 不是等热情再行动，而是用行动的速度与量催生热情（ch5）
- **习惯周期** — 兴奋→压力(第3天)→驯化(第7天)→习惯(第14天)（ch4）
- **公开目标** — 写下并告知周围人，断后路、激活潜意识、获得协助（ch3、ch4）
- **成长要冒险** — 行动有风险也不纠结；不行动、不冒险、不担责的人不成长（ch5）
- **自上而下×自下而上** — 团队目标结合领导设定与员工设定、往返磋商一致（ch6）
- **公心/动机至善** — 一心为公、摒弃私心，目标利于他人则获众人协助（ch5、ch6）
- **目标数字化** — 把目标、期限、期望结果与实际结果全部量化（ch2、ch4）
