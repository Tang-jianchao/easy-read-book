# 速查表 Cheatsheet

> 目标达成决策指南，帮助你在面对目标/计划/执行/团队时像作者一样行动。以一页为限。

## 核心决策规则

- **启动目标** → 用三步法：乐观构思(设高目标)→悲观计划(倒推+方案B)→乐观实施(从易到难)。
- **设目标** → 设"想实现"而非"能实现"的；可验证、有期限(具体到星期几)；别过高(恐慌)也别过低(舒适)。
- **订计划** → 结果倒推：时间反推中间目标 + 领域拆成可量化子目标；计划"一定能做到"的行动；留方案B；写清"不做的事"。
- **执行** → 计划行动而非计划结果，从最小、不会失败的事开始(跑马拉松先买鞋)。
- **卡壳/不顺** → 量先于质，增加可控行动量；用PDCA把期望与实际结果数字化、逐环节定位瓶颈。
- **不想行动** → 识别维持现状偏差；公开目标+结伴+公开行动计划来跨越；熬过最初两周。
- **自我怀疑** → 重塑"达成之脑"自我形象；记住成长要冒险、行动了不会后悔。
- **带团队** → 目标自上而下×自下而上、讲清为什么、传期待给头衔；用信任5原则+积极性5件小事。

## 关键阈值与判断(Tells)

| 信号 | 判断 |
|---|---|
| 目标一设就"能轻松完成" | 在舒适区，完成率低→应加高 |
| 目标高到恐慌、不敢想 | 在恐慌区，思维停滞→应下调 |
| 目标无限期/不可验证 | 是口号不是目标 |
| 计划没有中间目标 | 无法倒推、没有动力来源 |
| 结果不顺但说不出卡在哪环 | 没数字化→先量化再诊断 |
| 新习惯第3-7天想放弃 | 正常，撑过一周/两周即驯化 |
| 员工不服从 | 理性脑(话有误)或情感脑(缺信赖)问题 |
| 员工积极性低 | 用5件小事：赞美/过程/意义/授权/共享 |

## 时间与数量参考

- **期限**：设一年以内、越短越好，具体到星期几。
- **启动设定**：年度目标最晚提前3个月开始讨论。
- **习惯周期**：兴奋(1天)→压力(3天)→驯化(7天)→习惯(14天)。
- **首个障碍**：出现在完成期约5%处，撑过即进入正轨。
- **商谈对象**：和已完成目标、延迟满足感同量级的人商谈。

## 全书一句话(Bottom Line)

> 目标达成的诀窍无关性格与意志：乐观地构思目标、悲观地制订计划(结果倒推+方案B)、乐观地实施(从易到难+PDCA数字化)，待在学习区、用行动维持热情、公开目标以跨越维持现状偏差——个人如此，带领团队时再加"讲清为什么、传达期待、赢得信任、保持积极性"。
