# 速查表 Cheatsheet

> 芒格的决策指南，帮助你在面对判断/投资/人生时像他一样思考。以一页为限。

## 核心决策规则

- **思考任何问题** → 用多元思维模型（各学科重要理论全用上），别当"铁锤人"。
- **难题难解** → 逆向思考：反过来想，先收集错误再避免；知道"会死在哪里"就不去。
- **重大决策** → 过检查清单（著名失败案例），用流程替代直觉与记忆。
- **判断行为** → 先看激励：激励决定行为方向，警惕激励偏见。
- **投资/投入** → 只在能力圈内；留有安全边际；没做好持有十年的准备就不该买。
- **失去/止损** → 识别"被剥夺超级反应"，用期望值与绝对标准衡量，别死守沉没成本。
- **信息判断** → 易想到≠重要，主动找反证与关键难取信息。
- **想要什么** → 先让自己配得上它（黄金法则）。
- **处世** → 终身学习（每晚聪明一点点）；让客户/上级觉得他们最聪明。

## 关键心理倾向速查（人类误判心理学）

| 倾向 | 表现 | 应对 |
|---|---|---|
| 激励机制偏见 | 激励决定行为，好人也会做坏事 | 先审激励 |
| 被剥夺超级反应 | 失去的痛苦>得到的快乐 | 用期望值对冲 |
| 自视过高 / 过度乐观 | 高估自己、低估风险 | 找反证、多角度 |
| 避免痛苦否认 | 拒绝面对残酷事实 | 直面现实 |
| 避免不一致 | 难改坏习惯、拒绝新观念 | 主动更新认知 |
| 社会认同 | 随大流、受周围影响 | 独立判断 |
| 错误衡量易得性 | 易想到=重要 | 找难取关键信息 |
| 对比错误反应 | 被锚定/参照物操纵 | 用绝对标准 |
| 权威错误影响 | 盲从权威 | 独立思考 |

## 价值投资铁律

- 能力圈内 + 安全边际 + 长期持有（十年）。
- 优秀企业=持续产生现金、有护城河。
- 不追逐平庸机会；拒绝错误机会本身就是能力。
- 增长会放缓要诚实面对（伯克希尔继任问题）。

## 全书一句话(Bottom Line)

> 芒格的全部智慧浓缩为：掌握各学科的普世智慧（多元思维模型）并全部用上，用逆向思维先收集错误再避免，靠检查清单与常识守住能力圈、留出安全边际；最重要的——想得到什么先让自己配得上它，终身学习、每晚比早晨聪明一点点，并警惕人类误判心理学中那20多种随时会操纵你的心理倾向。
