# 第六章：价值投资——能力圈与长期持有

## Core Idea
价值投资的核心是**在能力圈内、以安全边际买入优秀企业并长期持有**。伯克希尔·哈撒韦长期大额投资业绩是"人类有史以来最出色"的，其秘诀不是频繁交易，而是拥有许多不断产生现金的优秀企业并耐心等待复利增长。

## Frameworks Introduced
- **优秀企业的力量**：伯克希尔的关键是拥有许多产生现金的伟大的企业；即使股价下跌也能回购。优秀企业给发展带来动力。
- **长期持有**："如果你没有做好把一只股票持有十年的准备，你一开始就不该买。"买入并耐心持有，让复利与时间起作用。
- **能力圈 & 安全边际**：只在理解的范围内投；买入价留有安全边际，抵御错误与不确定。
- **资本配置的传承**：芒格坦承沃伦（巴菲特）之后资本配置能力可能下降，"从前那种增长速度将会下降，我们可不想在这个问题上说谎"——诚实面对能力边界。

## Key Concepts
- **不追逐平庸机会**："我之所以能有今天，靠的就是不去追逐平庸的机会。"（芒格名言）
- **逆向应用**：巴菲特会通过"校准"芒格的"说不"来筛选项目——拒绝平庸/错误机会本身就是投资能力。
- **巴菲特是学习机器**：伯克希尔每个十年赚钱方法都不同，巴菲特醒着时一半时间在看书，是"不断学习的机器"。

## Mental Models
- "优秀企业现金机器"：选拥有持续现金流、有护城河的优秀企业，而非题材或短期波动。
- "十年持有测试"：买入前自问能否持有十年；不能则一开始就别买。

## Anti-patterns
- 追逐热点、频繁交易、在能力圈外投机。
- 买入不设安全边际，价格远高于内在价值。
- 凭短期波动与情绪决策，而非企业质量与长期价值。

## Worked Example
伯克希尔的启示：通过拥有大量不断产生现金的优秀企业，长期复利增长成为投资史上最出色的业绩之一。芒格与巴菲特分工：沃伦提供资本配置与商业嗅觉，芒格以跨学科"说不"校准项目——组合成长期价值投资体系。

## Key Takeaways
1. 只在能力圈内投资，圈外机会再诱人也不碰。
2. 买入留有安全边际，为错误与不确定留缓冲。
3. 没有十年持有的准备，一开始就别买。
4. 优秀的现金机器企业+耐心持有，是复利的来源。
5. 不追逐平庸机会；拒绝错误机会本身就是能力。
