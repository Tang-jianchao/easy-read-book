# 第三章：人类误判心理学（上）——倾向总览与激励偏见

## Core Idea
**人的心理倾向为数众多，而且它们在生活中会产生相互影响。** 芒格基于进化论与自学（西奥迪尼《影响力》+心理学入门教材）建立了"非临床心理学"体系：人的判断常受进化遗传程序驱动的心理倾向操纵，导致系统性误判。其中**激励机制引起的偏见（奖励惩罚超级反应）**是造成愚蠢行为的最重要原因。

## Frameworks Introduced
- **心理倾向的相互交织（lollapalooza）**：单一心理倾向常被教材孤立讲解，但现实中多种倾向联合作用、同向叠加时产生"lollapalooza效应"，效果惊人。
- **激励机制偏见（最关键）**：惩罚与奖励是超级反应倾向；"激励机制引起的偏见"解释了大量愚蠢商业与政策——你看到的，取决于你被怎么激励。管理者要警惕激励导致的扭曲。
- **西奥迪尼《影响力》的启示**：人类思维有内在缺陷可被利用来操纵；这本书既帮读者防骗，也被销售员用来更有效误导顾客——双刃剑。

## Key Concepts
- **社会性昆虫与进化局限**：蚂蚁神经系统只有约10万个细胞，行为由极简单的遗传程序驱动（死蚂蚁外激素被涂在活蚂蚁身上，其他蚂蚁把挣扎的活蚂蚁拖出巢穴）——证明行为程序会生搬硬套、易被欺骗操控。人类同理。
- **避免怀疑倾向/避免不一致倾向**：大脑为节省运算空间不愿改变、避免不一致——坏习惯难以改掉（"三岁看老"、狄更斯"我戴着我在生活中锻造的锁链"）。
- **社会认同倾向**：人观察周围行为并自动受影响；在模糊/压力情境下尤甚。

## Mental Models
- "蚂蚁实验"类比：复杂系统（人/组织）会机械执行程序而看不清全局，易被环境欺骗。
- "激励即导向"：判断任何行为，先看背后的激励是什么——激励决定行为方向。

## Anti-patterns
- 忽视激励机制对行为的塑造（好人也会因激励做坏事）。
- 低估心理倾向的相互叠加（以为"这点小倾向无妨"）。
- 用"纯理性"假设判断他人，忽略进化遗留的认知缺陷。

## Worked Example
芒格送西奥迪尼一股伯克希尔A股感谢其贡献（《影响力》卖出几十万册），又给每个孩子寄一本——既防自己被推销员欺骗，也警惕销售员反过来用此书误导顾客。激励偏见让他意识到：同样的心理学既能防骗也能用于操纵。

## Key Takeaways
1. 心理倾向众多且相互影响，会产生叠加的 lollapalooza 效应。
2. 激励机制引起的偏见是造成愚蠢行为的最重要原因——先看激励。
3. 人的判断受进化程序驱动、会机械犯错，别高估理性。
4. 社会认同、避免不一致等倾向无意识影响决策。
5. 心理学知识是双刃剑：既能防误判，也能被用来操纵——用于善而非恶。
