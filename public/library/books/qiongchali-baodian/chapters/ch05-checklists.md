# 第五章：检查清单与避免愚蠢

## Core Idea
把著名的失败案例排列成**正确决策的检查清单**，使自己在决策时逐条核对、避免重蹈覆辙。芒格追求的不是比别人聪明，而是**避免犯下愚蠢的错误**——拥有常识（能辨认智慧、拒绝愚蠢）与不自欺精神，是抵御误判的护城河。

## Frameworks Introduced
- **检查清单法**：芒格把著名失败的原因整理成清单，重大决策前过一遍——如同飞行员起飞前的清单，用流程替代记忆与直觉。
- **能力圈**：只在自己真正理解、有优势的范围内做判断与投资；圈外的机会无论多诱人都不碰。"如果你没做好持有一只股票十年的准备，一开始就不该买。"
- **安全边际**：买入价远低于内在价值，为错误与不确定性留出缓冲——价值投资抵御风险的核心。
- **常识与不自欺**：拥有常识=辨认智慧+拒绝愚蠢；不自欺是最强大的精神，因为太少见了。

## Key Concepts
- **"计算得太多，思考得太少"**：电脑/数据带来危险——人们用复杂计算掩盖缺乏真正思考与常识。
- **知识越多的优势**：拥有的基本知识越多，需要吸取的新知识就越少（蒙眼下棋大师靠棋盘知识对弈）。
- **避免愚蠢优先于追求聪明**：只要不搞砸，就不会把自己弄得一团糟；排除错误选项本身就在接近正确。

## Mental Models
- "飞行员清单"类比：重大决策（投资、人生转折）用结构化清单核对，替代临场判断。
- "能力圈边界"：知道自己不知道什么，比知道什么更重要；守住圈内，拒绝圈外诱惑。

## Anti-patterns
- 在能力圈外做重大投资/决策，凭感觉或跟风。
- 没有清单、全凭记忆与情绪决策。
- 用复杂计算/大数据包装缺乏常识的判断。

## Worked Example
芒格作为律师与投资人的日常工作方式：收集各领域失败案例→整理成检查清单→在重要决策前对照核对。这样他既避免了自己犯同样的错，也把"避免愚蠢"变成可执行的流程，而非依赖超凡智力。

## Key Takeaways
1. 决策前过检查清单，用流程替代直觉与记忆。
2. 只在能力圈内行动；圈外机会无论多诱人都拒绝。
3. 安全边际为错误与不确定性留缓冲，是投资护城河。
4. 避免愚蠢优先于追求聪明——不搞砸就已在接近正确。
5. 常识与不自欺是最被低估的智慧。
