# 第一章：普世智慧与多元思维模型

## Core Idea
**你必须知道重要学科的重要理论，并经常使用它们——要全部用上，而不是只用几种。** 大多数人只养成一个学科（如经济学）的思维模型，试图用一种方法解决所有问题——这是笨办法。跨学科掌握 100 种左右的思维模型并让它们变成随时可用的本领，是获得"普世智慧"、做出正确判断的根本。

## Frameworks Introduced
- **多元思维模型**：掌握物理、生物、化学、心理学、经济学、数学等各学科的重要理论，融会贯通，遇到不同问题应用不同模型。
- **铁锤人谚语**："在手里拿着铁锤的人看来，世界就像一颗钉子。"——单一工具/单一学科的人看待一切问题都套用同一方法。
- **学习的方法**：怀特海"发明了发明的方法"→文明才发展；同理，学习了学习的方法→个人才能进步。
- **不自欺的精神**：凯恩斯"介绍新观念不难，难的是清除那些旧观念"；不自欺是能拥有的最好精神，因为它太少见了。
- **常（非常）识**：拥有常识=能辨认智慧也能拒绝愚蠢；"人们计算得太多，思考得太少"。

## Key Concepts
- **学科割据是致命的**：大学各系互不了解其他学科的思维模型，这是美国高等教育的重大毛病（怀特海厌恶的"神经研究法"）。
- **知识要内化**：不能用"考完试清空大脑"的方法学模型，必须认真学习、让它们成为随时使用的本领；没有规则禁止老年后增加新模型。

## Mental Models
- "跨学科95%法则"：真正重要的大道理占每个学科的95%，从所有学科吸取所需知识并变成思维习惯，不是很难的事。
- "铁锤人"诊断：当一个人只用一种方法/一个学科解释所有事，他就是铁锤人，处理问题笨拙。

## Anti-patterns
- 只用单一学科/单一模型处理一切问题（铁锤人）。
- 死记硬背应付考试后清空知识，没有内化成思维习惯。
- 困在学科界线内，无视现实问题跨越学科的属性。

## Worked Example
芒格对巴菲特的评论与"校准"：巴菲特问芒格某个项目，若芒格说"不"，沃伦会用所有钱投资；若芒格说"这是最愚蠢的事"，沃伦会适当投资——通过校准芒格跨学科的"说不"智慧，沃伦获得很多判断依据。芒格自认对沃伦影响被夸大（沃伦本就优秀），但跨学科视角是其价值所在。

## Key Takeaways
1. 掌握多学科的重要理论并全部用上，别当"铁锤人"。
2. 真正的大道理占每学科95%，跨学科学习并不难。
3. 知识要内化成随时使用的思维习惯，而非考完即忘。
4. 不自欺与常识（辨认智慧、拒绝愚蠢）是强大的心智工具。
5. 学科割据、单一视角是致命的。
