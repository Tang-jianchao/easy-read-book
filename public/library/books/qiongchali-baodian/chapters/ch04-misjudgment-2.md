# 第四章：人类误判心理学（下）——关键倾向细解

## Core Idea
芒格的"误判心理学"共列 20 余种倾向。本章细解对决策影响最深的关键倾向，尤其是**自视过高、被剥夺超级反应、避免痛苦否认、过度乐观、错误衡量易得性**等——识别它们，是避免误判的第一步。

## Frameworks Introduced（关键倾向）
- **自视过高倾向**：高估自己的能力、判断与所拥有之物；"过高估计自己"是普遍且危险的。
- **被剥夺超级反应倾向**：人对失去的反应远强于对获得的反应——失去100元的痛苦大于得到100元的快乐。使人因"害怕失去"而做出非理性行为（如拒绝止损）。
- **避免痛苦的心理否认**：人会自动扭曲或否认带来巨大痛苦的事实，拒绝面对残酷现实。
- **过度乐观倾向**：低估风险、高估成功概率；尤其在涉及利益时。
- **错误衡量易得性倾向**：高估易得信息的重要性，低估难以获得但更关键的信息——"轻易想到的"被误当成"重要的"。
- **对比错误反应倾向**：不依据绝对标准，而是依据对比做判断，被操纵的锚定/参照物误导。
- **受简单联想影响的倾向**：把简单联想当因果或依据（如"贵的=好的"）。
- **不用就忘倾向**：技能与知识不用会退化。
- **权威错误影响倾向**：盲目服从权威，即使权威明显错误。
- **喜欢热爱/讨厌憎恨倾向**：因爱而高估、因恨而低估对象。

## Key Concepts
- **偏见与利益的绑定**：芒格强调激励机制偏见贯穿所有倾向——当某种判断有利于个人利益时，人几乎必然产生系统性偏差。
- **应对方法**：识别倾向本身 + 建立清单 + 用数学/统计与绝对标准对冲（如用概率和期望值替代直觉对比）。

## Mental Models
- "损失厌恶锚点"：被剥夺超级反应使人死守已获得的，错失更好选择——决策时把"失去"与"得到"放在同一尺度用期望值衡量。
- "易得性=相关性陷阱"：信息容易想起≠信息重要，要主动寻找反证与难获取的关键数据。

## Anti-patterns
- 因害怕损失拒绝止损/拒绝改变（被剥夺超级反应）。
- 用"忘不掉/易想到"的信息替代全面信息做决策。
- 盲从权威、因爱与恨扭曲判断。
- 用对比（锚定）而非绝对标准判断价值。

## Worked Example
芒格在投资与人生中反复用这些倾向自我检查：面对亏损时识别"被剥夺超级反应"，不因怕损失而死扛；面对新观点识别"避免不一致倾向"，不因旧观念拒绝新观念；面对诱惑识别"激励偏见"，回到长期价值与能力圈。

## Key Takeaways
1. 自视过高、过度乐观、被剥夺超级反应是投资与决策的头号敌人。
2. 被剥夺超级反应=损失厌恶：用期望值而非直觉衡量得失。
3. 避免痛苦否认：敢于直面残酷事实。
4. 易得性≠重要性：主动找反证和关键难取信息。
5. 用对比做判断易被锚定操纵；用绝对标准与统计对冲。
