# 第二章：逆向思维

## Core Idea
**"反过来想，总是反过来想。"**（雅各比）对于复杂的适应系统以及人类的大脑而言，如果采用逆向思考，问题往往会变得更容易解决。芒格得到正确判断的办法，通常是先收集各种错误判断的例子，然后仔细考虑该怎样避免得到这些下场。

## Frameworks Introduced
- **逆向思维（inversion）**：把问题反过来思考，通常能想得更清楚。例如想帮助印度，别问"我要怎样才能帮助印度"，而问"我要怎样才能损害印度"，然后避免这些损害。
- **先收集错误，再避免**：芒格无视行业与学科界线，收集各领域重大的愚蠢事例，研究如何避免，而非在自己领地上搜寻无足轻重的新蠢事。
- **配得上原则**："要得到你想要的某样东西，最可靠的办法是让你自己配得上它。"（黄金法则的现代版）

## Key Concepts
- **乡下人智慧**："要知道我会死在哪里就好啦，我将永远不去那个地方。"——知道避免什么，比知道追求什么更能保命。
- **反向验证**：正向规划常被欲望蒙蔽，从反面找陷阱、找会犯的错，能显著提高判断质量。

## Mental Models
- "反过来想"决策法：遇到选择，先问"这样做最坏会怎样、我怎样会搞砸它"，列出所有犯错方式，然后逐一避开。
- "错误清单法"：收集别人/自己犯过的重大错误，整理成清单，决策时对照。

## Anti-patterns
- 只正向思考、不逆向排查陷阱。
- 在自己的学科领地上找"微不足道的新蠢事"，无视其他行业明显的重大愚蠢。
- 高估自己对某事的掌控，从不设想最坏情况。

## Worked Example
芒格当律师时就用逆向法：收集错误判断的例子（各行业、各学科），考虑如何避免，形成自己的判断体系；对邪教、社会性昆虫的研究同样从"为什么会出错/如何被操控"入手，最终建立了人类误判心理学。

## Key Takeaways
1. 复杂问题反向思考往往更容易解决——"反过来想，总是反过来想"。
2. 正确判断来自先收集错误、再避免错误。
3. 知道"会死在哪里"（陷阱清单）比盲目追求更有价值。
4. 要得到想要的东西，最可靠的办法是让自己配得上它。
5. 别局限于自己学科找小错误，跨学科收集重大愚蠢。
