# 第七章：如何获得精彩人生（处世智慧）

## Core Idea
在南加州大学法学院毕业演讲中，芒格给出"屡试不爽"的人生道理：**要得到你想要的，最可靠的办法是让你自己配得上它**；正确的爱以仰慕为基础；**获得智慧是一种道德责任，必须终身学习**；用跨学科方法避免"法律头脑"的愚蠢；谨慎隐藏你的睿智。

## Frameworks Introduced
- **配得上原则（黄金法则）**："要得到你想要的，最可靠的办法是让你自己配得上它"；己所不欲勿施于人。赢得信任与尊敬是人生最大的快乐。
- **正确的爱以仰慕为基础**：去爱那些对我们有教育意义的先贤；毛姆《人生的枷锁》中"爱中带着藐视"是病态的爱，应赶快治好。
- **获得智慧是一种道德责任**：不仅为让生活更好；必须终身学习，否则走不远。
- **学习机器**：巴菲特醒着时一半时间在看书、其余与可信的人交谈——"他们每天夜里睡觉时都比那天早晨聪明一点点"。
- **跨学科方法**：从所有学科吸取重要道理变成思维习惯，避免单一学科的"法律头脑"。
- **隐藏睿智**：让客户觉得他是房间里最聪明的人、让上级是第二聪明的人，之后才表现自己——避免正确得罪有地位的人引发报复。

## Key Concepts
- **西塞罗**：如果一个人不知道他出生之前发生过什么，在生活中就像一个无知的孩童——除历史外，还要了解所有学科的重要思想。
- **孔子与孝道**：芒格推崇孔子孝道"天生的、需教育、代代相传"，认为它解释了美国亚洲人地位的上升。
- **米拉的榜样**：骨癌病理学研究者米拉休一年假、每天工作17小时、每周7天、写世界最好教科书之一——"如果你们的价值跟米拉差不多，你们想要获得多大的成就就能获得多大的成就"。

## Mental Models
- "每晚聪明一点点"：把终身学习量化成微小的每日进步，日积月累成为学习机器。
- "先配得上，再索取"：想要任何东西（财富、地位、爱、信任），先让自己配得上它。

## Anti-patterns
- 只想索取、不先让自己配得上。
- 爱上"病态的爱"（爱中带藐视、不基于仰慕）。
- 停止学习，靠已有知识走天下；死记硬背应付考试而非形成思维框架。
- 恃才傲物、当众显得比上级聪明（易遭报复）。

## Worked Example
芒格的自我实践：年轻时扑克玩得好，但"认为比上级知道得多时不太擅长掩饰想法"，因此得罪人——他承认这是艰难岁月，建议后人学会隐藏睿智，让客户/上级觉得他们最聪明，自己留到其后。

## Key Takeaways
1. 想得到什么，先让自己配得上它——这是黄金法则。
2. 正确的爱以仰慕为基础；爱有教育意义的先贤。
3. 获得智慧是道德责任；终身学习，每晚比早晨聪明一点点。
4. 跨学科形成思维框架，避免单一学科愚蠢。
5. 隐藏睿智：让客户与上级觉得他们最聪明，慎防得罪有权位者。
