# 第九章：政府的职能开始转变了

## Core Idea
政客发现"人们喜欢免费的东西、痛恨纳税"，于是靠承诺"免费福利"赢得选票，用**印钞（鱼邦储备券）**兑现承诺——这是政府职能从"限权"转向"扩张+印钞"的转折点。纸质货币脱离真鱼储备，成为隐性掠夺储蓄价值的工具。

## Frameworks Introduced
- **政治家生存公式（弗兰基·迪普）**：让人们以为你"免费给予"→获得无条件支持。但要给予就得先索取（政府一切来自税款），参议员自己不捕鱼。于是转向印钞：发行纸币，凭此可兑换政府储存的鱼。
- **央行与法定货币的起源（寓言版）**：鱼邦储备券→承诺可兑换真鱼→储备不足时被迫"官鱼"兑付→货币与真实价值脱钩。
- **宪法的"灵活性"滥用**：大法官被撤换后，新任命者宣称宪法是"灵活文件"、可按新形势解读——为越权发行纸币/挪用税款开绿灯。

## Key Concepts
- **鱼邦储备券（fiat 货币的寓言）**：政府印刷的、可兑换真鱼的纸币；印钞极易，给参议员带来"危险刺激"。
- **官鱼（货币贬值的隐喻）**：技师用 3 条真鱼拼接出 4 条"官鱼"（垃圾变鱼）——通过削减储蓄的价值制造"假增长"。开始时只小 10%，并立法禁止比较官鱼与真鱼（禁止用真实价值作锚）。
- **存款保险（鱼邦存款保险公司）**：政府宣布为储蓄承保→储户放心不取回存款→"即便我们在窃取存款的价值，储户也会以为我们在保护它"。

## Mental Models
- "官鱼魔术"= 货币供应增加但真实财富未增，通过稀释每单位货币的价值掩盖储备不足。
- 政客的时间尺度："我们只需要坚持到下次选举结束，之后会想出长远计划"——以选举周期而非经济周期做决策。

## Anti-patterns
- **撤换反对印钞的央行行长/诚实银行家**：迈克斯·郝寅航七世拒绝同流合污被处死——"随着迈克斯被埋葬，银行业可信赖的传统和健全的货币也一起被埋葬了"。
- **用"灵活宪法"为越权背书**：把宪法解释权政治化，突破纳税/投票与权力限制的约束。
- **存款保险掩盖掠夺**：看似保护储户，实为让储户对价值被窃取无感。

## Worked Example
弗兰基的完整骗局链条：发现"免费福利"能赢选票→季风危机+承诺"政府重建计划"→当选→发现无储蓄支撑→发行鱼邦储备券→首席大法官阻止→撤换大法官、任命自己人→宣称"灵活宪法"→顾问"投资"选民项目→郝寅航七世警告储备缩水→技师造"官鱼"→立法禁比较官鱼真鱼→设渔业部、鱼邦存款保险公司→处死反对者。层层突破约束、掩盖真实价值。

## Key Takeaways
1. "免费福利"是政客赢得支持的核心手段，但政府一切支出最终来自索取（税或印钞）。
2. 印钞（法定货币）让政府不必在收支间抉择，却稀释了储蓄的价值。
3. 货币只有与真实储备/价值挂钩才可信；脱离储备的货币必然贬值。
4. 警惕"宪法灵活解读"——它常是突破权力约束、越权的遮羞布。
5. 存款保险可能成为掩盖货币掠夺的工具，而非保护储户的机制。
