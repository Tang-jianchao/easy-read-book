# 第十章：不断缩水的鱼就像货币一样

## Core Idea
**通货膨胀的本质是货币供应量增加，不是价格上涨本身**——价格只是结果。当政府滥发货币超过储蓄/生产增长，每单位货币的购买力被稀释（官鱼越来越小），物价被迫上涨，储蓄被偷走，最终抑制储蓄、扭曲投资、酿成危机。

## Frameworks Introduced
- **通胀的正确定义（全书关键澄清）**：通胀=货币供应量增加；通缩=货币供应收紧。价格不会"膨胀"，只会涨跌。1990 年前字典都把通胀定义为货币供应量增加。增加货币供应量稀释货币价值，即使物价暂时平稳甚至下跌也可能发生。
- **官方通胀叙事的操纵（阿里·格林芬的"通鱼膨胀"理论）**：把物价上涨归因于"鱼成本推动""高就业繁荣推高需求"，并称"每年贬值一半的通鱼膨胀最理想、是经济发展的环节"——把政府滥发货币的责任转嫁给"成本""需求"，让民众误以为物价上涨与政府印钞无关。
- **通胀的分配效应**：通胀=把财富从以货币储蓄的人手中转移到以货币负债的人那里。最大受害者是退休人员（储蓄耗尽）、依赖固定收入者；而债务人、政客、金融公司受益。

## Key Concepts
- **滞胀（经济停滞型通货膨胀）**：货币过度投入同时带来通胀与经济衰退——20 世纪 70 年代最突出。现代经济学家误以为通胀与失业不能并存，却忽略"失业者少了→生产减少→供应减少→价格上涨"。
- **"官鱼从未变大、物价从未下降"**：只要靠印钞维持，货币单位价值持续缩水。
- **通胀抑制储蓄**：人们发现存进去的鱼变小→减少储蓄→银行投资池萎缩→企业裁员→失业→政府再加码印钞+最低工资管制（恶性循环）。

## Mental Models
- "给气球充气"类比：通胀就像给气球充气使其膨胀——膨胀的是货币供应，不是价格；价格只是被吹大的气球表面。
- 判断"有没有通胀"：看货币供应量是否增加，而非物价是否上涨。

## Anti-patterns
- **把"物价上涨"定义为通胀、据此否认通胀存在**——成功混淆通胀起因，让政府滥发货币逃脱追责。
- **经济不景气时增发货币**：不景气本需要通缩（物价下跌淘汰多余产能、平衡经济），增发货币人为抬高物价、阻碍这个自然调整过程。
- **价格管制（最低工资、价格制定）**：限制企业定价/雇工，使经营更难，抑制产能。

## Worked Example
官鱼缩水全过程：10:9→5:4（小 20%）→3:2→2:1→鱼骨→1/10→最后 50 或 100 条捆成一捆、每天吃 200 条鱼才饱（恶性通鱼膨胀）。随之：退休人员储蓄 20 年 4-5 年用光→人们减少储蓄→投资萎缩→失业→政府设最低报酬/雇工/价格限制→林迪·B 承诺"大社会"救济胜选→继续增发。通胀与失业、物价齐升（滞胀）。

## Key Takeaways
1. 记住真定义：通胀=货币供应量增加；价格只是其结果，别被"物价没涨就没通胀"骗。
2. 通胀把财富从储蓄者转给负债者/政客；退休与固定收入者受害最深。
3. 通胀抑制储蓄、扭曲投资、最终带来滞胀（通胀+失业并存）。
4. 官方常把通胀归因于"成本/需求"，实为掩盖政府滥发货币。
5. 经济不景气时需要的是让价格回落调整，而非增发货币抬高物价。
