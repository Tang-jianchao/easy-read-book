## 核心框架与心智模型

**1. 生产决定消费（全书总纲）**
经济增长的引擎是生产，不是消费；消费只是衡量生产的尺度。没有生产就没有东西可消费。用"找到生产某物的更好方式"解释一切增长。消费不能长期超过产能，借款不能长期超过存款。

**2. 消费不足 + 冒险 = 资本**
资本（工具/设备）由"牺牲当下消费 + 承担失败风险"创造。储蓄创造资本，资本扩大生产，生产提高生活水平。储蓄起来的一美元对经济的积极影响大于消费掉的一美元。

**3. 储蓄的 5 种处置与贷款三分类**
存/消费/借/投资/组合，取决于风险偏好。贷款问"能否扩大产能"：商业贷款（最佳）放，消费贷款（负担）拒，应急贷款（救命）放。借贷以真实储蓄为前提，"扩大信贷"不能凭空造储蓄。

**4. 利率是市场信号，不是政策工具**
利率由储蓄供给与借贷需求决定，受三大因素驱动（银行利润动机、对高风险损失担忧、消费时间偏好）。美联储操控利率的两大致命缺陷：脱离市场判断 + 政治考量偏袒低利率。低利率刺激借贷、抑制储蓄。

**5. 通胀 = 货币供应量增加（不是价格上涨）**
价格只是结果。看货币供应判通胀，别被"物价没涨就没通胀"骗。通胀把财富从储蓄者转给负债者/政客，受害最深的是退休与固定收入者；抑制储蓄、扭曲投资，终致滞胀。

**6. 通缩是生产率提高的自然结果，不是灾难**
技术创新单向，价格长期趋降，应鼓励储蓄。妖魔化通缩、为印钞通胀开路，是政治家最爱（通胀=隐性征税、稀释债务）。

**7. 泡沫 = 政策扭曲信贷 + 价格脱离收入与生产**
政府担保（"两棚"=房利美/房地美）让银行几乎无风险放贷→低利率/低标准→价格被推高→被视为"只赚不亏的投资"→泡沫膨胀。价格涨幅远超收入与信贷扩张，是泡沫警报；"价格永不跌"的集体信念由政客/企业/媒体共谋。

**8. QE/量化宽松 = 印钞的委婉说法 = 债务货币化**
向金融注入新资金推高价格，制造复苏假象。用汽油救火：越多越旺，一旦依赖就停不下来（QF1→QF2→无限量），"退出策略"是不可兑现的谎言。

**9. 政府入不敷出只有四选项**
增税（抑制生产）/ 削减支出（最好但难）/ 拒债（失信于外国，可清算重来）/ 印钞通胀（最容易却代价最惨，滑向恶性通胀）。法币失去真实支撑终成废纸（德国、匈牙利、津巴布韦先例）。

**10. 储备货币地位与全球失衡**
储备货币让发钞国"不储蓄也借贷、不生产也消费"；美元储备地位+人民币挂钩破坏了贸易逆差自我调节。储蓄国停止购买法币→法币崩溃→恶性通胀，而转向国内生产消费的反而繁荣（"无鱼不起浪"）。
