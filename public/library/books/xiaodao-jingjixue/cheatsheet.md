# 速查表 Cheatsheet

> 作者的判断规则与决策指南，帮助你在面对经济/政策/投资问题时像作者一样行动。以一页为限。

## 核心决策规则（决策规则）

- **判断任何经济问题** → 先看生产端，再看消费端。**生产创造价值，消费只是衡量尺度**；没有生产就没有东西可消费。
- **配置储蓄/资金** → 问"能否扩大产能"：能→投/贷；只用于享乐→拒；救命→放。
- **评估投资** → 只问收益是否大于支出；否则是浪费资源、阻碍增长。
- **判断通胀** → 看货币供应量是否增加，不看物价。物价是结果，不是定义。
- **判断泡沫** → 价格涨幅是否远超收入与真实生产；是否靠信贷无限扩张撑着。是→泡沫将崩。
- **评估刺激/QE** → 问复苏是否建立在干预本身之上（一停就崩=依赖）；QE 是汽油救火。
- **找危机责任** → 谁制造了低利率与宽松信贷（政客/央行），而非金融从业者。
- **评估贸易** → 用优势换缺乏，双方受益；壁垒保低效岗位、牺牲潜在收益。

## 资产/价格真伪识别（Tells & Smells）

| 信号 | 判断 |
|---|---|
| 价格涨幅远超收入增长（购房 2-3 倍→10-20 倍年收入） | 泡沫信号 |
| 信贷在无限扩张（政府担保、低首付、零首付） | 价格不可持续 |
| 官方把通胀归因于"成本/需求"而非货币供应 | 掩盖滥发货币 |
| 经济复苏"靠 QE/刺激才不崩" | 依赖成瘾，终将崩溃 |
| 金融资产创新高 + 失业/实体萧条并存 | 金融与实体背离的假象 |
| 政府用"就业本身即刺激"为无价值项目辩护 | 资源错配 |
| "价格下跌是最大威胁" | 为印钞/通胀开路的托词 |

## 政府入不敷出的出路（Trade-off 矩阵）

| 选项 | 政治难度 | 经济后果 |
|---|---|---|
| 增税 | 难（不受欢迎、有上限） | 抑制生产、降低活力 |
| 削减支出 | 难（利益受损者抗议） | 最好，但难执行 |
| 拒还债务 | 相对易（失信于外国） | 可清算、相对可重来 |
| 印钞/通胀 | 最容易、最政治正确 | 债务贬值，滑向恶性通胀、代价最惨 |

## 阈值与默认（Thresholds & Defaults）

- **储蓄一美元 > 消费一美元**：储蓄→资本→扩大生产。
- **借贷以储蓄为前提**：贷款总额受真实储蓄约束；"扩大信贷"不能凭空造储蓄。
- **通缩是生产率提高的自然结果**：技术创新单向，价格长期趋降，应鼓励储蓄而非恐惧。
- **经济增长的唯一原因**：找到了生产人类所需物品的更好方式（工具/资本/创新）。
- **储备货币地位是双刃剑**：让发钞国免生产免储蓄，但撤资/失信心即崩溃。

## 全书一句话（Bottom Line）

> 消费不能超过产能，借款不能超出存款，至少不能长期这样；经济不会因消费而增长，而是经济增长带动消费。储蓄创造资本、资本扩大生产、生产提高生活水平——偏离这条主线（靠印钞、担保、宽松信贷制造繁荣）的经济，最终必然崩溃，回到徒手捕鱼的状态。
