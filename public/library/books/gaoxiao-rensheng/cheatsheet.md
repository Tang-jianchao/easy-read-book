# 速查表 Cheatsheet

> 情境 → 方法选择。先诊断瓶颈，再选一个工具；不要一次把所有方法都装上。

## 三条决策规则

1. **先诊断瓶颈，只修一个环节**：入口乱→收件匣／PARA；行动乱→GTD／防弹笔记；时间乱→成果线／时间区；动力乱→拖延对策／原子习惯；方向乱→曼陀罗／百年计画。
2. **先低摩擦，再完整**：能用一个清单解决，就不要搭系统；“执行优先于整理”，系统要在使用中长出来。
3. **先保护时间，再谈效率**：先守住 Q2、成果线与神圣时间；没有保护，任何方法都会被临时任务吃掉。

## 关键默认值

| 项目 | 默认 |
|---|---|
| 收件匣处理 | 每天 1–3 次（上班、午休前、下班前） |
| 快速判断 | 2 分钟内能做完就立刻做，否则延后 |
| 成果线 | 每天至少推进一小步；一天最多约 4 条 |
| 番茄钟 | 25 分钟专注＋5 分钟休息；4 轮后长休 15–30 分钟 |
| 会议 | 3–5 个议题，重要议题先讨论，结束前定负责人 |
| 习惯 | 目标不是完美，而是不连续错过两天 |
| 晨间日记 | 3–5 分钟；每格 30–40 秒 |
| 覆盘 | 随时记录＋每周检视；每个问题都要落到下一步 |
| 网瘾自评 | 8 题中 ≥5 题“是”，需认真处理 |

## Tells & Smells

| 看到什么 | 通常表示 |
|---|---|
| 收件匣越积越多 | 只捕捉、不理清 |
| 清单列满还自责 | 优先级压死了内在意愿 |
| 一直在整理分类 | 整理替代了执行 |
| 所有事都在 Q1／Q2 | 重要性标准失效 |
| 只做关键 20%，细节崩盘 | 80% 地基没有处理 |
| 会议记录没有负责人 | 下次一定重来 |
| Check 只写“要更努力” | 没有数据，PDCA 流于形式 |
| 每天熬夜赶 Deadline | 只有截止线，没有成果线 |
| 九宫格填满却没有行动 | 把思考工具当成成果 |
