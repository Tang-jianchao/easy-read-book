## 核心框架与心智模型

**1. 全书主线：七段闭环**
第二大脑（接住资讯）→ 行动计画（变成下一步）→ 选择与执行（决定做什么、不做什么）→ 时间管理（保护执行时段）→ 养成习惯（让行动持续）→ 专案管理（让成果按时交付）→ 覆盘反思（让下一轮更好）。**Use when 不知从哪开始**：先判断哪一段最堵——入口乱、行动乱、取舍乱、时间乱、动力乱、专案乱、方向乱，只修那一段。

**2. 下一步行动（GTD 的核心）**
任何任务都要落到“现在就能开始”的具体动作。GTD 五阶段：捕捉→理清→整理→检视→执行。**Use when 脑中挂满未完成事项**：先建立单一收件匣，再逐项问“要不要行动？下一步是什么？”；执行时依次判断立即做、委派、排入延迟行事历。**Prefer 下一步行动 over 任务名称**，因为“制作报告”无法开始，“先找三份竞品资料”可以。

**3. 清空收件匣（Inbox Zero）**
清空不是全部完成，而是每一项都已分派：删除、封存、2 分钟内回应、延后到正式流程。每天固定 1–3 个时段处理（刚上班、午休前、下班前），其余时间关闭通知。**Use when 被邮件与即时通切碎**：把重要行程放进日历、任务放进待办、资讯放进笔记、长文放进稍后阅读；不要在收件匣里管理工作。

**4. PARA 与“执行优先于整理”**
只设四类：Projects（有截止日、可完成）、Areas（长期维持、无终点）、Resources（兴趣参考）、Archives（不活跃）。**Use when 资料找不到或分类越建越乱**：从正在执行的专案开始建，不要一次搭完；资料随执行在四类间移动。**Prefer 先执行再整理**，因为凭空设计的系统往往不是真正需要的系统。

**5. 卡片盒笔记法（Zettelkasten）**
暂时笔记 → 文献笔记（用自己的话重写＋来源）→ 永久笔记（一个观点一张、写清论述）→ 在卡片盒建立连结 → 专案时建索引笔记重组。**Use when 读很多却写不出**：写作不是打开空白文件，而是把已有卡片重新编排；由下而上，先写许多卡片，主题会自己浮现。

**6. 子弹笔记与防弹笔记**
子弹笔记用当日志、目标群组、未来志、当月志，靠“转移”重写条目来筛选；**Use when 每天忙却没有成就感**，因为转移会逼你重新确认“这件事还重要吗”。防弹笔记以“核心任务笔记”为单位，资料跟着行动排序，用 KPT（Keep／Problem／Try）覆盘；**Use when 资料散落、整理变拖延**，用搜寻代替分类，先执行再整理。

**7. 取舍四工具**
- **断捨离四象限**：有意义／没意义 × 用得到／用不到；**Use when 物品、目标、资讯太多**，右上设计流程、左上留精华、右下留现在需要的量、左下放手。
- **时间管理矩阵（艾森豪矩阵）**：重要×紧急；Q1 专注产出、Q2 每天固定保护、Q3 委派／加速、Q4 限制。**重要＝我能处理且能创造价值**；Q2 回报最高，且能减少未来 Q1 的救火。
- **80/20 法则**：先定义目标成效，再找贡献最大的关键成果；**Use when 时间不够**，但不要只做 20%，其余 80% 细节要稳定处理。
- **说不清单**：列出诱惑行为，为每个诱惑设计替代行为，并明确向他人表达界限；**Use when 被会议、邀约、滑手机切碎**。看似好的机会也可能是时间黑洞。

**8. 时间：成果线与时间区**
- **进攻行事历**：不要问“任务需要多少时间”，先问“我愿意投入多少时间、要换来什么成果”。拆解任务→从截止日回推“成果线”→每天只推进一小步→估算时间胃口（一天最多几条成果线）。**Use when 中长期专案不知何时开始**。
- **时间区（Time Blocking）**：盘点精力时段，高精力留给要事，杂事集中批次处理，不排满；**Use when 总被杂事打断**。每天留一段“神圣时间”，任何人、任何任务都不能侵占。
- **会议管理**：会前定目的、议程、时限（3–5 个议题，重要议题先讨论）；会后确认下一步与负责人。**Use when 会议议而不决**，因为没有结论与负责人的会议就是集体浪费。

**9. 习惯与动力**
- **原子习惯**：提示、渴望、回应、奖赏。好习惯——显而易见、有吸引力、轻而易举、令人满足；坏习惯反向操作。**Use when 想建立或破除习惯**：不要靠意志力，改环境、改提示、改阻力。
- **拖延五心态**：远观→设阶段成果与时限；逃避→拆简单下一步；惩罚→莫法特休息法轮换替代行动；理想→两分钟法则往回推到最小第一步；恐惧→成长心态与迭代清单。**Use when 明知该做却不动**：先辨心态，再选对策。
- **心流**：挑战与能力平衡、目标明确、即时回馈；能力不能立刻改，就设计“略高于当前能力”的挑战。**Use when 重复工作无聊或焦虑**。
- **番茄钟**：25 分钟专注＋5 分钟休息，四轮后长休息；被打断不暂停，记为失败并重开；记录一周后再调短或调长。**Use when 容易分心或想了解真实工作节奏**。
- **休息与防沉迷**：压力＋休息＝成长；把休息写成待办，安排在压力任务之后；防沉迷用减少目标、明确规则、替代活动，而不是一刀切禁止。

**10. 专案管理四工具**
- **PDCA**：Plan（目标、分析问题、策略）→ Do（执行＋搜集数据）→ Check（用真实数据与目标比对）→ Act（改进、实施、监控）。**Use when 流程要持续改进**；没有数据的 Check 只会变成空泛反省。
- **以终为始**：明确最终目标→分析条件→从终点倒推步骤→执行→监控调整；**Use when 长期目标模糊**，但要保持“动态的以终为始”，允许路径随反馈调整。
- **SMART**：Specific、Measurable、Achievable、Relevant、Time-based；最常失败的是可衡量标准与合理期限。**Use when 目标“感觉很清楚”却无法追踪**。
- **关键路径法（CPM）**：列任务→标依赖→找耗时最长的路径；关键路径上任一任务延迟，全案延迟。**Use when 复杂专案、任务有先后依赖**；非关键路径保留缓冲，关键路径任务密集监控。
- **前推法／倒推法**：倒推从完成日往回排，快速但易过度乐观；前推从最早开始日往后加实际时间，较现实。**Use when 时间预估总是太短**：倒推定 Deadline、前推定执行。

**11. 覆盘与长期方向**
- **覆盘／AAR**：确认初始目标→找差距→按准备、执行、验收列实际动作→找问题点→下一次行动分短期／中期／长期。**Use when 完成任务后想下次更好**：覆盘是行动清单，不是反省日记；保留有效经验与修正无效行动同等重要。
- **曼陀罗思考法**：3×3 或 81 格，中央写具体目标，周围八格写相关主题；**Use when 目标卡关、创意停滞、人生茫然**。它是思考工具，不是细部专案计划；填不满可以留白。
- **晨间日记**：早上用 3–5 分钟写昨天，先写开心的事，再写工作、财务、健康、人际四领域的事件与感受；**Use when 日记变成流水账**，写对未来有意义的话，并对照年度目标。
- **人生百年计画**：81 格曼陀罗，每十年一阶段，每阶段分八大领域；**Use when 想让长期方向落地**，再用原子习惯、防弹笔记、进攻行事历、PARA 接回每日行动。

**12. 组合原则**
- **不要全用**：一次只修一个瓶颈，跑通再扩展。
- **低摩擦优先**：能用一个清单解决，就不要搭系统。
- **先保护时间**：先守 Q2、成果线、神圣时间，再谈效率。
- **先执行再整理**：系统要在使用中长出来。
- **系统要能接住变化**：好的系统不是完美计划，而是被打断后还能继续。
