# 速查表

## 财富：三个概念别混
| 概念 | 本质 | 判断信号 |
|---|---|---|
| 财富 | 睡觉时仍在赚钱的资产 | 停手后仍有收入 |
| 金钱 | 转移财富的信用符号 | 只是欠条，会贬值 |
| 地位 | 社会等级中的位置 | 零和，靠击败他人 |

## 三种杠杆怎么选
| 杠杆 | 需要许可？ | 适合谁 | 主要风险 |
|---|---|---|---|
| 劳动力 | 是（有人追随） | 有管理能力者 | 管理复杂、众叛亲离 |
| 资本 | 是（有人出资） | 有信誉与判断力者 | 放大错误决策 |
| 代码/媒体 | 否 | 普通人 | 前期慢、需持续输出 |

**规则**：先选无需许可的杠杆；判断力不够时，不要加杠杆。

## 四种运气
| 类型 | 来源 | 你能做什么 |
|---|---|---|
| 不期而遇 | 意外 | 保持开放 |
| 坚持不懈 | 大量尝试 | 持续行动 |
| 专业敏感 | 领域深耕 | 做到专家 |
| 性格品牌 | 独特声誉 | 让机会找你 |

## 决策四问
1. 这个选择 10 年后的后果是什么？
2. 利弊真的相当吗？相当就选短期更痛苦的那条。
3. 仍然难以抉择？默认否定。
4. 这个判断能被证伪吗？不能，就别当真理。

## 幸福 vs 成功
| | 幸福 | 成功 |
|---|---|---|
| 起点 | 满足现状 | 不满现状 |
| 游戏 | 单人 | 多人/零和 |
| 终点 | 平和 | 下一个目标 |
| 陷阱 | 欲望契约 | 享乐适应 |

## 面对任何状况：三选一
- **改变**：横下心行动，不空想。
- **接受**：泰然处之，停止与现实对抗。
- **逃避**：决然离开，不拖延。
- **最痛苦**：想改不改、想走不走、又不接受。

## 快速诊断
- 收入停手即停 → 你在出租时间，缺股权/杠杆。
- 总觉得别人更好 → 做 100% 交换测试。
- 同时想要很多 → 欲望超载，只留一个。
- 说“没时间” → 这件事不是你的优先项。
- 反复犹豫 → 答案多半是否定。
- 愤怒 → 你在用别人的行为惩罚自己。
- 忙到没空思考 → 你在用战术勤奋逃避战略判断。
- 想改变却一直说“打算” → 你还没真想改。

## 每日/每周系统
- 每天：晨练、阅读 1 小时、冥想/独处、睡 8 小时。
- 每周：留 1–2 天不排满，用于思考。
- 每年：生命公式打分，只改一个最低杠杆点。
