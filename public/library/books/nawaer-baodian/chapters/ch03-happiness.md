# 第三章：学习幸福

## Core Idea
幸福不是持续的快乐，而是“无缺憾感的平和”。它是一种可以习得的技能和可以做出的选择；最大的障碍是欲望——那份“不得到我想要的东西，我就不会快乐”的自我契约。

## Frameworks Introduced
- **幸福=无缺憾感的平和**：当生命不缺少什么时，大脑停止追忆与谋划，内心宁静。
  - When to use: 评估自己是否幸福，或追求幸福时。
  - How: 不问“我还缺什么”，而问“此刻有什么缺憾感”；减少缺憾，而不是增加刺激。
- **欲望即痛苦**：欲望是你与自己签的契约——“不得到它，我就不快乐”。
  - When to use: 每次强烈想要某样东西时。
  - How: 先识别契约，再选择是否签署；目标是不同时对生活有一个以上的欲望。
- **幸福是技能/选择**：基因决定上下限，环境有影响，但个体可以通过训练提高幸福基线。
  - When to use: 认为自己“天生不幸福”时。
  - How: 像练肌肉一样练：试错、养成好习惯、选择环境与人。
- **三种应对**：面对任何状况，只能改变现状、接受现状或逃避现状。
  - When to use: 陷入纠结、反复空想时。
  - How: 明确选一个；纠结与回避才是大部分痛苦的来源。
- **嫉妒解药：100% 交换测试**：你只能嫉妒对方的全部人生，不能只挑其中一部分。
  - When to use: 嫉妒某人时。
  - How: 问“我愿意成为他，包括他的家庭、欲望、焦虑、健康、全部记忆吗？”若不愿意，嫉妒就无效。
- **五只黑猩猩理论**：观察最常与你相处的人，就能预测你的行为与幸福。
  - When to use: 选择朋友、伴侣、同事时。
  - How: 问：他们积极吗？维系关系耗心力吗？我钦佩且不嫉妒他们吗？
- **成功≠幸福**：成功源于对现状的不满，幸福源于满足现状；享乐适应让胜利很快失效。
  - When to use: 把某个成就当作“幸福终点”时。
  - How: 识别自己是否在玩一个已经过于简单的游戏；学会在合适的时候退出。

## Key Concepts
- **缺憾感**：觉得“少了点什么”的主观感受；幸福是它的消失，而不是快乐的增加。
- **中性状态**：没有幸福也没有不幸福的状态；像孩子一样沉浸当下，不是平淡，而是完美的平静。
- **平和**：静态的幸福；幸福是动态的平和。内心平和时，做什么都能获得幸福体验。
- **享乐适应**：再好的东西也会很快习惯；人造物品比自然体验更容易导致适应。
- **嫉妒**：想只拿走别人生活的某一部分；它不改善你的生活，只让你不快乐。
- **单人游戏 / 多人游戏**：幸福、健康、内在成长是单人游戏；地位、政治、学术排名是零和多人游戏。
- **一致性偏见**：公开承诺会推动你按承诺行事；可用于养成幸福习惯。
- **幸福基线**：长期平均的幸福水平，可以通过习惯、环境与人际关系提高。
- **接受**：无论结果如何都能泰然处之；不是放弃，而是停止与现实对抗。
- **死亡**：接受无法改变之事的最深层练习；正视死亡，才能活在当下。

## Mental Models
- **平和是静态幸福，幸福是动态平和**：先求内心安静，再谈快乐体验。
- **生活是单人游戏**：真正的评价标准在内；别人眼里的好坏不能替你打分。
- **中性状态=孩子状态**：孩子快乐，因为他们沉浸当下，不要求环境迎合欲望。
- **欲望是自我契约**：每次想要，先问“我是否愿意签下‘得不到就不快乐’的条款？”
- **选择短期痛苦**：运动、阅读、戒糖短期难受，长期提高幸福基线。

## Anti-patterns
- **认为改变外部环境能带来永久幸福**：外部问题无穷无尽，欲望适应得比收入快。
- **同时追多个欲望**：分心、焦虑，一个都追不好。
- **嫉妒**：只想要别人的某一部分，却不愿承担对方的全部人生。
- **被“应该”驱动**：每个“应该”背后常是负罪感或社会规训，违背心意会带来痛苦。
- **用多巴胺零食替代幸福**：社交媒体、新闻、糖、咖啡、游戏带来短刺激，拉低长期基线。
- **把积极想法等同于幸福**：每个积极想法都含一个消极想法的种子；幸福不是强行乐观。
- **把成功当幸福终点**：成功后仍会享乐适应，然后继续追逐下一个目标。

## Worked Example
一次“欲望审计”：
1. **写下**当前最强烈的欲望（新车、升职、某个关系）。
2. **读出契约**：“如果得不到它，我就不会快乐。”问自己是否愿意签。
3. **只留一个**最有价值的欲望，其余先放下；同时追多个只会分心。
4. **做 100% 交换测试**：若嫉妒某人，问是否愿意接受他的全部人生；通常答案是否定的，嫉妒随之失效。
5. **三选一**：改变、接受或逃避；停止“想改变却不行动、想走却不走、又不肯接受”的纠结。
6. **换框**：对挫折问“这件事有什么积极面？”或“宇宙要给我上什么课？”把反应时间从几秒练到近乎即时。

## Key Takeaways
1. 幸福=无缺憾感的平和，不是持续快乐，也不是积极情绪。
2. 欲望是“不得到就不快乐”的自我契约；一次只选一个欲望。
3. 幸福是技能，可以通过习惯、环境与人际关系提高基线。
4. 面对问题只做三选一：改变、接受、逃避；纠结最耗人。
5. 用 100% 交换测试消除嫉妒；生活本质是单人游戏。
6. 成功源于不满，幸福源于满足；不要把成功当作幸福的终点。
7. 少看屏幕、少看新闻、少糖少咖啡，多运动、多阳光、多与快乐的人相处。
