# 术语表 Glossary

> 《小狗钱钱》(博多·舍费尔)，按拼音排序，标注册。

- **愿望清单** — 写下10个愿望，确定最重要目标（钱钱1-1）
- **梦想储蓄罐** — 为重要目标专款储蓄，目标可感（钱钱1-1）
- **梦想相册** — 目标图片可视化，天天看强化动机（钱钱1-1）
- **成功日记** — 每天写5件成功的事，建立自信（钱钱1-1）
- **挣钱之道** — 为别人解决难题 + 关注自己能做/知道/拥有的（钱钱1-3~4）
- **债务4忠告** — 毁信用卡、最低分期、剩下一半存一半还、花钱前问"有必要吗"（钱钱1-6）
- **量入为出** — 支出不随收入盲目增长，学会合理分配财产（钱钱1-6）
- **鹅与金蛋** — 鹅=本金，金蛋=利息；"不要杀死你的鹅"（钱钱1-7）
- **50/40/10分配** — 金先生的收入分配：50%养鹅、40%梦想、10%零花（钱钱1-7）
- **投资三原则** — 安全、下"金蛋"（收益）、简单明了（钱钱1-14）
- **投资俱乐部（金钱魔法师）** — 集体储蓄投资、共同决策（钱钱1-14）
- **股票基金** — 买多只股票分散风险，选大型跨国基金+10年走势（钱钱1-16）
- **复利（利滚利）** — 收益再投资产生更多收益，时间越长越显著（钱钱1-16）
- **甜甜圈理论** — 外圈金钱、内圈品格；品格是核心（钱钱2）
- **白色石头** — 象征独特本质/使命，成长=成为真实的自己（钱钱2）
- **7条准则** — 友好亲和、勇于承担、善待他人、帮助给予、感恩之心、勤学不辍、值得信赖（钱钱2-10）
- **巨人 vs 侏儒** — 内心两种声音：信守计划的是巨人，引诱打破的是侏儒（钱钱2-10）
- **演讲3件事** — 讲真实经历、鼓舞行动、聚焦少数人消除紧张（钱钱2-10）
- **榜样法** — 不确定如何守准则时，想榜样会怎么做（钱钱2-10）
- **橘子例子** — 橘子的回答只与其自身有关，不取决于外在；勇于承担（钱钱2-10）
