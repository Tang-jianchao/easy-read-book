# 钱钱2·11~14章：演讲比赛、事件、回家、道别（实践与成长）

## Core Idea
**实践**是品格与能力的试金石。吉娅把7条准则与演讲技巧用于真实的演讲比赛，并在关键时刻（事件）运用所学帮助他人（安娜）。**把学到的转化为行动**，品格与财富都随之成长。

## Frameworks Introduced
- **演讲比赛实践**：把"讲真实经历+鼓舞行动+聚焦少数人"的演讲技巧用于实战；紧张时靠成功日记与练习化解。
- **助人的事件**：运用7条准则（帮助给予、值得信赖）与资源（金先生的帮助、放大镜发现药方线索）帮助病危的安娜——品格在助人中兑现。
- **成长的完成**：回家、道别——历练后带着成长回归，品格与理财都更成熟。

## Key Concepts
- **知行合一**：准则不是背诵，而是在真实挑战中践行（演讲、助人）。
- **帮助他人是准则的落脚点**：帮助给予、值得信赖等准则通过具体助人行为体现并深化。
- **练习的力量**：演讲要反复练习，真诚的内容也需打磨。

## Mental Models
- "品格在行动中兑现"：7条准则靠真实行动而非空谈。
- "练习让真诚更强大"：真实经历+反复练习。

## Anti-patterns
- 只学不练，准则停留在纸面。
- 关键时刻退缩，放弃帮助他人或践行承诺。
- 演讲只求技巧完美，不讲真实经历。

## Worked Example
演讲比赛：吉娅用"讲真实经历+鼓舞行动"替代追求完美技巧，练习时聚焦喜欢的人消除紧张；同时在"事件"中用放大镜发现药方线索、联合金先生与朋友们帮助安娜——践行帮助给予与值得信赖，品格在助人中成长。

## Key Takeaways
1. 把学到的准则与技巧用于真实行动。
2. 演讲比赛：真实经历+鼓舞行动+聚焦少数人。
3. 帮助他人是品格准则的落脚点。
4. 反复练习让真诚内容更有力。
5. 历练后带着成长回归（回家/道别）。
