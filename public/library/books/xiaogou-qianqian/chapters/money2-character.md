# 钱钱2·1~7章：奖学金、白色石头、放大镜、论文、加利福尼亚、寄宿学校、好老师（品格启蒙）

## Core Idea
钱钱2转向**品格教育**。核心是**甜甜圈理论**：金钱（外圈）很重要，但品格（内圈）才是核心——没有内圈，外圈只是空洞。故事通过吉娅在寄宿学校的学习与"白色石头"的追寻，引入品格修炼。

## Frameworks Introduced
- **甜甜圈理论**：甜甜圈外圈=金钱/外在（理财），内圈=品格/内在（核心）。二者都要，但品格更根本。
- **白色石头**：象征每个人独特的本质/使命/内在价值——人成长的目标是"找到属于自己的白色石头"（成为真实的自己，见《少有人走的路》个体化呼应）。
- **寄宿学校的历练**：离开舒适区、面对陌生环境与挑战，是品格成长的契机。
- **好老师的引导**：通过对话、故事、7条准则卡片，引导品格修炼。

## Key Concepts
- **品格是核心**：没有内圈（品格），外圈（金钱）只是空洞——理财要建立在好品格上。
- **寻找白色石头**：每个生命有独特本质，成长=发现并成为真实的自己。
- **逆境促进品格**：陌生的寄宿学校、冲突（如平头男生挑衅）是修炼品格的道场。

## Mental Models
- "甜甜圈：外圈金钱，内圈品格"：品格是核心，金钱围绕它。
- "白色石头=独特使命"：人应成为真实的自己。

## Anti-patterns
- 只重金钱（外圈）而忽略品格（内圈），内圈空洞。
- 逃避陌生/逆境，拒绝品格历练。
- 丢失"白色石头"，成为他人期待而非真实的自己。

## Worked Example
吉娅到寄宿学校：离开家面对陌生环境与挑战（奖学金、论文、与同学冲突如平头男生）——这是品格修炼场。在好老师引导下学甜甜圈理论，并决心寻找属于自己的"白色石头"（真实独特自我），开始7条准则的修炼。

## Key Takeaways
1. 甜甜圈理论：外圈金钱，内圈品格是核心。
2. 品格修炼比金钱更根本。
3. 白色石头=独特本质，成长=成为真实自己。
4. 逆境/陌生是品格历练的契机。
5. 好老师的引导+故事+准则卡片促品格成长。
