# 钱钱2·8~10章：危险、好老师的秘密、7条准则（核心）

## Core Idea
钱钱2的核心章节：**7条准则**（品格修炼）与**演讲技巧**。7条准则构成甜甜圈的内圈：友好亲和、勇于承担、善待他人、帮助给予、感恩之心、勤学不辍、值得信赖。演讲的本质是讲真实经历、鼓舞行动、消除紧张。

## Frameworks Introduced
- **7条准则**：
  1. **友好亲和**：愿他人生活美好幸福；不伤害任何人、不介入争端（"愤怒和仇恨，我们不接受就仍属对方"）；谦虚有礼、尊重他人、承认并非永远正确。**友好的力量比暴力更强大**。
  2. **勇于承担**：遇事自我抉择；不受不公平影响，专注能做/知道/拥有的；**把责任推给别人=把权利也交给对方**（橘子例子：橘子的回答只与其自身有关）。
  3. **善待他人**：只称赞他人，无法称赞就不说；尽量不批评，不得不批评用礼貌友善方式；聚焦他人优点闪光点（"当你只看到光明，你就会成为光明"）。
  4. **帮助给予**：祝愿所有人顺利；送礼物表达好感；最美好之事是帮助他人（"帮助他人能给自己带来快乐"）。
  5. **感恩之心**：对看似寻常的事心怀感恩；困难中也关注值得感激之物（"幸福之人的秘密=有能力辨别奇迹发生的时刻并感激"）。
  6. **勤学不辍**：骄傲自满=不必再学；阅读好书、写成功日记/知识笔记、向他人学习；不与他人比较，尽己所能做到最好（"只要坚持不懈地学习，生活就总是多姿多彩"）。
  7. **值得信赖**：成功取决于自身习惯；自律者比天赋懒惰者更成功；守时、信守承诺（**巨人vs侏儒**：信守计划/承诺的是巨人，引诱打破的是侏儒，让巨人获胜）。
- **演讲3件事（安娜）**：①讲心里真实存在的东西（真实经历，听众才亲近）②要求听众做具体的事（不能鼓舞行动的演讲浪费时间）③忘记很多人，只聚焦两三个喜欢的人（消除紧张）。
- **使用榜样法**：不确定如何守准则时，想心中的榜样"如果是他/她，会怎么做"，回到正轨。

## Key Concepts
- **品格是内圈核心**：7条准则修炼品格，让外圈（金钱）有坚实的核心。
- **巨人vs侏儒**：内心两种声音——侏儒引诱打破计划，巨人要求信守承诺；让巨人获胜才能成为有能力成为的人。
- **不与比较、尽己所能**：勤学不辍的核心是不与他人比，做到最好的自己。

## Mental Models
- "7条准则=内圈"：品格修炼是甜甜圈的核心。
- "巨人vs侏儒"：信守承诺与自律，让巨人获胜。
- "榜样法"：用榜样的视角校正自己的准则。

## Anti-patterns
- 介入争端、批评他人、只盯缺点（违背善待/友好）。
- 推卸责任（=交出权利）；骄傲自满（=停止成长）。
- 忘记承诺、不自律（侏儒获胜）。

## Worked Example
每周一个主题修炼（周一友好亲和、周二勇于承担……）：遇冲突（如平头男生挑衅）——友好比暴力更有力（老学者的故事：不接受愤怒，它就仍属对方）；把责任推给别人=把权利交给对方（橘子例子）——因此遇事自我抉择、专注自己能做的。

## Key Takeaways
1. 7条准则：友好亲和、勇于承担、善待他人、帮助给予、感恩之心、勤学不辍、值得信赖。
2. 品格是甜甜圈内圈，比金钱更核心。
3. 巨人vs侏儒：信守承诺，让巨人获胜。
4. 演讲=讲真实经历+鼓舞行动+聚焦少数人消除紧张。
5. 用榜样法校正自己的准则。
