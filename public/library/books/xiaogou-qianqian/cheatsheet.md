# 速查表 Cheatsheet

> 理财+品格决策指南，帮助你在钱与人生上像《小狗钱钱》一样行动。以一页为限。

## 理财核心流程

1. **想清楚** → 写10个愿望，选最重要目标。
2. **看得见** → 梦想储蓄罐（专款）+梦想相册（天天看）。
3. **有信心** → 每天写5件成功的事（成功日记）。
4. **挣得到** → 为别人解决难题 + 专注自己能做/知道/拥有的。
5. **分得清** → 收入分配：如50%养鹅（储蓄）、40%梦想、10%零花。
6. **守得住** → 别杀鹅（保本金），只花利息（金蛋）。
7. **投得好** → 三原则：安全、收益、简单；选大型跨国基金+10年走势；用不急用的钱长期持有。

## 债务4忠告速查

| 忠告 | 动作 |
|---|---|
| 1 | 毁掉信用卡 |
| 2 | 按最低分期付款 |
| 3 | 剩下一半存起来、一半还消费贷（最好不借） |
| 4 | 花钱前问"这真的有必要吗？" |

## 7条准则速查（品格=甜甜圈内圈）

| # | 准则 | 要点 |
|---|---|---|
| 1 | 友好亲和 | 不介入争端、谦虚尊重（愤怒不接受就仍属对方） |
| 2 | 勇于承担 | 自我抉择，推责=交权（橘子例子） |
| 3 | 善待他人 | 只称赞、不批评、看闪光点 |
| 4 | 帮助给予 | 帮助他人最快乐 |
| 5 | 感恩之心 | 寻常事也感恩，困难中找值得感激 |
| 6 | 勤学不辍 | 谦恭好学、向他人学、不与别人比 |
| 7 | 值得信赖 | 自律守时信诺，让巨人获胜 |

## 关键信号（Tells）

| 信号 | 判断 |
|---|---|
| 想挣钱但没目标/没自信 | 先写愿望清单+成功日记 |
| 靠信用卡/消费贷买非必要物 | 走债务4忠告 |
| 收入增长支出同步涨 | 未量入为出，需合理分配 |
| 想花光本金满足愿望 | 在"杀鹅"，应只花利息 |
| 行情下跌就恐慌割肉 | 用不急用的钱+长期持有 |
| 重钱轻品格 | 甜甜圈外圈空心，补内圈 |

## 全书一句话(Bottom Line)

> 理财的起点是明确目标（愿望清单→储蓄罐→相册）与自信（成功日记），挣钱靠为别人解决难题、专注自己所能；量入为出、按债务4忠告处理债务，把收入分成"养鹅（本金）+梦想+零花"，绝不杀鹅——用投资三原则（安全、收益、简单）选大型跨国基金长期持有，靠复利滚雪球。而这一切要建立在品格（甜甜圈内圈）之上：7条准则——友好亲和、勇于承担、善待他人、帮助给予、感恩之心、勤学不辍、值得信赖，让巨人获胜、信守承诺——有了坚实的品格核心，外圈的财富才不会空洞。
