# 第18章：六功 爆发跳跃、爆发俯卧撑、打挺、前翻、后翻、上杠

> 覆盖《囚徒爆发力》原书第4–9章：六条爆发力/技巧技艺链。

## Core Idea
六功是六条十式技艺链，分别训练下肢弹跳、上肢弹推、仰卧起身、向前翻转、向后翻转与杠上翻越。基础链（爆发跳跃、爆发俯卧撑）打造“燃料”，技巧链（打挺、前翻、后翻、上杠）把燃料变成实用速度与敏捷。

## Frameworks Introduced
- **爆发跳跃十式**：直蹦 → 深蹲跳 → 直跳 → 助跑跳 → 踢臀跳 → 拍膝团身跳 → 团身跳 → 抱腿团身跳 → 穿针跳 → 自杀跳。
  - 五个技术：起跳（髋引导、对称）、团身（膝上拉）、落地（屈髋屈膝缓冲）、牵张回弹（不停顿）、立停（水平转动量转垂直）。
- **爆发俯卧撑十式**：上斜俯卧弹 → 跪姿俯卧弹 → 俯卧弹 → 拍掌俯卧撑 → 拍胸俯卧撑 → 拍髋俯卧撑 → 囚徒俯卧撑 → 半飞人俯卧撑 → 全身俯卧弹 → 飞人俯卧撑。
  - 要点：手距略宽于肩、手掌平放、身体绷直、只下降约 1/3、靠牵张回弹而非主动“跳”。
- **打挺十式**：卷体起坐 → 卷体蹲起 → 肩上弹 → 桥打挺 → 坐打挺 → 半打挺 → 经典打挺 → 直腿打挺 → 武术打挺 → 鲤鱼打挺。
  - 三步：卷起（膝近头）、踢腿（向上而非向下）、翻转（手推+髋爆发）。
- **前翻十式**：肩滚 → 手滚 → 跳跃滚 → 倒立滚 → 背落前手翻 → 前手翻 → 鱼跃前手翻 → 背落前空翻 → 助跑前空翻 → 站立前空翻。
  - 五段：助跑、起跳、团身、打开、落地。
- **后翻十式**：后向肩滚 → 后向手滚 → 桥踢翻 → 猴子侧翻转 → 猴子后翻转 → 猴子翻转 → 后手翻 → 单臂后手翻 → 四点后空翻 → 站立后空翻。
  - 前置：桥、倒立/倒立撑、跳跃落地；关键仍是团身与落地。
- **上杠十式**：摆动晃身 → 跳跃引体向上 → 晃身引体向上 → 引体向上跳 → 拍掌引体向上 → 拉至胸部 → 拉至髋部 → 跳跃上翻 → 单杠上翻 → 双立臂。
  - 四阶段：晃、拉、翻、撑；使用虚握（无拇指）便于转腕。

## Key Concepts
- **团身**：把膝拉向胸，缩小转动惯量、提高角速度；所有空翻的核心。
- **牵张回弹**：利用肌腱弹性与牵张反射；落地后不停顿，立刻弹起。
- **立停**：把水平惯性转为垂直惯性；助跑跳与前空翻的枢纽。
- **虚握（false grip）**：上杠时不用拇指，让手腕能转到杠上，撑起时受力面积更大。
- **基础链是燃料**：爆发跳跃与爆发俯卧撑要终生练，持续提高高度/速度，而不是“通关”后丢弃。
- **技巧链是软件**：打挺、前翻、后翻、上杠靠神经系统学习，需高频、低疲劳、完美重复。

## Mental Models
- **“燃料箱与赛车”**：基础爆发动作是燃料，技巧动作是赛车；没有燃料，技巧训练白费。
- **“先跳得高，再翻得动”**：空翻的高度来自腿与髋的爆发；不要用技巧掩盖力量不足。
- **“团身是加速器”**：转得越快，越能及时以脚落地。
- **“落地是动作的一半”**：不会落地，就不算掌握空翻。

## Anti-patterns
- **跳级练空翻**：没练翻滚、后手翻、桥与落地，直接冲后空翻。
- **只练技巧不练基础**：爆发跳跃/俯卧撑停滞，空翻高度不足。
- **用手臂硬撑**：上杠的“撑”是纯力量，但前面的晃、拉、翻才是省力关键。
- **爆发俯卧撑塌腰/撅臀**：用“毛毛虫”借力，失去爆发力训练意义。
- **落地直腿**：膝踝承受冲击，易伤。
- **把六功当有氧**：高次数、短休息，练成耐力而非爆发。

## Worked Example
一个能做标准俯卧撑、深蹲但不会空翻的人，先练爆发跳跃：直蹦 → 深蹲跳 → 直跳 → 助跑跳 → 团身跳，建立起跳、团身、落地与牵张回弹；同时练爆发俯卧撑，从墙壁/上斜俯卧弹到拍掌俯卧撑。基础链达到第五式后，开始打挺：卷体起坐 → 桥上弹 → 坐打挺 → 经典打挺；再把打挺的髋爆发迁移到前翻的翻滚与鱼跃前手翻。整个路径以“月”为单位，每次只练少量高质量次数，不追求当天学会空翻。

## Key Takeaways
1. 六功 = 两条基础链 + 四条技巧链。
2. 爆发跳跃与爆发俯卧撑是终生燃料，不是通关任务。
3. 团身、落地、牵张回弹是空翻的三大技术。
4. 上杠四阶段：晃、拉、翻、撑；虚握是关键。
5. 技巧链靠高频、低疲劳、完美重复。
6. 先有基础爆发力，再练高难技巧。
