# 第16章：起居、饮食、疗伤与心灵

> 覆盖《囚徒健身2》原书第18–22章：起居有时、狱中饮食、疗伤八法、心灵、监狱里的健身房。

## Core Idea
训练只占一天 4%，其余 96% 决定成败：睡眠、饮食、伤病处理与心理状态。作者用监狱生活说明，纪律与规律比天赋更能累积成果；所谓“监狱健身房神话”，大多与事实相反。

## Frameworks Introduced
- **疗伤八法**：
  1. 自我保护（先不受伤）
  2. 及时治疗
  3. 坚持锻炼没有受伤的部位
  4. 锻炼受伤部位（在无痛范围内）
  5. 热疗
  6. 循序渐进
  7. 信心十足
  8. 疗伤是个学习的过程
- **训练中的六个恶魔**：自卑、泄气、痛苦、衰老、没兴趣、没有时间。
  - How: 识别它 → 用长期视角与具体行动反驳 → 不把情绪当成事实。
- **监狱健身房四神话**：
  1. 所有监狱都有健身房；
  2. 监狱健身房让人变得更大更强；
  3. 所有囚犯都整天举重、肌肉畸形；
  4. 囚犯无所事事只能举重。
  - 事实：多数监狱器械少、杠铃片焊死、空间拥挤；真正让囚徒变强的是自身体重训练。

## Key Concepts
- **休息**：恢复的第一要素，高于营养与补剂；睡眠不足会直接拖垮力量与情绪。
- **规律**：固定起床、训练、吃饭、睡觉时间；减少决策消耗，形成训练惯性。
- **一日三餐**：监狱饮食普通，但足以支撑训练；关键是总量、蛋白质与不暴食。
- **补剂**：非必需；作者更看重睡眠、饮食与训练质量。
- **疼痛与训练**：急性期先保护与治疗；随后在无痛范围内活动受伤部位，促进血流；不要完全静止。
- **心理恶魔**：负面自我对话会削弱训练执行；识别、挑战、用行动覆盖。
- **监狱现实**：器械稀缺、自由重量受限；自重训练才是囚徒力量的主要来源。

## Mental Models
- **“4% 训练，96% 生活”**：训练是扳机，恢复与生活方式是弹药。
- **“纪律释放天赋”**：固定作息让普通人持续进步，也让天赋不被浪费。
- **“受伤后不是停，而是换”**：不能练的动作先停，能练的部位继续；完全静止反而恢复更慢。
- **“情绪是天气，不是气候”**：六个恶魔会来，但不代表事实；用记录与行动穿过它们。

## Anti-patterns
- **熬夜+高强度**：恢复不足，力量下降、情绪恶化、受伤率上升。
- **暴食/依赖补剂**：热量过剩、体脂上升；补剂替代不了睡眠与饮食。
- **受伤后硬练或完全躺平**：硬练加重损伤，躺平延长恢复；应无痛活动+循序渐进。
- **被“没时间”说服**：把训练排进日程，而不是等有空。
- **相信监狱健身房神话**：误以为器械与药物是囚徒强大的原因，忽略自重训练传统。
- **把疼痛当意志考验**：疼痛是信息，不是勋章。

## Worked Example
作者在狱中多次受伤：鼻梁骨折、肋骨骨折、膝盖脱臼、韧带撕裂等。他的处理不是停练，而是：先确认伤情、保护伤处；不能练的动作暂停；用无痛范围的活动与热疗促进恢复；能练的部位照常训练；恢复期以低阶动作重建，逐步回到原强度。与此同时，他保持固定作息、三餐、充足睡眠，并用训练日记记录微小进步。结果是在高墙内仍能长期训练，且很少因训练本身受伤。作者把这套经验压缩为“疗伤八法”，并强调：它不是医学替代，而是训练者在受伤后继续前进的常识。

## Key Takeaways
1. 睡眠与规律是恢复的第一要素。
2. 一日三餐、总量适中即可，不必依赖补剂。
3. 疗伤八法：保护、治疗、练未伤处、无痛活动伤处、热疗、渐进、信心、学习。
4. 六个心理恶魔要靠识别与行动穿过。
5. 监狱健身房神话掩盖了自重训练的真正价值。
6. 训练只占 4%，生活方式决定另外 96%。
