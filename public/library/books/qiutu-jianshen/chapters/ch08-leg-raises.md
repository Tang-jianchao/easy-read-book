# 第8章：魔鬼六块 举腿

## Core Idea
腹肌不是靠卷腹“雕”出来的，而是靠举腿一类全身性动作练出来的厚实中段。举腿比仰卧起坐更自然、调用肌肉更多，还能同时练握力、背阔肌、肩部与髋部；按十式渐进，最终能完成悬垂直举腿。

## Frameworks Introduced
- **举腿十式**：
  1. 坐姿屈膝
  2. 平卧抬膝
  3. 平卧屈举腿
  4. 平卧蛙举腿
  5. 平卧直举腿
  6. 悬垂屈膝
  7. 悬垂屈举腿
  8. 悬垂蛙举腿
  9. 悬垂半举腿
  10. 悬垂直举腿（最终式）
- **地面四式 → 悬垂六式**：先在地面建立骨盆控制与腹肌发力，再进入悬垂，逐步增加力臂与稳定需求。
- **“魔鬼六块”标准**：不是纤细的模特腹肌，而是厚实、强硬、能传力、能保护内脏、能承受冲击的中段。

## Key Concepts
- **腹直肌**：从胸骨到骨盆是一整块，不能“上腹”“下腹”分开练；动作只是改变力矩。
- **腹横肌**：腰部深层“紧身衣”，负责稳定内脏与躯干；举腿时主动收腹能训练它。
- **骨盆后倾**：举腿不是单纯抬腿，而是让骨盆向上卷、腹肌缩短。
- **呼吸**：放下双腿时吸气，举到最高点呼气；必要时组间多喘几口气。
- **悬垂的额外收益**：握力、背阔肌、肩部稳定、前锯肌与股四头肌深层都被调用。
- **体脂与清晰度**：腹肌清晰取决于全身精瘦度，不能靠局部高次数“减肚子”。

作者对悬垂直举腿的评价很高：它是狱中腰部练习之王，但并非越难越好；能完成 30 个完美重复，已足以让中段力量超过绝大多数训练者。所有全身动作（俯卧撑、深蹲、桥）都会调用中段，因此不必把腹肌训练无限加码。如果目标是清晰腹肌，训练只解决“厚度”，饮食与体脂才解决“看得见”；局部高次数不能定点减脂。训练前先拉伸腘绳肌，能明显改善直腿举腿的动作质量。

## Mental Models
- **“中段是传力链，不是展示面”**：腹肌负责把下肢力量传到上身，跑步、跳跃、踢腿都依赖它。
- **“先控制骨盆，再抬起双腿”**：骨盆不稳，腿抬得再高也是髋屈肌代偿。
- **“悬垂是考试的放大镜”**：地面动作的弱点，到悬垂阶段会暴露为摆动、塌腰或握力不足。
- **“腹肌与下背是一对”**：只练腹不练桥，会造成前后失衡与腰痛。

## Anti-patterns
- **卷腹崇拜**：只做卷腹、反向卷腹、侧卷腹，练不到厚实中段与传力能力。
- **靠摆动借力**：最低点用惯性甩腿，腹肌没发力，腰椎受压。
- **只练腹不练背**：腹强背弱，容易出现下背痛；应同时练桥与深蹲。
- **饭后立刻练**：至少间隔两小时，否则腹胀影响动作。
- **用高次数代替升级**：腹肌耐力上去了，力量与厚度没变化。
- **局部减脂幻想**：狂做举腿不会单独减掉腹部脂肪。

## Worked Example
从坐姿屈膝到悬垂直举腿的路径：坐姿屈膝让初学者在坐姿中体验骨盆后倾与腹肌缩短；平卧抬膝、平卧屈举腿、平卧蛙举腿逐步增加腿的力臂与动作幅度；平卧直举腿要求腿伸直、下背贴地；进入悬垂后，从悬垂屈膝开始，经过屈举腿、蛙举腿、半举腿，最后到双腿伸直、与地面平行的悬垂直举腿。作者提醒：如果直腿举腿很难，往往是腘绳肌过紧；训练前先拉伸腘绳肌，动作会顺畅很多。

## Key Takeaways
1. 举腿是比仰卧起坐更好的中段训练。
2. 十式从地面到悬垂，逐步增加力臂与稳定需求。
3. 骨盆后倾、不摆动、呼吸配合，是动作质量的核心。
4. 腹肌清晰靠全身减脂，不靠局部高次数。
5. 腹与背要平衡训练，桥与深蹲不可缺席。
