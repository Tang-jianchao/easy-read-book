# 第14章：侧身肌肉链、颈部与小腿 被忽略的三处

> 覆盖《囚徒健身2》原书第7–11章：顺风旗、抓旗基础八式、扬旗进阶八式、颈部、小腿。

## Core Idea
身体是三维的：除了前链与后链，还有常被忽略的侧链；颈部与小腿则是“小肌肉、大收益”的典型。三者都不能靠孤立器械练好，而要用自身体重、全动作幅度与渐进升级。

## Frameworks Introduced
- **抓旗基础八式**：
  1. 悬吊抓
  2. 单蜷腿斜身抓
  3. 双蜷腿斜身抓
  4. 斜身抓
  5. 双蜷腿水平抓
  6. 单蜷腿水平抓
  7. 屈腿抓旗
  8. 抓旗
- **扬旗进阶八式**：
  1. 支撑推举
  2. 推举悬吊
  3. 蹬地推举
  4. 蜷腿竖直推举
  5. 竖直推举
  6. 单蜷腿扬旗
  7. 屈腿扬旗
  8. 扬旗
- **抓握方式**：垂直抓握（上下手正反握直杆）、水平抓握（一高一低横杠）、双人抓握（抓同伴手臂）。
- **颈部两式**：正颈桥、反颈桥；摔跤传统，前后左右全面强化。
- **小腿“加码”**：动作幅度（地面/台阶）、双腿/单腿、膝盖伸直/弯曲。

## Key Concepts
- **侧链**：阔筋膜张肌、腹斜肌、前锯肌、肋间肌、背阔肌；投掷、转身、单臂支撑都依赖它。
- **旗类动作的价值**：身体保持直线承受侧向力矩，比负重体侧屈更安全，也更考验协调。
- **颈部**：颈椎支撑颅骨；强壮颈部是头部“减震器”，降低冲击与慢性疼痛风险。
- **颈桥**：用肩与手臂承重，不把体重压在头顶；从低幅度、短时间开始。
- **小腿**：力量从腰髋经双脚传地；小腿弱则跑跳、推车、爬楼都受限。
- **提踵进阶**：双腿地面 → 单腿地面 → 双腿台阶 → 单腿台阶；再过渡到屈膝版本（偏重比目鱼肌）。

颈部训练从短时间、低幅度开始，出现头晕或麻木立即停止；小腿则以 2–3 组、每组 15–20 次为常规，逐步加幅度与单侧化，不必追求大重量。

## Mental Models
- **“身体是三维的”**：只练前后链，侧链就是薄弱环节；搬抬不对称物体时最明显。
- **“小肌肉，大杠杆”**：颈与小腿体积小，却决定冲击承受与地面传力。
- **“用姿势加难度”**：旗类靠身体角度与单侧化；小腿靠幅度、单双侧与膝角度。
- **“先直线，再力矩”**：旗类必须保持身体一条直线；弯曲躯干就变成作弊。

## Anti-patterns
- **侧卷腹/绳索转体**：孤立、低阻力，练不到侧链的传力能力。
- **害怕腰变粗**：自然训练不会把腰练粗；腰粗来自肥胖与药物。
- **颈部挂重物/颈带**：易引起头痛与慢性颈痛；颈桥更自然。
- **只做站姿器械提踵**：幅度小、膝角度单一；自身体重提踵更全面。
- **旗类塌腰/屈髋**：失去直线，压力转到腰椎。
- **跳过抓握**：旗与扬旗都要求极强握力，握不住就无法练。

## Worked Example
一个想练扬旗但握力不足的人，先做悬吊抓与单蜷腿斜身抓，建立基础拉力与侧链张力；再逐步到斜身抓、水平抓、屈腿抓旗，最后抓旗。与此同时，他用垂直抓握在路灯杆上练习，双手一正一反；每次只练 3–5 组，组间充分休息。颈部则从正颈桥的短时间保持开始，逐步增加幅度与时间；小腿用单腿台阶提踵，从 2 组×15 次逐步加到 3 组×20 次。作者提醒：这三处都属“小组织”，进步以月计，不能按大肌群的节奏催。

## Key Takeaways
1. 侧链、颈部、小腿是全身力量的薄弱环节。
2. 旗类用基础八式→进阶八式渐进，身体保持直线。
3. 颈部用正/反颈桥，不用颈带挂重物。
4. 小腿用幅度、单双侧、膝角度三个“加码”渐进。
5. 小肌肉恢复慢，频率与组数都要克制。
6. 抓握是旗类动作的前置条件。
