# 第6章：升降机般的大腿 深蹲

## Core Idea
真正的力量源于髋部与腿部。深蹲同时弯曲髋、膝、踝三个关节，用动作把下肢所有肌肉作为一个整体训练；自身体重深蹲不把大重量压在脊柱上，能以更安全的方式一路升级到单腿深蹲。

## Frameworks Introduced
- **深蹲十式**：
  1. 肩倒立深蹲
  2. 折刀深蹲
  3. 支撑深蹲
  4. 半深蹲
  5. 标准深蹲
  6. 窄距深蹲
  7. 偏重深蹲
  8. 单腿半深蹲
  9. 单腿辅助深蹲
  10. 单腿深蹲（最终式）
- **三关节协同**：髋、膝、踝必须同时弯曲；只屈膝会向后倒。
- **全幅度原则**：完整深蹲让股四头肌四块都参与，并拉伸小腿与跟腱。
- **单侧化升级**：从双腿到偏重，再到单腿半蹲、辅助单腿蹲、单腿蹲。

## Key Concepts
- **力量的源泉在下半身**：挺举、硬拉、卧推的发力都依赖腿与髋；腿弱则全身弱。
- **伦巴德悖论**：深蹲时股四头肌与腘绳肌同时强力收缩，说明深蹲能练整条大腿。
- **髋主导**：下蹲时像“向后坐”，不是弯腰；上身略前倾以平衡。
- **膝盖轨迹**：膝盖跟随脚尖方向，不内扣；脚跟尽量不离地。
- **核心与脊柱**：深蹲时腹横肌、腹肌、竖脊肌共同稳定躯干。
- **踝关节活动度**：踝背屈不足会让脚跟抬起或上身过度前倾。

深蹲的常见变式包括深蹲跳、跳箱、手枪深蹲与虾式深蹲；它们可以作为爆发力或增肌的补充，但不能替代十式的渐进。膝盖有旧伤的人应先做肩倒立深蹲、折刀深蹲与支撑深蹲，确认无痛后再增加幅度；全幅度深蹲不会“毁膝盖”，错误负荷与突然加量才会。

另一个关键是脚跟：如果脚跟离地，说明踝背屈不足或重心前移；可先做小腿与踝的活动度练习，或在脚跟下垫小片，但不要把垫高当成永久解决方案。深蹲的呼吸也重要：下蹲吸气、起身呼气，核心保持紧张，避免憋气导致血压骤升。

## Mental Models
- **“腿有多老，人就有多老”**：下肢爆发力最先流失，也最值得长期投资。
- **“深蹲是全身动作，不是腿部孤立动作”**：它同时练髋、腿、脊柱、核心与踝。
- **“用动作幅度加难度，不用杠铃加难度”**：从半蹲到全蹲、从双腿到单腿，都是渐进。
- **“膝盖不是敌人，错误负荷才是”**：循序渐进的全幅度深蹲能强化膝关节，而非毁掉它。

## Anti-patterns
- **半蹲当标准**：只下一点就起身，股四头肌与髋部都没练到。
- **膝盖内扣**：下蹲或起身时膝向内塌，增加韧带压力。
- **脚跟离地**：踝活动度不足或重心前移，导致膝盖前压力过大。
- **弯腰代偿**：髋不会动，用腰把身体“折”下去。
- **弹震起身**：在底部反弹借力，跳过最难的发力段。
- **只练腿屈伸/腿弯举**：孤立器械把腿部肌肉拆开，破坏协同。

## Worked Example
从肩倒立深蹲到标准深蹲的路径：肩倒立深蹲让初学者在支撑下体验髋膝踝同时弯曲；折刀深蹲用椅子或床沿辅助，降低平衡要求；支撑深蹲借物体分担部分体重；半深蹲逐步增加幅度；最后到标准深蹲。之后通过窄距、偏重、单腿半蹲、单腿辅助，最终完成单腿深蹲。作者强调：单腿深蹲要求膝盖与髋部在完整幅度内稳定，任何一步跳过，都会在单腿阶段暴露为疼痛或失衡。

## Key Takeaways
1. 腿部是全身力量的发动机。
2. 深蹲必须三关节同时动，脚跟稳定、膝盖跟随脚尖。
3. 自身体重深蹲对脊柱更友好，适合长期练。
4. 十式从双腿到单腿，逐步提高单侧力量与平衡。
5. 全幅度、慢速、无弹震，是深蹲质量的核心。
