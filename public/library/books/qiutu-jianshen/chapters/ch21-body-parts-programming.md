# 第21章：部位策略与训练计划的制订

> 覆盖《囚徒增肌》原书第3–4章：打造身体各部位、训练计划的制订。

## Core Idea
自重可以练到全身每个部位，关键是选对动作、用增肌的次数区间、并按“计划线”控制复杂度。新手用简单计划（少回数、少动作、多复合），进阶者再增加分化与孤立动作。

## Frameworks Introduced
- **部位—动作对应**：
  - 股四头肌：深蹲、单腿深蹲、虾式深蹲、西斯深蹲。
  - 腘绳肌/臀：桥、单腿桥、髋伸动作、爆发跳跃。
  - 小腿：站姿提踵、深蹲提踵、单腿提踵；爆发跳收尾。
  - 胸：俯卧撑各变式（标准、偏重、单臂）。
  - 背：引体向上、水平引体向上、毛巾/吊环变式。
  - 肩：倒立撑、靠墙倒立撑、偏重倒立撑。
  - 肱二头肌：引体向上、反握引体、窄距引体。
  - 肱三头肌：窄距俯卧撑、屈臂撑、倒立撑。
  - 前臂/握力：悬吊、指尖俯卧撑、毛巾悬吊。
  - 腹：举腿各变式、直角式。
  - 颈：正颈桥、反颈桥。
- **计划线**：计划复杂度 = 每循环训练回数 × 每回动作种类数。
  - 低复杂度：回数少、动作少、多复合 → 新手。
  - 高复杂度：回数多、动作多、多孤立 → 进阶健美者。
- **增肌计划骨架**：全身 2–3 次/周，或上/下分化、推/拉/腿分化；每个动作热身后 2 组，每组 8–20 次。

## Key Concepts
- **动作选择**：优先能渐进、能高次数、能保持姿势的复合动作；技巧动作作为补充。
- **次数区间**：5–8 次偏力量与肌肉；12–20 次偏肌肉与耐力；增肌可覆盖 6–20 次。
- **渐进**：先加次数，再加难度（更难的变式）；不要只加组数。
- **分化**：训练回数增加时，用分化保证每个部位有恢复时间。
- **计划服务于恢复**：复杂度越高，越需要睡眠、饮食与休息支撑。

一个可直接执行的两周全身示例：周一深蹲+俯卧撑，周三引体+举腿，周五桥+倒立撑；每个动作热身后 2 组，记录次数，两周后按次数或难度渐进。

## Mental Models
- **“先复合，后孤立”**：复合动作打底，孤立动作补弱。
- **“计划线从左到右”**：新手在左端（简单），进阶再向右（复杂）；不要一开始就做健美冠军的计划。
- **“每个部位都有自重答案”**：没有“自重练不到小腿/脖子/前臂”这回事，只是动作选择问题。
- **“复杂度是成本”**：每增加一个动作/回数，都要用恢复来支付。

## Anti-patterns
- **只练镜子肌肉**：胸、臂、腹练得多，腿、背、颈、小腿欠账。
- **新手照搬高阶分化**：动作太多、回数太多，恢复不足。
- **只加动作不加次数**：训练量上去了，肌肉刺激没上去。
- **用技巧动作做增肌主课**：平衡先崩，肌肉没被逼到位。
- **忽略腿与后链**：上肢再强，整体力量与体型仍失衡。
- **计划过复杂**：无法坚持、无法判断进步。

## Worked Example
一个新手想增肌，作者给的计划是全身 3 次/周：深蹲、俯卧撑、引体向上（或水平引体）、举腿，每个动作热身后 2 组，每组 8–15 次，记录次数；两周后能轻松完成上限，就换更难变式或加次数。三个月后，加入桥与倒立撑，并开始上/下分化：上肢日（俯卧撑、引体、倒立撑）、下肢日（深蹲、桥、举腿），每个动作仍 2 组。计划线从简单逐步向右移，而不是一开始就推/拉/腿六分化。作者强调：计划不是魔法，执行、渐进与恢复才是。

## Key Takeaways
1. 每个部位都有对应的自重动作。
2. 增肌优先复合动作，孤立动作补弱。
3. 计划复杂度按“回数×动作数”控制，新手从简。
4. 每个动作热身后 2 组，6–20 次区间。
5. 渐进先加次数，再加难度。
6. 分化是为了恢复，不是为了显得专业。
