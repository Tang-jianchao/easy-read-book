# 第4章：关于本书 囚徒健身

## Core Idea
本书把老派体操压缩成一套可自我指导的系统：六类基本动作（六艺）× 每条十级难度（十式）× 明确的升级标准。训练者不需要教练，只需按表逐级推进，直到每条链的“最终式”。

## Frameworks Introduced
- **六艺**：俯卧撑、深蹲、引体向上、举腿、桥、倒立撑。
  - 覆盖推力、拉力、下肢、中段、脊柱、肩部，六类即可练全身。
  - When to use: 设计全身训练计划时，以六艺为骨架，不再添加孤立动作。
- **十式**：每艺细分为十级难度，第一式最易、第十式最难。
  - 每式含：动作描述、解析、训练目标（初级/中级/升级标准）、稳扎稳打、更上一层楼。
- **升级表**：每章末尾列出十式与升级条件，回答“何时可以进下一式”。
  - How: 达到该式升级标准 → 进入下一式；未达标 → 留在当前式提高次数或质量。
- **最终式**：每艺第十式；六艺共六个最终式。

## Key Concepts
- **六艺**：俯卧撑（胸、肩前束、肱三头肌）、深蹲（股四头肌、臀、腘绳肌、小腿）、引体向上（背阔肌、斜方肌、肱二头肌、握力）、举腿（腹直肌、腹斜肌、髋屈肌）、桥（竖脊肌、整条脊柱链）、倒立撑（三角肌、肩袖、肱三头肌）。
- **十式**：同一动作模式的难度梯度，不是十种无关动作。
- **升级标准**：可量化的组数×次数门槛，通常按初级、中级、升级三档。
- **稳扎稳打**：作者对常见失败点、退阶方法与安全边界的提示。
- **变式**：不属于十式、但可用于换花样、康复或补强的动作。
- **最终式**：单臂俯卧撑、单腿深蹲、单臂引体向上、悬垂直举腿、铁板桥、单臂倒立撑。

读升级表时先看“初级标准”，它决定你是否具备练这一式的资格；再看“升级标准”，它决定你何时离开。两者之间是积累次数与动作质量的区间。若长期卡在两者之间，优先改质量、加休息，而不是加组数。精英标准只出现在少数最终式，属于长期目标，不是升级门槛。

## Mental Models
- **“六艺是骨架，十式是楼梯”**：先确定练哪条链，再确定站在第几级。
- **“升级靠标准，不靠感觉”**：感觉良好不等于达标；用组数×次数与动作质量判定。
- **“每一式都是下一式的教练”**：低阶动作不是浪费时间，而是在给高阶动作存关节、肌腱与神经本钱。
- **“全身优先于局部”**：六艺互相补位；只练一艺会造成失衡。

## Anti-patterns
- **跳级**：直接从标准俯卧撑或标准引体向上开始，忽略前四式的组织适应。
- **只练强项**：胸、臂练得多，桥、举腿、倒立撑长期缺席。
- **把十式当全部**：十式是主干，变式与辅助练习只在明确目的下使用。
- **忽略升级表**：凭心情加难度，导致动作走形与伤病。

## Worked Example
六艺与最终式对应表：

| 动作类型 | 主要肌群 | 最终式 |
|---|---|---|
| 俯卧撑 | 胸、三角肌前束、肱三头肌 | 单臂俯卧撑 |
| 深蹲 | 股四头肌、臀、腘绳肌、小腿 | 单腿深蹲 |
| 引体向上 | 背阔肌、斜方肌、肱二头肌、握力 | 单臂引体向上 |
| 举腿 | 腹直肌、腹斜肌、髋屈肌 | 悬垂直举腿 |
| 桥 | 竖脊肌、整条脊柱链 | 铁板桥 |
| 倒立撑 | 三角肌、肩袖、肱三头肌 | 单臂倒立撑 |

作者的目标不是让读者记住六张表，而是让读者用这六张表做自己的教练：选式、达标、升级、记录、遇到停滞则退阶或巩固。

## Key Takeaways
1. 六艺覆盖全身，无需再堆孤立动作。
2. 十式是难度阶梯，升级必须达标。
3. 每式都有训练目标与安全提示，照表执行即可自我指导。
4. 最终式是方向，不是起点。
5. 变式是补充，不是主课。
