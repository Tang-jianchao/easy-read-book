# 第5章：铠甲般的胸肌与钢铁般的肱三头肌 俯卧撑

## Core Idea
俯卧撑是最好的上身推力练习：它同时练胸、肩前束、肱三头肌，并让推力肌群与腹部、下背、下肢协同工作。把它当高次数耐力练习是浪费；按十式渐进，它能练出不输卧推的力量，且更护肩肘。

## Frameworks Introduced
- **俯卧撑十式（难度阶梯）**：
  1. 墙壁俯卧撑
  2. 上斜俯卧撑
  3. 膝盖俯卧撑
  4. 半俯卧撑
  5. 标准俯卧撑
  6. 窄距俯卧撑
  7. 偏重俯卧撑
  8. 单臂半俯卧撑
  9. 杠杆俯卧撑
  10. 单臂俯卧撑（最终式）
- **训练目标三档**：每式设初级、中级、升级标准；达到升级标准才进下一式。
  - 例：第一式墙壁俯卧撑为初级 1 组×10 次、中级 2 组×25 次、升级 3 组×50 次。
  - 例：第十式单臂俯卧撑为初级 1 组×5 次（每侧）、中级 2 组×10 次（每侧）、精英 1 组×100 次（每侧）。
- **完美技巧优先于次数**：动作质量达标，次数才有意义。

## Key Concepts
- **一条直线**：躯干、髋部、双腿始终成直线；撅臀或塌腰说明核心锁定不足。
- **双腿并拢**：分开双腿会降低稳定需求，让动作变容易。
- **肘部管理**：肘部不要完全锁死；推起时保持微弯，避免关节不适。偏重与单臂变式对肩袖是极好的强化。
- **节奏 2-1-2**：2 秒下降、底部停 1 秒、2 秒推起；慢速消除惯性，让压力落在肌肉与关节上。
- **呼吸**：推起呼气、下降吸气；若憋气或不适，宁可多换几次气。
- **全幅度**：胸部接近地面（或支撑物），不要只做上半程。
- **快速变式**：击掌俯卧撑等弹震动作只作为进阶后的偶尔刺激，不是主课。
- **变式不是主课**：屈臂撑、下斜俯卧撑、击掌俯卧撑可用于换花样、康复或补强，但不能替代十式的渐进。

## Mental Models
- **“俯卧撑是移动的卧推”**：身体在空间中保持刚性，胸臂负责推，核心负责传力。
- **“难度靠杠杆，不靠加片”**：抬高脚、缩短支撑、单侧化、改变手距，都是在给身体加“可调重量”。
- **“肩袖是长期资产”**：偏重、不稳定支撑能强化肩袖；肘部外撇与大重量卧推则消耗它。
- **“每一式都在为下一式存本钱”**：低阶动作练的是关节、肌腱与动作模式，不是浪费时间。

## Anti-patterns
- **只追次数**：标准俯卧撑做几百次，却从不升级到窄距、偏重、单臂。
- **肘部外撇**：像卧推那样把肘部张到身体两侧，增加肩袖压力。
- **塌腰撅臀**：核心没锁住，腰椎代偿。
- **半程动作**：只下到一半就推起，胸肌与关节都没得到完整刺激。
- **跳级**：没练前四式就直接冲标准或单臂，结果动作走形、肩肘疼痛。
- **用惯性作弊**：靠腰部弹动或蹬地借力，次数上去了，力量没上去。

## Worked Example
从墙壁俯卧撑到标准俯卧撑的典型路径：墙壁俯卧撑达到 3 组×50 次 → 上斜俯卧撑（物体高度约身高一半）达到 3 组×40 次 → 膝盖俯卧撑 → 半俯卧撑 → 标准俯卧撑。作者强调，一个资质普通但耐心的人用约一年从第一式走到最终式；另一个跳过前四式、直接练标准俯卧撑的人，七周后就卡在偏重俯卧撑，连一次都做不了。差别不在天赋，而在是否为关节与肌腱留出适应时间。

## Key Takeaways
1. 俯卧撑是上身推力的核心动作，价值高于卧推。
2. 十式提供清晰的难度阶梯，按升级标准推进。
3. 身体成直线、双腿并拢、肘部不锁死，是三条底线。
4. 慢速 2-1-2 节奏优先于快速弹震。
5. 偏重与单臂变式能强化肩袖，但必须建立在前面几式之上。
