# 第17章：爆发力、实用速度与敏捷性的原则

> 覆盖《囚徒爆发力》原书第1–3章：对速度的需求、五大关键原则、核心概念与解答。

## Core Idea
爆发力不是“力量”的同义词，而是力量与速度的结合；实用速度是全身快速移动；敏捷性是高速中改变方向。现代器械、箱跳与奥林匹克举重各有所长，但只有爆发式体操能同时训练三者。

## Frameworks Introduced
- **三种素质定义**：
  - **爆发力**：有力量的快速移动（力量 × 速度）。
  - **实用速度**：整个身体快速移动。
  - **敏捷性**：在快速移动中改变方向。
- **五大关键原则**：
  1. 依靠自身体重；
  2. 斯巴达式训练（极简、随时可做）；
  3. 全身训练；
  4. 专注少数几类动作；
  5. 逐步升级。
- **六功 vs 六艺**：六艺（俯卧撑、深蹲、引体向上、举腿、桥、倒立撑）练慢速力量与肌肉；六功（爆发跳跃、爆发俯卧撑、打挺、前翻、后翻、上杠）练爆发力、实用速度与敏捷性。
- **前置条件**：开始爆发力训练前，六艺至少练到第五式；关节与软组织需要基础力量。

## Key Concepts
- **爆发力 ≠ 力量**：能撑住汽车需要力量，但不需要速度；能跳起翻转需要两者。
- **箱跳/路锥/奥举的局限**：箱跳缺方向变化；路锥缺负荷；奥举缺全身位移与敏捷。三者都不能单独练全三种素质。
- **爆发式体操的优势**：以体重为负荷、全身快速移动、在高速中改变方向（空翻、打挺、上杠）。
- **十式/最终式**：六功同样每条链十式，第十式为最终式；目标不是“做一次”，而是掌握。
- **从第一式开始**：即使有运动基础，也建议从第一式建立关节适应与身体智慧。
- **六功清单**：爆发跳跃、爆发俯卧撑、打挺、前翻、后翻、上杠；前两条是基础，后四条是技巧。前置的“第五式”指俯卧撑、深蹲、引体向上、桥、举腿各自至少到第五式，倒立撑可稍后；基础不足时先补六艺，不要用空翻“练胆”。

## Mental Models
- **“力量是马力，速度是转速”**：两者相乘才是爆发力；只练一边都不完整。
- **“硬件与软件”**：基础爆发动作练肌肉、肌腱、骨骼（硬件）；技巧动作练神经系统（软件）。
- **“用身体重量，不用外加重物”**：外重会拖慢速度，也增加关节压力。
- **“少数动作，长期升级”**：六功足够覆盖全身爆发力；花样越多，进步越难追踪。

## Anti-patterns
- **只做箱跳**：有爆发力与部分速度，但缺方向变化与敏捷。
- **只做路锥**：有敏捷与速度，但负荷太小，练不出爆发力。
- **只做奥举**：有爆发力，但身体几乎不位移，缺实用速度与敏捷。
- **没有力量基础就练空翻**：关节、肌腱未准备，受伤风险高。
- **追求花哨动作**：跳过基础跳跃与俯卧弹，直接练空翻。
- **把六艺与六功混为一谈**：慢速力量与快速爆发需要不同训练逻辑。

## Worked Example
作者用三个问题检验训练方法：是否需要力量+速度？是否全身快速移动？是否在高速中改变方向？箱跳：是、是、否；路锥：否、是、是；奥举：是、否、否；空翻/打挺/上杠：是、是、是。因此，若目标是“尽可能全面爆发”，应以六功为主，其他方法作为补充。作者并不否定箱跳、奥举或路锥，而是指出它们各自只覆盖一部分素质；选择取决于目标，而不是流行度。

## Key Takeaways
1. 爆发力 = 力量 × 速度，不等于力量。
2. 实用速度 = 全身快速移动；敏捷 = 高速变向。
3. 五大原则：自重、极简、全身、少而精、渐进。
4. 六功与六艺分工不同，不可互相替代。
5. 开始六功前，六艺至少到第五式。
6. 从第一式开始，给关节与神经系统适应时间。
