# 术语表

按拼音字母顺序排列。

- **爆发力** — 力量与速度的结合，即有力量地快速移动；不等于纯粹力量 (ch17)
- **爆发俯卧撑** — 以最快速度把身体推离地面的上肢爆发力动作链，共十式 (ch18)
- **爆发跳跃** — 以下肢弹跳为核心、训练起跳/团身/落地/牵张回弹的十式动作链 (ch18)
- **标准桥** — 手脚撑地、身体弯成弓形的桥，训练整条脊柱链的主动保护 (ch9)
- **侧链** — 身体侧面的肌肉链，包括腹斜肌、阔筋膜张肌、前锯肌、肋间肌等 (ch14)
- **复合动作** — 一次调动多个肌群、多个关节的动作，效率高且更自然 (ch20)
- **巩固训练** — 对只能做一两次的新动作，每天少量多次练习、每次留余力的方法 (ch11)
- **孤立动作** — 只针对单一肌群或单关节的动作，增肌效率低且易失衡 (ch20)
- **关节润滑** — 通过主动拉伸式让滑液循环、为无血流的软骨提供营养 (ch15)
- **核心** — 稳定躯干与髋部的深层肌肉群，包括腹横肌、腹斜肌、髋屈肌等 (ch8)
- **后链** — 身体背面的肌肉链，包括腘绳肌、臀肌、竖脊肌、小腿等 (ch15)
- **肌腱** — 连接肌肉与骨骼的结缔组织；其强度常比肌肉体积更决定实际力量 (ch1)
- **渐进/升级** — 按难度阶梯从第一式推进到第十式，而非只增加次数 (ch4)
- **紧张柔韧性** — 肌肉在被拉长或伸展时仍保持强力收缩的能力 (ch15)
- **静力练习** — 保持某一姿势不动、以时间计的训练，如悬吊、桥式、直角式 (ch13)
- **举腿** — 以腹肌与髋屈肌为主、从地面到悬垂共十式的核心动作链 (ch8)
- **拉力** — 把身体或外物拉向自己的力量，代表动作是引体向上 (ch4)
- **疗伤八法** — 作者总结的伤后训练常识：保护、治疗、练未伤处、无痛活动伤处、热疗、渐进、信心、学习 (ch16)
- **六功** — 爆发跳跃、爆发俯卧撑、打挺、前翻、后翻、上杠六条爆发力/技巧链 (ch17)
- **六艺** — 俯卧撑、深蹲、引体向上、举腿、桥、倒立撑六类基础力量动作 (ch4)
- **毛巾悬吊** — 用毛巾增加抓握厚度与全掌参与的悬吊变式，终极目标为单臂毛巾悬吊 (ch13)
- **魔鬼六块** — 作者对厚实、强硬、能传力的中段的称呼，区别于纤细的模特腹肌 (ch8)
- **耐力** — 长时间持续做功的能力；高次数、短休息主要练耐力而非力量 (ch3)
- **PARC** — 爆发力升级四要素：熟练度、适应力、规律性、信心 (ch19)
- **平台期** — 训练停滞阶段；用减脂、多休息、耐心退阶、规律生活破解 (ch11)
- **前链** — 身体正面的肌肉链，包括胸、肩前束、腹直肌、股四头肌等 (ch15)
- **牵张回弹** — 利用肌腱弹性与牵张反射，在落地后不停顿地弹起 (ch18)
- **全程动作幅度** — 动作从起始到结束的完整范围；力量训练优先全程，爆发训练可只用 1/3 (ch5)
- **热身** — 用同一动作链的低阶动作做 2–4 组高次数、半力练习，激活关节与神经 (ch11)
- **三规六矩** — 爆发力训练规则：每组不超过 3 次，每个动作有效总次数为 6 的倍数 (ch19)
- **三诀** — 关节训练三原则：均衡三条功能链、润滑关节、主动拉伸 (ch15)
- **升级标准** — 每式规定的组数×次数门槛，达到后才进入下一式 (ch4)
- **十式** — 每条动作链的十个难度级别，第一式最易、第十式最难 (ch4)
- **实用速度** — 整个身体快速移动的能力，如跳跃、冲刺、空翻 (ch17)
- **双立臂** — 悬吊后将躯干拉过单杠并撑起的动作，上杠链最终式 (ch18)
- **顺风旗** — 侧身抓握支撑物、身体水平展开的侧链力量技艺 (ch14)
- **体脂** — 身体脂肪比例；越低越轻，自重动作相对越容易 (ch3)
- **团身** — 把双膝拉向胸口以缩小转动惯量、提高空翻角速度的技术 (ch18)
- **推力** — 把身体或外物推离自己的力量，代表动作是俯卧撑与倒立撑 (ch4)
- **握力** — 手指与手掌抓握的能力；是引体、悬吊、旗类动作的入口 (ch13)
- **训练日记** — 用纸笔记录每次动作、次数与感受，让微小进步可见 (ch11)
- **训练量** — 训练的总组数、总次数或总时长；与强度相互排斥 (ch11)
- **训练强度** — 单组训练接近极限的程度；力量增长主要来自强度 (ch11)
- **悬吊八式** — 从水平悬吊到单臂毛巾悬吊的抓握力量阶梯 (ch13)
- **扬旗** — 抓旗的进阶侧链技艺，身体竖直展开、对侧链要求极高 (ch14)
- **引体向上** — 垂直拉起自身重量的背部与肱二头肌复合动作，共十式 (ch7)
- **增肌十诫** — 自重增肌十条原则：高次数、艰苦、简单复合、少组、日志、休息、饮食、睡眠、意志、力量 (ch20)
- **直角式** — 悬垂或支撑中把腿举至与地面平行并保持的举腿式，训练髋与下背 (ch15)
- **指尖俯卧撑** — 用手指指腹支撑、训练伸肌与手部平衡的俯卧撑变式 (ch13)
- **中段** — 躯干中部的腹、腰、髋深层肌肉群，负责传力与稳定 (ch8)
- **最终式** — 每条动作链的第十式，代表该链的极限技艺 (ch4)
