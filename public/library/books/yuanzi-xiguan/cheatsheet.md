# 习惯决策速查表

## 一、先诊断，再动手

| 症状 | 最可能断在哪一环 | 先做什么 |
|---|---|---|
| 总是“忘了做” | 提示 | 执行意图：写死时间地点；习惯叠加；把提示放到眼前 |
| 知道该做但不想动 | 渴求 | 喜好系结；重构关联；加入“行为正常”的群体 |
| 开始了但坚持不了 | 反应（太难） | 两分钟规则；减少阻力；预备环境 |
| 做完了却没动力再来 | 奖励 | 即时强化；习惯追踪；让完成本身可感知 |
| 坏习惯反复出现 | 提示仍在 | 移除/隐藏提示；增加阻力；承诺机制 |
| 坏习惯“明知有害却觉得爽” | 错误关联 | 逐条拆穿收益；重构为“失去什么” |
| 一次中断后彻底放弃 | 全有或全无 | 绝不错过两次；只做最小版本 |

## 二、四定律双向操作

| 环节 | 养好习惯 | 破坏习惯 |
|---|---|---|
| 提示 | 让它显而易见 | 让它脱离视线 |
| 渴求 | 让它有吸引力 | 让它缺乏吸引力 |
| 反应 | 让它简便易行 | 让它难以施行 |
| 奖励 | 让它令人愉悦 | 让它令人厌恶 |

## 三、设计一个新习惯（顺序不要乱）

1. **定身份**：问“拥有该结果的人属于哪类人？”
2. **选最小动作**：缩到两分钟能完成；找到门户习惯。
3. **挂提示**：执行意图（时间+地点）或习惯叠加（既有习惯之后）。
4. **降阻力**：预备环境，让开始不需要决策。
5. **加吸引**：喜好系结；加入同好群体。
6. **给回报**：完成后立即记录或小奖励。
7. **防中断**：绝不错过两次；准备“最低版本”预案。
8. **定期升级**：稳定后加一点难度；定期反思。

## 四、拆除一个坏习惯（按成本从低到高）

1. **移除提示**（最省力）：手机放另一房间、取关账号、清空零食。
2. **增加阻力**：多一步、上锁、交给别人保管、拔插头。
3. **重构关联**：拆穿“它对我有好处”的错误叙事。
4. **承诺机制**：提前付费、加入黑名单、让违约有代价。
5. **问责/契约**：找见证人，设定即时、具体、可执行的惩罚。
6. **环境切换**：搬离旧提示密集的场景（如果前五步都不够）。

## 五、关键数字与默认值

| 项目 | 书中数字/规则 | 用法 |
|---|---|---|
| 微习惯复利 | 每天1%，一年约37倍 | 用长期轨迹判断，不用单日结果 |
| 执行意图实验 | 写清时间地点组91% vs 对照组35%—38% | 计划要具体到无需决策 |
| 两分钟规则 | 新习惯开始≤2分钟 | 先标准化，再优化 |
| 心流难度 | 约高于当前能力4% | 作为“加一点难度”的参照 |
| 绝不错过两次 | 错过1次=意外，2次=新习惯 | 中断后24小时内接上 |
| 社会模仿 | 肥胖朋友使本人肥胖概率+57% | 选群体就是选默认行为 |
| 指差确认 | 错误减少85%，事故率降30% | 高风险流程加多通道确认 |
| 古德哈特 | 指标成为目标即失效 | 追踪指标，但别被指标绑架 |

## 六、关键取舍

| 选择 | 选 A 当…… | 选 B 当…… |
|---|---|---|
| A. 改环境 / B. 练意志 | 想长期、可持续、少消耗 | 只应对一次性突发诱惑 |
| A. 即时奖励 / B. 延迟回报 | 习惯尚未形成、需要启动 | 已有内在动机、奖励会拆台 |
| A. 习惯追踪 / B. 不追踪 | 需要证据、维持动力 | 追踪成本高于收益、指标会扭曲行为 |
| A. 承诺机制 / B. 保持灵活 | 明确知道该做什么、只需防软弱 | 环境不确定、需要保留调整空间 |
| A. 专精一项 / B. 技能组合 | 已有明显天赋、赛道明确 | 单项难拔尖、可用组合创造稀缺 |
| A. 探索 / B. 利用 | 时间充裕、方向未定 | 截止期近、已有较优方案 |

## 七、快速识别信号

- **你在“酝酿”而不是行动**：一直在做计划、买课、列清单，却没有产生任何结果。
- **你在靠意志硬撑**：每次都要说服自己，环境里提示原封不动。
- **你的身份在拖后腿**：常说“我就是这种人”“我不是那块料”。
- **你在错误赛道努力**：越努力越挫败，说明天赋/环境不匹配，而非不够拼。
- **你被指标绑架**：为了数字优化，忘了最初为什么做。
- **你正在厌倦**：不是该换赛道，而可能是该加一点难度或变化。
- **你一次中断就想全盘放弃**：把“完美连续”当目标，而不是“尽快接上”。
