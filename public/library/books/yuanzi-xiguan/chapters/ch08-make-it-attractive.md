# 第8章：怎样使习惯不可抗拒

## Core Idea
习惯由多巴胺驱动的期待感推动：真正促使我们行动的是“预期奖励”，而非奖励本身。因此让习惯有吸引力的关键，是把你想做的事与必须做的事绑定，让前者为后者提供期待。

## Frameworks Introduced
- **超常刺激（supernormal stimulus）**：夸大现实特征的强化版线索，会引发远超正常水平的反应。
  - When to use: 理解垃圾食品、社交媒体、广告为何让人难以抗拒；设计更具吸引力的体验。
  - How: 识别被夸大的感官特征（盐糖脂的精确组合、动态对比、即时点赞）；要么主动降低暴露，要么把同样的吸引力用于好习惯。
- **多巴胺驱动反馈回路**：提示出现→多巴胺上升→产生渴求→采取行动；期待阶段的峰值往往高于获得阶段。
  - When to use: 分析习惯动力从何而来；为什么“想要”不等于“喜欢”。
  - How: 把奖励提前“预告”给大脑（可视化的进度、即将到来的乐趣）；不要把动力寄托在获得奖励的瞬间。
- **喜好系结（temptation bundling）**：把“需要做的低频行为”与“想要做的高频行为”绑定。
  - When to use: 明知某习惯重要却总不想开始；有明确想做的娱乐活动。
  - How: 只在做需要的事时才允许自己做想要的事。公式：继[当前习惯]之后，我将[我需要的习惯]；继[我需要的习惯]之后，我将[我想要的习惯]。
- **普雷马克原理**：高频行为可以强化低频行为；用更喜欢做的事奖励不太喜欢做的事。
  - When to use: 设计奖励、安排工作与娱乐顺序。
  - How: 先做低频行为，再允许高频行为；确保高频行为确实有吸引力且不破坏长期目标。

## Key Concepts
- **超常刺激**：比自然线索更夸张、更能激活本能反应的人造刺激。
- **多巴胺**：不只关联快乐，更关联动机、学习与记忆；期待奖励时也会分泌。
- **渴求 vs 喜欢**：想要（wanting）与享受（liking）是两套系统；大脑分配给渴求的回路远多于喜欢。
- **期待峰值**：对奖励的期待往往比获得奖励更令人兴奋；假期前的憧憬常胜过假期本身。
- **喜好系结**：把需要做的事与愿意做的事捆绑，使前者获得后者的吸引力。
- **激励仪式**：在做困难习惯前固定做一件喜欢的事，让前者逐渐与积极感受关联。

## Mental Models
- **把多巴胺想成“预告片”**：最吸引人的常是预告，不是正片；利用预告，而不是追逐正片。
- **把习惯想成“套餐”**：单点不想吃，捆绑喜欢的配菜就能吃下去。
- **把超常刺激想成“被放大的本能”**：现代食品与平台在按我们的古老按钮；要有意识地选择谁在按按钮。
- **把系结想成“先吃药再吃糖”**：糖不是药的一部分，但能让吃药变得可期待。

## Anti-patterns
- **只靠意志对抗超常刺激**：用进化了5万年的大脑硬扛精心设计的现代诱惑，胜率很低。
- **把“想要”误当“喜欢”**：追逐多巴胺预告，得到后却发现并不享受，于是不断加量。
- **系结与身份冲突**：健身后的奖励是冰激凌、省钱的奖励是买新夹克，短期奖励拆长期目标的台。
- **奖励延迟到看不见**：只承诺“以后会更好”，当下没有任何吸引力，习惯难以启动。
- **把娱乐当作无条件奖励**：想要的行为不需要先完成需要的行为，系结就失效了。

## Worked Example
都柏林工程系学生罗南·伯恩爱看奈飞，却知道自己该多锻炼。他改造了健身脚踏车：只有以特定速度踩踏板，奈飞节目才会播放；踩得太慢，节目就暂停，直到他重新达到速度。于是“看剧”这个高频行为被绑定在“骑车”这个低频行为上，他用“一次一集奈飞”的方式减了肥。商业模式同样如此：ABC 在周四晚推出《实习医生格蕾》《丑闻》《逍遥法外》，把它包装成“TGIT（感谢上帝，今天是周四）”，并鼓励观众准备爆米花、红酒，把“看节目”（需要观众做的）与“放松、喝酒、吃爆米花”（观众早想做的）绑定。久而久之，“周四晚8点”本身就成了放松与娱乐的提示。个人版可以是：只在健身房读八卦或看真人秀；只在处理完积压邮件后做足疗；掏出手机后先做十个立卧撑，才能刷脸书。

## Key Takeaways
1. 让人行动的是对奖励的期待，不是奖励本身；把期待设计进习惯。
2. 习惯是多巴胺驱动的反馈回路；“想要”与“喜欢”不是一回事。
3. 用喜好系结把需要做的事与想做的事绑定，让前者获得吸引力。
4. 普雷马克原理：高频行为可以强化低频行为；先做该做的，再做想做的。
5. 系结的奖励必须与身份一致，不能用拆台式奖励。
6. 现代世界充满超常刺激；要么减少暴露，要么把吸引力导向好习惯。
