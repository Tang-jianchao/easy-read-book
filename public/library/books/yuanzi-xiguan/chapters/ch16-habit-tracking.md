# 第16章：怎样天天保持好习惯

## Core Idea
最有效的激励之一是“看得见的进步”。习惯追踪用视觉证据让行为显而易见、有吸引力、令人愉悦；同时用“绝不错过两次”防止一次中断演变成新习惯。但指标只能辅助系统，不能替代系统。

## Frameworks Introduced
- **曲别针策略**：每完成一次关键动作，就把一个曲别针从满罐移到空罐，用可见的累积制造即时满足。
  - When to use: 需要大量重复、过程枯燥、结果延迟的任务（销售电话、俯卧撑、写作页数）。
  - How: 准备两个容器与固定数量的标记物（120个曲别针）；每完成一次动作移动一个；直到全部转移。也可用发夹、弹珠、进度条、页码。
- **习惯追踪（habit tracking）**：用日历打叉、日志、应用记录习惯是否发生。
  - When to use: 想维持习惯、看清真实执行率、在低谷时获得证据。
  - How: 选一个最重要的习惯；每次完成后立即记录；让记录成为习惯叠加的一环：“在[当前习惯]之后，我将[追踪我的习惯]。”测量尽量自动化；手动追踪只限于最重要的习惯。
- **绝不错过两次（Never Miss Twice）**：错过一次是意外，错过两次是新习惯的开始。
  - When to use: 生病、出差、忙碌导致习惯中断；陷入“全有或全无”思维。
  - How: 允许一次失误；尽快接上，哪怕只做最小版本；不追求完美，只追求不连续中断。
- **无秤胜利（non-scale victory）**：当主指标停滞时，寻找其他能证明进步的信号。
  - When to use: 体重、收入等数字长期不动，令人沮丧。
  - How: 关注睡眠、精力、情绪、衣服合身度、他人反馈等替代指标；不要被单一数字绑架。

## Key Concepts
- **视觉量度**：把抽象进步转化为可见标记，强化行为并提供即时满足。
- **“永不中断”**：关注的不是单次质量，而是持续出现；宋飞用“每天写笑话”保持创作链。
- **追踪的三重功效**：建立视觉提示、提供内在激励、制造完成后的满足感。
- **古德哈特定律**：“当一项措施成为目标时，它就不再是一项好措施。”
- **反馈过多 / 过少**：天天盯每个选择是过度关注局部；从不回顾则看不见明显瑕疵。
- **习惯周期**：习惯会自然经历启动—维持—中断—恢复；需要为偏离准备预案。

## Mental Models
- **把追踪想成链条**：链条越长，越不想亲手打断；但链条是为了服务目标，不是为了链条本身。
- **把打叉想成“给身份投票”**：每一个叉都是“我是那种会做这件事的人”的证据。
- **把指标想成仪表盘**：仪表盘帮你开车，但不能代替目的地；盯着仪表盘开车会撞墙。
- **把“绝不错过两次”想成止损**：一次亏损可以承受，连续亏损会吞掉复利。

## Anti-patterns
- **追踪太多**：同时记录十个习惯，负担过重，最后全部放弃。
- **指标替代目标**：为了凑够一万步而忽视健康，为了季度收入而牺牲产品质量。
- **断一次就全盘放弃**：把“完美连续”当作目标，一次中断就认定失败。
- **只追踪不调整**：记录了一堆数据，却从不回顾、不修正方向。
- **被单一数字绑架**：体重不降就否定所有努力，忽视睡眠、精力、力量等真实进步。

## Worked Example
23岁的股票经纪人特伦特·迪尔施米德在偏僻的阿伯茨福德工作，资源与资历都不占优。他每天上班时在桌上放两个罐子：一个装满120个曲别针，一个是空的。每拨通一个推销电话，就把一个曲别针移到空罐；直到120个全部转移，才算完成当天任务。18个月内，他为公司带来500万美元收益；24岁时年薪达到7.5万美元（约合今天的12.5万美元）。曲别针本身没有魔力，它把“打120个电话”这个抽象任务变成可见、可累积、可完成的进度条，每移动一次都给大脑一点即时满足。另一个例子是杰里·宋飞：他的目标不是写出好笑话，而是“永不中断”每天写；关注的是链条不断，而不是单次灵感。富兰克林则用一本小册子追踪13项美德，每天结束时记录进步。追踪的力量在于：它同时让行为显而易见、有吸引力、令人愉悦。

## Key Takeaways
1. 看得见的进步是最有效的激励之一；用视觉量度制造即时满足。
2. 习惯追踪同时服务于前三条定律：提示、吸引、满足。
3. 手动追踪只选最重要的习惯；能自动化就自动化。
4. 绝不错过两次：一次失误是意外，连续两次是新习惯的开始。
5. 警惕古德哈特定律：指标成为目标后，就会偏离本意。
6. 定期反思与回顾，确保追踪服务于系统，而不是反过来。
