# 第13章：怎样利用两分钟规则停止拖延

## Core Idea
习惯是切入点，不是终点。把任何新习惯缩减到两分钟内可以完成的版本，先让“开始”变得毫不费力；一旦开始，继续下去往往容易得多。先标准化，再优化。

## Frameworks Introduced
- **两分钟规则（Two-Minute Rule）**：“当你开始培养一种新习惯时，它所用时间不应超过两分钟。”
  - When to use: 拖延、启动困难、总想“一次做很多”；新习惯反复死在第一天。
  - How: 把目标缩减为两分钟版本：“每晚读一本书”→读一页；“做30分钟瑜伽”→拿出瑜伽垫；“复习功课”→打开笔记；“跑3英里”→系好跑鞋；“整理衣物”→叠一双袜子。
- **门户习惯（gateway habit）**：能自然把你引向更有成效道路的最小入口动作。
  - When to use: 目标很大，直接执行令人畏惧。
  - How: 把目标按“非常容易→非常困难”分级，找到最容易的那一级作为入口。跑马拉松很难，但“穿上跑鞋”只是举手之劳；先做入口动作，再让后续自然发生。
- **决定性时刻（decisive moments）**：一天中少数几个选择点，会为后续一段时间设定轨迹。
  - When to use: 想用最少干预撬动一天的行为。
  - How: 识别关键岔路口（叫外卖还是做饭、换健身服还是瘫沙发、打开作业还是游戏）；把决定性时刻设计成偏向好习惯的默认选项。
- **先标准化，再优化**：先建立稳定、可重复的最低版本，再逐步提升难度与时长。
  - When to use: 还没有形成习惯就想追求完美方案。
  - How: 连续做到最小版本；稳定后再扩展；每次只扩展一点点。

## Key Concepts
- **门户习惯**：通往更大行为的最小启动动作。
- **决定性时刻**：少数会设定后续行为轨迹的选择点。
- **习惯塑造（habit shaping）**：从最小行为开始，逐步向最终目标扩展。
- **仪式化启动**：把开始阶段固定成仪式，帮助进入高度专注状态。
- **“做两分钟就停”版本**：不是“开始做更多”的策略，而是把两分钟本身作为全部任务，降低心理负担。
- **身份投票**：哪怕只在健身房待两分钟，也是在为“我是不会错过健身的人”投票。

## Mental Models
- **把习惯想成门**：两分钟规则只负责把门推开；进门之后走多远是下一步的事。
- **把决定性时刻想成岔路口**：每天只有几个关键路口，走对方向，后面顺理成章。
- **把启动想成仪式**：像特怀拉·萨普叫出租车——上车那一刻，仪式就完成了，后面自然会去健身。
- **把“做得少”想成“比不做好”**：一次俯卧撑胜过不锻炼，读一页胜过不读。

## Anti-patterns
- **一开始就设太大**：梦想改变时兴奋过头，第一天就安排两小时，第二天就放弃。
- **把两分钟当骗局**：认为“真正目标是做更多，所以两分钟没意义”，于是拒绝开始。
- **等待动力**：把启动交给心情，而不是交给一个足够小的动作。
- **只重时长不重仪式**：开始阶段混乱，难以进入专注状态。
- **在习惯未稳定前频繁加码**：标准化没做好就追求优化，导致反复归零。

## Worked Example
编舞家特怀拉·萨普把成功归功于一个简单仪式：每天五点半起床，穿好练功服，出门叫出租车，告诉司机去91街和第一大道交叉口的健身馆。她说，仪式不是健身房里的伸展和负重，而是“出租车”——在告诉司机目的地的那一刻，整个仪式就完成了。这个动作极小，却减少了她偷懒或换方式的机会，把“去健身”变成日常行为库中的默认项。另一个例子是一位读者减重100多磅：他每天去健身房，但规定自己最多只练5分钟，时间一到立刻离开。几周后他想：“反正我总是来这里，不妨多待一会儿。”几年后体重恢复正常。写日记也一样：格雷戈·麦吉沃恩不写全部想法，而是在感觉写烦之前及时收笔；海明威说：“最佳做法是一定要在你感觉还好时及时收手。”两分钟规则保护的正是“明天还愿意再来”的意愿。

## Key Takeaways
1. 新习惯开始阶段不应超过两分钟；先让开始变得毫无阻力。
2. 找到你的门户习惯：跑马拉松的门户是穿上跑鞋，不是跑完马拉松。
3. 习惯是切入点，不是终点；两分钟只是启动正式程序的仪式。
4. 先标准化，再优化；不能改善一个还不存在的习惯。
5. 识别并设计决定性时刻，用少数关键选择撬动一整天。
6. 做得比希望少，也远胜什么都不做；每次小行动都在为新身份投票。
