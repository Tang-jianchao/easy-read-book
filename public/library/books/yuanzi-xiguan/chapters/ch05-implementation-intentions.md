# 第5章：培养新习惯的最佳方式

## Core Idea
人们常以为自己缺动力，实际缺的是明确计划。把新习惯绑定到具体的时间、地点或既有习惯上，提示就会变得显而易见，行动也不再依赖“想起来”或“有感觉”。

## Frameworks Introduced
- **执行意图（implementation intentions）**：事先规定“何时、何地、做什么”的计划。
  - When to use: 知道该做什么却总是拖延；习惯总被忙碌、遗忘或临时决定挤掉。
  - How: 填写公式“我将于[时间]在[地点][行为]”。例：早晨7点，我将在厨房冥想1分钟；下午6点，我将在卧室学20分钟西班牙语。关键是具体到无需再做决定。
- **习惯叠加（habit stacking）**：把新习惯接在一个已经每天发生的旧习惯之后。
  - When to use: 时间地点不固定；想让新行为自动获得一个可靠提示。
  - How: 使用公式“继[当前习惯]之后，我将[新习惯]”。例：倒完咖啡后冥想1分钟；脱下上班鞋后换上运动装；坐下吃晚饭时说出当天一件感动的事。可串联成链条：倒咖啡→冥想→写待办→做第一件事。
- **狄德罗效应**：买入新物品后引发连锁消费；作者把它反用为“行为连锁”——每个动作都可成为下一个动作的提示。
  - When to use: 设计习惯链、理解为什么一个改变会带动一串改变。
  - How: 找出日常中稳定发生的“锚点行为”，把新行为紧接其后；让上一动作自然触发下一动作。

## Key Concepts
- **执行意图**：把模糊意愿转成可执行计划的“如果—那么”结构。
- **习惯叠加**：执行意图的特殊形式，用既有习惯而非钟表/地点做提示。
- **提示频率匹配**：新习惯每天做，就要叠加在每天发生的习惯上；叠加在每周一次的行为上会失效。
- **提示具体性**：提示必须具体且可立即行动；“午休时做俯卧撑”不如“合上笔记本电脑准备吃午饭时，在办公桌边做十个俯卧撑”。
- **新鲜起点效应**：周、月、年的头一天，人们更愿意开始新行为；可借势启动。
- **决策消除**：预先决定何时何地做，行动时刻就不必再消耗意志力做选择。

## Mental Models
- **把执行意图想成给习惯预约座位**：没有时间地点的习惯，永远在候补。
- **把习惯叠加想成多米诺骨牌**：推倒第一张，后面的顺势倒下；关键是选对第一张。
- **把旧习惯想成免费提示器**：你已经在做的事，就是最可靠的闹钟。
- **把模糊计划想成空头支票**：“我会多读书”没有兑现日期，也没有收款人。

## Anti-patterns
- **模糊承诺**：“我会吃得更健康”“我会写得更多”——没有时间、地点、动作，等于没有计划。
- **等待灵感**：把启动权交给“哪天有状态”，而不是预先设定的提示。
- **提示频率错配**：想每天做，却叠加在“每周开一次会”之后。
- **提示不够具体**：“午休时”包含饭前饭后、室内室外多个模糊点，导致执行不一致。
- **在混乱时段硬塞新习惯**：早上孩子乱跑、家务缠身时加入冥想，提示会被噪声淹没。
- **只叠加不检查**：链条过长、锚点不稳定，一处断裂就整条失效。

## Worked Example
英国研究人员把248人分成三组，用两周培养健身习惯。第一组只记录频率；第二组额外阅读运动益处；第三组在同样动机材料之外，还要填写：“下周，我将于×天×时×处进行为时至少20分钟的剧烈运动。”结果：第一、二组约35%—38%的人每周至少锻炼一次，动机材料几乎没有额外作用；第三组达到91%，是前两组的两倍以上。差别不在“多想练”，而在“何时何地练”被提前写死。作者自己的俯卧撑实验也说明具体性的重要：最初写“午休时做十个俯卧撑”，结果饭前饭后、地点都不确定，执行断断续续；改成“当我合上笔记本电脑准备吃午饭时，我会在办公桌边上做十个俯卧撑”后，行为才稳定下来。

## Key Takeaways
1. 多数“缺乏动力”其实是“缺乏计划”；先把时间、地点、动作写具体。
2. 执行意图公式：我将于[时间]在[地点][行为]。
3. 习惯叠加公式：继[当前习惯]之后，我将[新习惯]。
4. 提示的频率必须与新习惯一致；每天做的事要挂在每天发生的锚点上。
5. 提示越具体、越可立即行动，习惯越容易触发。
6. 用新鲜起点（周初、月初、年初）启动，但不要依赖它维持。
