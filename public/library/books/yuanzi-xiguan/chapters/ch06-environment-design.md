# 第6章：原动力被高估，环境往往更重要

## Core Idea
行为是人与环境的函数。与其反复给自己打气，不如重新设计空间：让好习惯的提示显而易见，让坏习惯的提示退出视野。环境是塑造行为的无形之手，而你可以成为它的建筑师。

## Frameworks Introduced
- **环境设计（environment design）**：通过摆放、分区与重新布置，增加好习惯提示的显眼度与可达性。
  - When to use: 知道该做什么却总是“想不起来”；依赖意志力反复失败；想批量影响自己或他人的行为。
  - How: ①把好习惯所需的物品放在视线与手边（药瓶放水龙头旁、吉他放客厅中央、水瓶放各处）；②把坏习惯的提示移出视线或增加取用步骤；③让最佳选择匹配最鲜明的提示。
- **情境即提示（context as cue）**：习惯最终不只绑定单一触发物，而绑定整个环境与情境。
  - When to use: 同一空间里总自动进入某种行为（沙发→刷手机、床→看剧）；想建立稳定的行为模式。
  - How: 为不同活动划分独立空间——“一个空间，一种用途”；空间不足时划分活动区（阅读椅、写字桌、餐桌），数字空间同理（电脑只写作、平板只阅读、手机只社交）。
- **新环境优势**：在全新环境中建立新习惯更容易，因为旧提示不在场。
  - When to use: 旧环境反复把你拉回旧行为；想彻底切换模式。
  - How: 去没去过的咖啡店、公园长椅、房间角落建立新惯例；换一家不熟悉的超市；无法换环境时，重新布置现有空间。

## Key Concepts
- **B=f(P,E)**：勒温的等式——行为是人与环境的函数。
- **暗示冲动购物**：顾客购买并非因为真正需要，而是因为商品呈现方式触发了需求想象。
- **视觉主导**：人类约1100万个感觉接收器中约1000万个用于视觉，视觉提示是行为最强的催化剂。
- **提示显眼度**：提示越显眼、越易取用，行为越可能发生；藏起来的物品约等于不存在。
- **情境混杂**：一个空间承载多种活动时，较容易实行的习惯会占上风（手机=工作+社交+娱乐，结果总是滑向娱乐）。
- **环境建筑师**：多数人生活在别人设计的世界里；主动设计者重新掌控自己的行为。

## Mental Models
- **把环境想成看不见的手**：你以为是自己选了矿泉水，其实是水瓶先出现在你手边。
- **把提示想成舞台灯光**：灯光打在哪里，观众就看哪里；把光打在你想要的行为上。
- **把空间想成记忆索引**：每个房间都在提示一套剧本；换房间就是换剧本。
- **把手机想成提示大杂烩**：功能越多，越难与单一习惯绑定；需要为它划分用途。

## Anti-patterns
- **迷信原动力**：认为改变全靠“想不想”，忽视环境对行为的持续塑造。
- **把好习惯藏起来**：吉他放壁橱、维生素放柜子深处、苹果放冰箱底层，然后怪自己没毅力。
- **一屋多用**：在床上工作、在沙发上吃饭、在餐桌办公，导致每个行为都缺少稳定提示。
- **让坏习惯触手可及**：零食放台面、遥控器放沙发边、手机放枕边，然后要求自己克制。
- **忽视情境切换**：在旧环境里硬建新习惯，持续与旧提示对抗。

## Worked Example
波士顿马萨诸塞总医院的安妮·桑代克没有劝任何人少吃糖，只改了自助餐厅的布局：在收银台旁的冰箱里增加矿泉水，在各点餐台旁摆放瓶装水，苏打水仍在原处。三个月内，苏打水销量下降11.4%，瓶装水销量上升25.8%；食物供应也做了类似调整，效果相近。没有人被说服，行为却改变了。另一个例子来自阿姆斯特丹史基浦机场：清洁人员在每个小便池中央贴了一个苍蝇形状的小标签，男性会本能地瞄准“苍蝇”，溅出量显著减少，卫生间清洁费用每年降低8%。还有荷兰的能源实验：同样面积、同样电价的家庭，电表装在楼上主走廊的比装在地下室的少用约30%的能源——因为消耗变得可见。三个案例的共同点是：不改变人，改变人面前的提示。

## Key Takeaways
1. 行为是环境的函数；想改变行为，先改变提示的可见度与可达性。
2. 让好习惯的提示显而易见，让坏习惯的提示退出视野。
3. 为不同活动划分独立空间；一个空间一种用途，习惯才稳定。
4. 新环境更容易建立新习惯，因为旧提示不在场；换环境是最快的重启方式。
5. 视觉是最强感官通道；把重要提示放在看得见的地方。
6. 不要做环境的消费者，要做环境的设计师。
