## 核心框架与心智模型

**1. 微习惯复利：每天1%，一年约37倍（全书基石，ch01）**
习惯是自我提高的复利。每天进步1%，一年后约提升37倍；每天退步1%，一年后几乎归零。人们高估决定性时刻，低估每日微小改进。结果（体重、净资产、知识）是习惯的滞后指标；判断自己不要看当前位置，要看当前习惯把你带向哪里。突破前有一段“潜能蓄积期”：努力没有消失，只是尚未跨过临界点。**用体系替代目标**：目标是想要的结果，体系是导致结果的过程；赢家和输家常有相同目标，目标无法区分成败。修正输入端，输出端自会修正。

**2. 行为改变三层次与身份认同（ch02）**
改变分三层：结果（得到什么）、过程（做什么）、身份（相信什么）。最持久的是身份改变。身份由反复行为提供的证据塑造：每个行动都是投给“我想成为的那个人”的一票，不需要全票，只需多数。两步程序：①决定你想成为哪类人（从想要的结果倒推：“拥有该结果的人属于哪类人？”）；②用小赢证明给自己看。把“读一本书”改成“成为读者”，把“跑马拉松”改成“成为跑步者”。警惕身份标签：“我数学不好”“我总是迟到”会变成自我实现的牢笼。

**3. 习惯回路与行为转变四大定律（ch03）**
所有习惯都是四步反馈回路：**提示 → 渴求 → 反应 → 奖励**。提示触发行为，渴求提供动力（你渴求的是状态变化，不是动作本身），反应是实际执行（取决于动力与难度），奖励满足渴求并教大脑“值得重复”。四环缺一，行为不会成为习惯。由此得到四定律：**让它显而易见、让它有吸引力、让它简便易行、让它令人愉悦**；戒除坏习惯则反向操作：脱离视线、缺乏吸引力、难以施行、令人厌恶。遇到任何行为问题，先问四个问题：怎样才能让它明显？有吸引力？容易？令人愉悦？

**4. 第一定律：让它显而易见（ch04—ch07）**
- **指差确认**：指向目标并大声说出状态，把自动行为提升到意识层面；日本铁路借此把错误减少85%。
- **习惯记分卡**：列出日常习惯，标“+/-/=”，第一轮只观察不评判；判断标准是“是否支持我想成为的身份”。
- **执行意图**：写死“我将于[时间]在[地点][行为]”；写清时间地点的健身组执行率91%，对照组仅35%—38%。
- **习惯叠加**：“继[当前习惯]之后，我将[新习惯]”；锚点频率必须与新习惯一致，提示要具体到可立即行动。
- **环境设计**：行为是人与环境的函数（B=f(P,E)）；好习惯提示放眼前，坏习惯提示移出视线；一个空间一种用途；新环境更容易建立新习惯。
- **让它脱离视线**：自控力强的人不是更能忍，而是更少遇到诱惑；习惯一旦编码不会遗忘，最实用的拆除方式是移除提示。自我控制是权宜之计，有纪律的环境才是长期方案。

**5. 第二定律：让它有吸引力（ch08—ch10）**
习惯是多巴胺驱动的反馈回路：真正推动行动的是**对奖励的期待**，不是奖励本身；“想要”与“喜欢”是两套系统。现代世界充满**超常刺激**（盐糖脂精确配比、动态对比、即时点赞），它们在按我们古老的本能按钮。对策：
- **喜好系结**：把需要做的低频行为与想要做的高频行为绑定（只在健身时看奈飞；只在处理邮件后做足疗）。
- **模仿三个群体**：亲近的人、群体中的多数人、有权势的人；加入“你想要的行为被视为正常、且你已与群体有共同点”的文化，集体身份会强化个人身份。
- **重构关联**：坏习惯不是“你喜欢它”，而是你误把它当成满足深层动机的最佳方式；逐条拆穿“吸烟减压/社交必需”等错误关联，把“我得”改成“想”，把“牺牲”改成“收益”。

**6. 第三定律：让它简便易行（ch11—ch14）**
- **频率优先于时长**：习惯基于重复次数，不是天数；别问“要多少天”，问“要重复多少次”。行动产生结果，酝酿只是准备；完美主义常是延迟失败的借口。
- **最省力法则**：人天然选择阻力最小的选项；不要只加动力，要减阻力。因减而加：清除流程中的多余步骤，产出反而增加。
- **两分钟规则**：新习惯开始不超过两分钟；找到门户习惯（跑马拉松的门户是穿上跑鞋）；先标准化，再优化。
- **让它难以施行**：承诺机制用当下选择锁定未来行为（雨果把衣服锁起来写《巴黎圣母院》）；一次性选择（自动储蓄、好床垫）与技术自动化，让好习惯不可避免、坏习惯难以维持。

**7. 第四定律：让它令人愉悦（ch15—ch17）**
前三条定律提高行为当下发生的概率，第四条提高未来重复的概率。人脑偏爱即时回报，而好习惯的回报常延迟；**基本准则：重复有即时回报的行为，避免受即时惩罚的动作**。给好习惯加一点即时快乐，给坏习惯加一点即时痛苦。
- **即时强化**：完成后立刻给满足感；戒除坏习惯时把“没做”转化为可见收益（每次放弃购买就存入“梦想账户”）。
- **习惯追踪 / 曲别针策略**：用日历打叉、移动曲别针制造可见进步；追踪同时让行为显而易见、有吸引力、令人愉悦。
- **绝不错过两次**：错过一次是意外，错过两次是新习惯的开始；中断后尽快接上，哪怕只做最小版本。
- **问责与习惯契约**：公开承诺、见证人、具体可执行的违约代价；后果越即时、具体、直接，越能改变行为（但要警惕古德哈特定律：指标成为目标就失效）。

**8. 高阶战术：从“好”到“伟大”（ch18—ch20）**
- **选择合适领域**：基因不决定命运，而决定你在哪些领域更有胜算；选择与天性匹配的习惯，努力做好容易做的事；单项比不过别人，就用技能组合与专门化创造稀缺性；找不到游戏就自创一个。用**探索/利用权衡**：先广泛尝试，找到较优选项后集中投入，同时保留少量探索。
- **金发女孩准则**：难度略高于能力时动力最高（心流约高4%）；太难焦虑，太易无聊；习惯稳定后要持续加一点难度。
- **习惯动作 + 刻意练习 = 精通**：习惯让技能自动化，但熟练后容易忽略反馈；要建立**反思与回顾**体系（年终三问、半年诚信报告），并**弱化身份**、保持灵活，避免被单一角色锁死。

**9. 一页决策链**
定身份 → 选最小动作 → 挂提示（时间地点/既有习惯）→ 降阻力 → 加吸引 → 给即时回报 → 防中断（绝不错过两次）→ 定期升级与反思。戒坏习惯则反向：移除提示 → 增加阻力 → 重构关联 → 承诺机制 → 问责/契约 → 必要时换环境。
