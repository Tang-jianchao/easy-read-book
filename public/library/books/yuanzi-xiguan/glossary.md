# 术语表

按拼音字母排序。

- **暗示冲动购物** — 顾客因商品的呈现方式（位置、可见度、陈列）而临时产生需求并购买，而非出于真实需要 (ch06)
- **边际收益的聚合** — 把流程拆成多个环节，每个环节改进1%，汇总后产生显著跃升 (ch01)
- **长时程增强** — 重复活动使神经元连接增强的生理机制，是习惯自动化的神经基础 (ch11)
- **超常刺激** — 夸大现实特征的强化版线索，如三个红点的假喙、盐糖脂精确配比的加工食品 (ch08)
- **承诺机制** — 当下的选择锁定未来行为，使坏习惯难以施行、好习惯更容易坚持；又称奥德修斯合约 (ch14)
- **狄德罗效应** — 买入新物品后引发连锁消费；书中反用为“一个动作触发下一个动作”的行为链 (ch05)
- **第二定律** — 让它有吸引力；坏习惯则让它缺乏吸引力 (ch08)
- **第三定律** — 让它简便易行；坏习惯则让它难以施行 (ch11)
- **第四定律** — 让它令人愉悦；坏习惯则让它令人厌恶 (ch15)
- **第一定律** — 让它显而易见；坏习惯则让它脱离视线 (ch04)
- **多巴胺驱动反馈回路** — 提示出现后多巴胺上升，产生渴求并驱动行动；期待奖励时的峰值常高于获得时 (ch08)
- **恶性循环** — 坏习惯自我滋养：情绪低落→暴食→更难受→继续暴食 (ch07)
- **反馈回路** — 提示→渴求→反应→奖励的循环；奖励教会大脑是否值得重复 (ch03)
- **复利** — 每天1%的改进一年约37倍；好习惯与坏习惯都按复利累积 (ch01)
- **古德哈特定律** — 当一项措施成为目标时，它就不再是一项好措施；指标会扭曲行为 (ch16)
- **赫布定律** — “一起激发的神经元连在一起”；重复强化神经连接 (ch11)
- **核心价值观** — 反思与诚信报告中被重新审视的深层原则，用来校准习惯方向 (ch20)
- **环境设计** — 通过摆放、分区、重新布置，让好习惯提示显眼、坏习惯提示退出视野 (ch06)
- **激励仪式** — 在做困难习惯前固定做一件喜欢的事，使前者逐渐与积极感受关联 (ch10)
- **即时奖励 / 延迟奖励** — 行为立刻得到的回报 vs 很久以后才出现的回报；大脑偏爱前者 (ch15)
- **金发女孩准则** — 挑战难度与能力匹配时动力最高；太难焦虑，太易无聊 (ch19)
- **决定性时刻** — 一天中少数会为后续行为设定轨迹的关键选择点 (ch13)
- **渴求** — 改变内在状态的愿望；你渴求的是状态变化，不是习惯动作本身 (ch03)
- **刻意练习** — 把注意力集中在成功的一个小元素上，重复内化后再进入下一个 (ch20)
- **两分钟规则** — 新习惯开始阶段不超过两分钟，先让“开始”变得毫不费力 (ch13)
- **门户习惯** — 能自然引向更大行为的最小入口动作，如“穿上跑鞋”之于跑马拉松 (ch13)
- **潜能蓄积期** — 努力与结果之间的滞后期；跨过临界点前，改变几乎不可见 (ch01)
- **情境即提示** — 习惯最终绑定整个环境与情境，而不只是单一触发物 (ch06)
- **曲别针策略** — 每完成一次动作就移动一个标记物（曲别针、弹珠），用可见累积制造即时满足 (ch16)
- **深层动机** — 节省精力、食物与水、伴侣、联结、认可、减少不确定性、地位等古老需求 (ch10)
- **身份认同** — 你对自己“是哪类人”的信念；由反复行为提供的证据塑造 (ch02)
- **时间不一致性** — 大脑评估奖励时偏向当下而非未来，导致明知故犯 (ch15)
- **提示** — 预测奖励的线索，触发习惯回路；最常见的是时间与地点 (ch03)
- **体系** — 导致结果的过程与日常流程；目标定方向，体系产生进步 (ch01)
- **习惯叠加** — 把新习惯接在已有习惯之后：“继[当前习惯]之后，我将[新习惯]” (ch05)
- **习惯回路** — 提示、渴求、反应、奖励四步组成的神经反馈回路 (ch03)
- **习惯记分卡** — 列出日常习惯并标注“+/-/=”，先观察不评判 (ch04)
- **习惯契约** — 公开宣告承诺并约定违约责罚的书面/口头协议，通常有问责伙伴签字 (ch17)
- **习惯追踪** — 用日历打叉、日志或应用记录习惯是否发生，提供视觉证据与即时满足 (ch16)
- **喜好系结** — 把需要做的低频行为与想要做的高频行为绑定，让前者获得吸引力 (ch08)
- **行动 / 酝酿** — 行动会产生结果；酝酿只是计划、策划、学习，本身不产生结果 (ch11)
- **行为改变三层次** — 结果变化、过程变化、身份变化；最持久的是身份变化 (ch02)
- **行为转变四大定律** — 让它显而易见、有吸引力、简便易行、令人愉悦 (ch03)
- **耶克斯-多德逊法则** — 最佳激励水平位于枯燥乏味与焦虑不安之间的中点 (ch19)
- **一次性选择** — 只做一次、却长期降低未来阻力或持续创造价值的决定 (ch14)
- **执行意图** — 事先规定“何时、何地、做什么”的计划：“我将于[时间]在[地点][行为]” (ch05)
- **指差确认** — 指向目标并大声说出状态，用多通道确认把自动行为提升到意识层面 (ch04)
- **自我控制** — 短期应急手段而非长期策略；长期靠有纪律的环境 (ch07)
