# 术语表 Glossary

> 《少有人走的路》1-8 全套 (M·斯科特·派克)，按拼音排序，标注册。

- **自律** — 主动要求自己以积极态度承受痛苦、解决问题；解决人生问题的主要工具（册1）
- **推迟满足感** — 先苦后甜，重设快乐与痛苦次序；自律四原则之一（册1）
- **承担责任** — 勇敢说"这是我的问题，由我来解决"；自律四原则之二（册1）
- **忠于事实** — 诚实面对现实与内心；自律四原则之三（册1）
- **保持平衡** — 灵活自律、适时放下；自律四原则之四（册1）
- **爱** — "为促进自我与他人心智成熟而不断扩展自我界限的意愿"；自律的原动力（册1）
- **成长与信仰** — 心智成熟是扩展意识、建立个人信仰的终身过程（册1）
- **恩典（Grace）** — 生命中的意外馈赠（爱、潜意识、机遇）推动超越自利（册1）
- **神经官能症 / 人格失调症** — 强加责任于己 vs 推卸责任于人；责任感问题两种相反表现（册1）
- **谎言 / 恶狼** — 谎言的本质是掩盖真相、逃避痛苦；喂养恶狼的食物（册2）
- **邪恶** — 由颠倒是非的谎言产生；live 颠倒成 evil（册2）
- **两只狼** — 善狼（勇敢诚实爱）与恶狼（畏惧虚伪谎言），"你喂过的那只赢"（册2）
- **人生是一场修行** — 把困难、痛苦、关系当修行素材（册3）
- **心灵探索** — 向内诚实审视动机、恐惧、欲望（册3）
- **寻找自己的归宿** — 在关系、信仰、使命中找到归属与意义（册3）
- **反抗草率的思考** — 独立审慎思考，不随波逐流（册4）
- **追寻自我 / 放下自我** — 前半生建立自我，后半生超越自我中心（册4）
- **真诚共同体（Community）** — 接纳差异、尊重个性、成员独立完整的群体（册5）
- **聆听不一样的鼓声** — 接纳差异、尊重每个人的独特性（册5）
- **个体化（荣格）** — 成为真实自己的过程；独特、真实、完整、包容（册5）
- **真实造就完整** — 压抑真实破坏完整性（册5）
- **真诚是生命的药** — 真诚面对痛苦是疗愈之始；婚姻家庭是修行道场（册6）
- **死亡=关系消失** — 人活在关系中；关系的饱满是人生的饱满（册7）
- **生命朝圣** — 把人生看作主动寻找意义的朝圣之旅（册8）
- **寻找石头** — 珍惜并安放一生中有意义的东西，完成归宿（册8）
