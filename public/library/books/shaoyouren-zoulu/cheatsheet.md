# 速查表 Cheatsheet

> 心灵成长决策指南，帮助你在面对困难、关系与人生时像派克一样行动。以一页为限。

## 核心判断

- **遇到问题** → 别逃避。自律四原则：推迟满足感、承担责任、忠于事实、保持平衡。
- **面对痛苦** → 痛苦是疗愈的入口，不是敌人。回避它只会让问题以更可怕的面目出现。
- **诚实 vs 谎言** → 喂养善狼（诚实自律）或恶狼（谎言逃避）？live 颠倒成 evil——谎言通向邪恶。
- **经营关系** → 真诚共同体：接纳差异、尊重个性，像沙拉而非一锅粥；真诚是生命的药。
- **面对复杂/焦虑时代** → 反抗草率的思考，独立审慎判断，接受矛盾与不确定。
- **规划人生** → 前半生追寻自我，后半生放下自我。
- **面对死亡** → 死亡=关系消失；主动珍视并经营关系，把人生当朝圣。

## 自律四原则速查

| 原则 | 含义 | 反例 |
|---|---|---|
| 推迟满足感 | 先苦后甜 | 先吃奶油再吃蛋糕、拖延工作 |
| 承担责任 | "这是我的问题" | 推卸给环境/他人 |
| 忠于事实 | 诚实面对现实与内心 | 自我欺骗、掩盖真相 |
| 保持平衡 | 灵活自律、适时放下 | 僵化或放纵 |

## 关键信号（Tells）

| 信号 | 判断 |
|---|---|
| 总说"我本可以/我应该" | 神经官能症（过度自责） |
| 总说"我不能/不得不" | 人格失调症（推卸责任） |
| 用谎言掩盖真相 | 逃避痛苦→滋养恶狼 |
| 被"一锅粥"同化 | 失去个体化、完整与真实 |
| 压制真实需求/情感 | 内在的"洞"，不完整 |
| 一切以自我为中心 | 自恋走向自我毁灭 |
| 回避死亡意识 | 无法真正珍惜生命与关系 |

## 全书一句话(Bottom Line)

> 人生苦难重重——接受这一点就能从苦难中解脱；解决一切问题的关键在自律（推迟满足感、承担责任、忠于事实、保持平衡），自律的原动力是爱，而喂养善狼（诚实）还是恶狼（谎言）决定你走向治愈还是邪恶。成长是终身的向内修行：在焦虑时代反抗草率的思考、在复杂矛盾中抉择，前半生追寻自我、后半生放下自我；在真诚共同体里聆听不一样的鼓声、接纳差异，以真诚为生命的药修复婚姻与关系；直面死亡、珍视关系，把人生当作寻找并安放意义的朝圣——这就是那条少有人走的、通往心智成熟的路。
