# 术语表 Glossary

> 《指数基金投资指南》(银行螺丝钉)，按拼音排序，标章节。

- **指数** — 按规则挑选一篮子股票并计算加权平均值的工具，规则透明、长期存续（ch2）
- **指数基金** — 按指数规则复制持仓的基金，让投资者买下整个指数（ch2）
- **宽基指数** — 不限行业、覆盖广的指数（沪深300/中证500/上证50/中证800/恒生）（ch3）
- **行业指数** — 聚焦特定行业的指数（消费/医药/证券/红利）（ch3）
- **价格与价值的关系** — 价格围绕内在价值波动、长期趋于一致（股价像遛弯的小狗）（ch4）
- **能力圈** — 不熟不做，能判断品种大致价值才算具备（ch4）
- **安全边际** — "用0.4元买价值1元的东西"，价格大幅低于价值时买入（ch4）
- **市盈率（PE）** — 市值/盈利，愿为1元净利润付多少；适用盈利稳定品种（ch4）
- **盈利收益率（E/P）** — 市盈率倒数，格雷厄姆常用；越高越低估（ch4）
- **市净率（PB）** — 股价/净资产，适用强周期行业（证券/航空/能源）（ch4）
- **股息率** — 现金分红/市值，=盈利收益率×分红率（ch4）
- **盈利收益率法** — >10%分批投、<10%但>6.4%持有、<6.4%分批卖（ch4）
- **博格公式** — 指数基金收益=股息率+市盈率变化率+盈利增长率（ch4）
- **定投** — 定期定额买入，分摊成本、规避择时（ch5）
- **懒人定投法** — 低估时定投、正常持有、高估卖出（ch5）
- **定期不定额** — 估值越低投越多，定投收益放大器（ch5）
- **低估是一个区域** — 不必追求最低点，区域内持续定投（ch5/8）
- **货币基金** — 随取随用、稳健低收益的现金管理工具（如余额宝）（ch7）
- **债券基金** — 稳健资产，利率低位选短期、高位选长期（ch7）
- **定投双核制** — 工资现金流+定投双引擎（ch8）
- **买指数就是买国运** — 指数随国家经济增长（日本股市教训）（ch8）
- **巴菲特卖出三条件** — 基本面恶化、过于高估、有明显更低估品种（ch8）
- **ROE（净资产收益率）** — 净利润/净资产，衡量资产运作效率（ch4）
