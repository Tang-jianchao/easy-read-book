# 速查表 Cheatsheet

> 定投指数基金决策指南，帮助你在投资上像银行螺丝钉一样行动。以一页为限。

## 核心流程

1. **攒资产** → 让钱为你工作，投资长期收益最高的股票类资产。
2. **选品种** → 宽基为主（沪深300/中证500），了解行业再配行业指数。
3. **判估值** → 4指标：PE、盈利收益率、PB、股息率；宽基用PE/盈利收益率，周期行业用PB。
4. **找低估** → 盈利收益率>10%（或PE/PB历史低位）=低估，值得投。
5. **低估定投** → 低估时定期（不定额）买入，正常持有，高估卖出。
6. **定期不定额** → 越低估投越多，放大收益。
7. **家庭配置** → 应急→货币基金；中期→债券基金；长期→低估指数基金。
8. **心理建设** → 别杀鹅、低估是区域、工资+定投双核、买国运。

## 盈利收益率法速查（格雷厄姆）

| 盈利收益率 | 动作 |
|---|---|
| >10% | 分批买入（低估） |
| 10%～6.4% | 坚定持有 |
| <6.4% | 分批卖出（高估） |

## 博格公式

**指数基金年复合收益率 = 股息率 + 市盈率变化率 + 盈利增长率**

## 4 个估值指标速查

| 指标 | 公式 | 适用 |
|---|---|---|
| 市盈率 PE | 市值/盈利 | 盈利稳定的宽基 |
| 盈利收益率 | 盈利/市值（PE倒数） | 宽基，越高越低估 |
| 市净率 PB | 股价/净资产 | 强周期行业（证券/航空/能源） |
| 股息率 | 分红/市值 | 越低估股息率越高 |

## 卖出三条件（巴菲特）

1. 基本面恶化
2. 过于高估（普通投资者主要标准）
3. 有明显更低估、更合适的品种

## 关键信号（Tells）

| 信号 | 判断 |
|---|---|
| 盈利收益率>10% | 低估，分批买入 |
| 盈利收益率<6.4% | 高估，分批卖出 |
| 低估买入后还下跌 | 短期看供求，别恐慌（长期看价值） |
| 看到上涨定投下不去手 | 低估是区域，按估值而非情绪 |
| 短期波动想卖"鹅" | 别杀鹅，长期持有 |
| 追热点买热门 | 忽视能力圈与安全边际，易亏损 |

## 全书一句话(Bottom Line)

> 想成为富人先攒资产——投资长期收益最高的股票类资产，而指数基金是最适合普通人的选择。用价值投资理念（价格与价值的关系、能力圈、安全边际）武装自己，靠4个估值指标（PE/盈利收益率/PB/股息率）判断低估——盈利收益率>10%买入、<6.4%卖出（博格公式揭示收益来自股息+PE变化+盈利增长）。用懒人定投法在低估时定期买入、正常持有、高估卖出，配合定期不定额放大收益；按家庭资产分层配置（货币+债券+指数）。最重要的是心理建设：别杀鹅、低估是区域不是点、短期涨跌看供求、工资+定投双核、买指数就是买国运——有恒产者有恒心，用纪律穿越牛熊，在低估时积累、高估时兑现，让复利慢慢滚大你的财富。
