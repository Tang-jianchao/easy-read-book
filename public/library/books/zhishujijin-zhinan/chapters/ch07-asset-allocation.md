# 第七章：做好家庭资产配置

## Core Idea
家庭资产分层配置：**货币基金**（随取随用）、**债券基金**（稳健）、**指数基金**（长期增值）搭配，兼顾流动性、安全与收益。没有低估指数基金可投时，用货币基金/债券基金承接资金。

## Frameworks Introduced
- **货币基金（如余额宝）**：随取随用的"现金管理"工具，单位净值固定为1，收益稳定但较低——作为应急/流动性储备。
- **债券基金**：稳健资产。**利率低位选短期、利率高位选长期**；随时可投，出现浮亏可加仓拉低成本。
- **家庭资产配置**：按用途/期限分层——短期要用的放货币基金，中期稳健放债券基金，长期增值放指数基金（低估定投）。
- **资金承接**：没有低估指数基金可投资时，货币/债券基金作为替代品承接资金，等指数回到低估再投。

## Key Concepts
- **流动性分层**：不同资产匹配不同使用期限与风险。
- **货币基金单位净值=1**：稳健不亏本（相对），但收益低。
- **债券基金择期**：利率高位选长期（锁定高息）、低位选短期。

## Mental Models
- "资产分层配置"：短期货币+中期债券+长期指数，兼顾三性。
- "债券=稳健压舱"：利率高选长期、低选短期。
- "无低估指数→暂投债/货基"：资金不闲置，等待低估机会。

## Anti-patterns
- 全部资金投入高波动指数基金（无应急流动性）。
- 长期资金放货币基金（收益低、被通胀侵蚀）。
- 忽视债券在配置中的稳健作用。

## Worked Example
家庭配置示例：①应急金（3-6个月生活开支）→货币基金（随取随用）；②中期稳健资金→债券基金（利率高位选长期）；③长期增值→低估指数基金（按定投计划）。指数高估/无低估品种时，多余资金暂投货币/债券，待指数回到低估再转投。

## Key Takeaways
1. 货币基金=现金管理，随取随用、稳健低收益。
2. 债券基金=稳健资产，利率低位选短期、高位选长期。
3. 家庭资产分层：货币+债券+指数，兼顾流动/安全/收益。
4. 无低估指数时，资金暂投债/货基承接。
5. 配置是长期纪律，别把应急金投入高风险。
