# 第三章：常见指数基金品种

## Core Idea
指数基金分**宽基指数**（不限行业，覆盖广）与**行业指数**（聚焦特定行业）。宽基是普通投资者首选（分散、稳定、可估值）；行业指数波动更大、需对行业有判断。认识主要品种是挑选的基础。

## Frameworks Introduced
- **指数基金分类**：按追踪标的分宽基与行业；按市场分国内/跨境（美股、港股等）。
- **常见宽基指数基金**：
  - **沪深300**：大盘股为主，沪深两市规模最大300只（覆盖广、有代表性）。
  - **中证500**：中盘股为主，排除沪深300后规模最大500只。
  - **上证50**：超大盘（沪市规模最大50只）。
  - **中证800**：大中盘（沪深300+中证500）。
  - **恒生/恒生国企**：港股代表。
- **行业指数基金**：
  - **消费**：必需消费（食品饮料等，盈利稳定）。
  - **医药**：300医药/500医药（医药行业公司）。
  - **证券/金融**：券商、银行、保险。
  - **红利/养老**：高股息、养老主题。

## Key Concepts
- **宽基 vs 行业**：宽基跨行业分散，盈利稳定、适合用市盈率/盈利收益率估值；行业指数集中于单一行业，波动大、需理解行业周期。
- **选择思路**：普通投资者以宽基为主（沪深300+中证500覆盖大中盘），辅以了解行业时选行业指数。

## Mental Models
- "宽基=压舱石"：跨行业分散，稳定可估值，适合长期定投。
- "行业=进攻/补充"：了解行业才参与，波动更大。

## Anti-patterns
- 只买单一行业指数（风险集中、波动大）。
- 不了解行业就重仓行业指数。
- 忽视跨境/港股品种的配置价值。

## Worked Example
构建组合示例：沪深300（大盘）+中证500（中盘）两只宽基覆盖A股大中盘，作为定投主力；若对医药/消费有了解，可辅以相关行业指数增强收益；港股可用恒生/恒生国企指数配置。宽基为主、行业为辅。

## Key Takeaways
1. 指数分宽基（不限行业）与行业（聚焦）。
2. 宽基主力：沪深300、中证500、上证50、中证800、恒生。
3. 行业补充：消费、医药、证券、红利等。
4. 宽基分散稳定可估值；行业波动大需判断。
5. 普通投资者以宽基为主，了解行业再配行业。
