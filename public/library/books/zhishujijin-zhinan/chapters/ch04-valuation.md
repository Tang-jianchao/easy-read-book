# 第四章：如何挑选适合投资的指数基金（估值）

## Core Idea
用**价值投资理念**（格雷厄姆）挑选指数基金：判断"买什么"——找出当前值得投资的（低估）品种。核心是价格与价值的关系、能力圈、安全边际；用**4个估值指标**与**盈利收益率法/博格公式法**判断是否低估。这是全书最重要章节之一。

## Frameworks Introduced
- **价值投资理念（格雷厄姆三理论）**：
  1. **价格与价值的关系**：价格围绕内在价值波动（股价像遛弯的小狗，终回主人身边），长期趋于一致。
  2. **能力圈**：不熟不做，能判断品种大致价值才算具备能力圈；"知道边界所在比能力圈大小更重要"。
  3. **安全边际**："用0.4元买价值1元的东西"——价格大幅低于价值时买入。
  原理：能判断大致价值，在价格大幅低于价值时买入。**不清楚能力圈、忽视安全边际，是投资者亏损主因。**
- **4个估值指标**：
  - **市盈率（PE）**=市值/盈利，愿为1元净利润付多少代价；适用流通性好、盈利稳定品种（宽基）。警惕"市盈率陷阱"（下行/周期行业盈利下滑使PE失真）。
  - **盈利收益率（E/P）**=市盈率倒数，格雷厄姆常用；越高估值越低、越可能低估。
  - **市净率（PB）**=股价/净资产；适用强周期行业（证券、航空、航运、能源）与资产稳定品种；关注ROE（资产运作效率）。
  - **股息率**=现金分红/市值；=盈利收益率×分红率；股价越低股息率越高。
- **盈利收益率法（格雷厄姆策略）**：**>10%分批投资；<10%但>6.4%坚定持有；<6.4%分批卖出**。分批避免卖在最低。历史配合此策略定投年复合收益率提升两倍以上。
- **博格公式法**：**指数基金年复合收益率=股息率+市盈率变化率+盈利增长率**。在股息率高、PE低、盈利稳定时买入；变种用PB估值周期行业。盈利收益率法≈博格公式快速判断版。

## Key Concepts
- **估值指标有适用条件**：宽基（盈利稳定）用PE/盈利收益率；周期行业用PB；亏损/高成长不适用PE。
- **低估判断**：盈利收益率>10%（或PE/PB处于历史低位）=低估区域，值得投资。

## Mental Models
- "0.4元买1元"（安全边际）：价格大幅低于价值才买。
- "能力圈=知道边界"：不熟不做，知边界比圈大重要。
- "低估是买入依据"：用估值指标判断价格是否低于价值。

## Anti-patterns
- 追热点、买热门涨得好的（忽视内在价值）。
- 用PE估周期行业/下行行业（市盈率陷阱）。
- 忽视能力圈与安全边际（投资者亏损主因）。

## Worked Example
用盈利收益率法：某宽基指数基金当前盈利收益率12%>10%→处于低估，开始分批定投；若跌至8%（10%与6.4%之间）→坚定持有已买份额；若涨至6%<6.4%→高估，分批卖出获利。

## Key Takeaways
1. 价值投资：能判断价值+价格大幅低于价值时买入。
2. 4估值指标：PE、盈利收益率、PB、股息率，各有适用条件。
3. 盈利收益率法：>10%投、6.4%卖、中间持有。
4. 博格公式：收益=股息率+PE变化率+盈利增长率。
5. 清楚能力圈+安全边际，避免追热点亏损。
