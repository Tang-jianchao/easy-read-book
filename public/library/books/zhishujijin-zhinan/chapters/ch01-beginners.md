# 第一章：投资新手的建议

## Core Idea
想成为富人，第一步是**攒资产**——让钱为你工作。历史数据显示股票/股票基金是**长期收益率最高的资产**之一；指数基金是最适合普通投资者（尤其上班族）的股票基金。看收益更要看风险（波动），用长期眼光投资。

## Frameworks Introduced
- **攒资产**：富人靠拥有能持续增值的资产（而非仅靠劳动收入）致富；投资=把现金转化为能下"金蛋"的资产。
- **长期收益率最高的资产**：历史（各类资产对比）显示股票/股票基金长期收益领先债券、货币、黄金与现金。
- **看收益更要看风险**：高收益常伴随高波动；普通投资者需理解并承受波动，用长期时间化解。
- **适合上班族的基金——指数基金**：省时省力（不选股、不择时）、费率低、分散风险，"躺着赚钱"，适合没有大量时间研究的上班族。

## Key Concepts
- **复利的力量**：投资收益再投资，时间越长增长越显著。
- **资产 vs 现金**：现金会被通胀侵蚀购买力，资产能保值增值。

## Mental Models
- "攒资产，不攒现金"：让钱变成能增值的资产。
- "长期收益最高=股票类资产"：用长期眼光投资股票基金。
- "指数基金适合普通人"：省心、低费、分散。

## Anti-patterns
- 只看短期收益追热点（风险高、易亏损）。
- 忽视风险（波动）而重仓高风险品种。
- 让现金闲置，被通胀侵蚀。

## Worked Example
上班族小金每月发工资后，先按比例存下一部分购买指数基金（攒资产），而非全部花掉或存定期。长期坚持，资产随股市长期上涨与复利增长，逐步积累财富——这就是"攒资产"的起点。

## Key Takeaways
1. 想变富先攒资产，让钱为你工作。
2. 股票/股票基金是长期收益最高的资产。
3. 看收益更要看风险（波动）。
4. 指数基金最适合上班族（省时、低费、分散）。
5. 用长期眼光投资，靠复利积累。
