# 第六章：构建属于自己的定投计划

## Core Idea
把方法落到**可执行的定投计划**：明确每月可投金额、选低估品种、设定买卖规则、坚持执行。每月收入扣除生活开支后，**剩余资金50%左右可用于定投**。三个实例与读者案例展示不同人群如何落地。

## Frameworks Introduced
- **构建定投计划步骤**：①梳理现金流（每月能拿出多少）→②选低估指数品种→③确定定投额与频率→④执行（低估买入/正常持有/高估卖出）→⑤定期检视。
- **资金分配**：每月收入扣除必要生活开支后，**剩余资金50%左右**定投指数基金（留有应急，不过度）。
- **三个定投计划实例**：不同收入/风险偏好人群的方案（如刚工作的年轻人、有家庭者）。
- **读者案例**：真实读者按方法定投的效果（如2016年定投沪深300，盈利5.6%左右等）。

## Key Concepts
- **节流为先**：钱少也要存（原则一），先梳理支出、保证定投资金。
- **低估时启动**：遵循指数基金投资策略，在低估值得投资时开始定投计划。
- **纪律执行**：低估坚持定投、正常持有、高估卖出，不因短期波动中断。

## Mental Models
- "50%剩余资金定投"：平衡储蓄与生活，不过度投资。
- "节流为先，攒钱+定投"：先保证有资金可投。
- "低估启动、纪律执行"：计划的核心是可执行与坚持。

## Anti-patterns
- 不梳理现金流，随意决定定投额。
- 高估时启动定投（收益低）。
- 无纪律、中途放弃或追涨杀跌。

## Worked Example
读者案例：某人每月工资扣除生活开支后，将50%剩余资金定投低估的沪深300指数基金（510300），低估时坚持每月定投；2016年1月开始定投至7月盈利5.6%左右——按计划与估值执行，逐步积累份额。

## Key Takeaways
1. 定投计划：梳理现金流→选低估品种→定额→执行→检视。
2. 每月剩余资金50%左右可用于定投。
3. 节流为先，钱少也要存。
4. 低估时启动，纪律执行三阶段。
5. 用实例/读者案例校准自己的计划。
