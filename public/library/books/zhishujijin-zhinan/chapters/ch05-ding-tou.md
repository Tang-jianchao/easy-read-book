# 第五章：如何买卖指数基金——懒人定投法

## Core Idea
**懒人定投法**：在价格低于价值（低估）的时候定投指数基金。定投分摊成本、规避择时、化腐朽为神奇；结合估值（低估多投、正常持有、高估卖出）比任何时候都投收益更高。用**定期不定额**（估值越低投越多）进一步放大收益。

## Frameworks Introduced
- **什么是定投**：定期定额买入（如每月固定金额），分摊买入成本、避免择时压力、强制储蓄。适合工薪族。
- **结合估值的懒人定投法**：**低估时坚持定投；正常估值暂停定投、继续持有（可转投其他低估品种）；高估时分批卖出**。指数基金不是任何时候都适合定投，低估定投才能获更高收益。
- **定投实操步骤**：选好低估品种→确定每月定投额→（场内填"卖一"价格买入）执行→定期检视估值→低估加投/正常持有/高估卖出。
- **如何计算年复合收益率**：投资期末资金=本金×（1+年复合收益率）^年数；反解年复合收益率评估定投效果。
- **提高定投收益的5个小技巧**（含**定期不定额**）：
  - **定期不定额=定投收益放大器**：每次金额不同，估值越低投得越多（盈利收益率法：低估加倍；博格公式：PE/PB低时多投），在普通定投上显著提升收益。
  - 其他技巧围绕低估加码、长期坚持、避免追高。

## Key Concepts
- **低估是区域不是点**：不必追求买在最低点，低估区域持续定投即可。
- **低估定投的威力**：2004-2015回测，低估定投年复合收益率远超任何时候定投（配合策略提升两倍多）。
- **现金流匹配**：用每月稳定收入（工资）定投，形成持续买入。

## Mental Models
- "低估定投、正常持有、高估卖出"：定投三阶段。
- "低估是一个区域"：在区域内持续投，别纠结最低点。
- "定期不定额放大收益"：越低估越投，自动高抛低吸。

## Anti-patterns
- 任何时候都定投（高估时也投，收益低）。
- 一次性重仓买入（择时风险大）。
- 低估时因下跌恐慌停止定投（错失摊低成本）。

## Worked Example
结合盈利收益率法的定投：盈利收益率>10%（低估）→坚持每月定投（可用定期不定额，越低估投越多）；跌至10%与6.4%之间→暂停新投、持有已有份额；<6.4%（高估）→分批卖出。这样在低估时积累份额，高估时兑现利润。

## Key Takeaways
1. 定投分摊成本、规避择时、化腐朽为神奇。
2. 低估定投、正常持有、高估卖出。
3. 低估是区域不是点，持续定投。
4. 定期不定额（越低估越投）放大收益。
5. 指数基金不是任何时候都适合定投。
