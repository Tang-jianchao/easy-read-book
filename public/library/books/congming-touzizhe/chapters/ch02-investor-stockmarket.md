# 第二章：投资者与股市波动

## Core Idea
**价格波动是投资效益的指示计，不是投资决策的向导。** 聪明的投资者应利用市场波动（在悲观时买、乐观时卖），而非被其牵着走。股票市场的作用是提供一个报价机制，让买卖在方便的价格进行——但报价者（市场先生）情绪化，你只在愿意时才利用它的报价。

## Frameworks Introduced
- **波动是指示计非向导**：价格波动用于衡量投资效益（账面变化），不应成为买卖指令本身。
- **低价买进高价卖出**：在悲观时期买入普通股、乐观时期卖出。但1949年后"连续牛市"使该策略对普通股失效（卖了难买回）。
- **市场波动是决策向导**：把市场报价当"可利用的机会"，而非"必须服从的命令"——这是把波动变成优势的关键。
- **企业估值 vs 股市估值**：区分企业内在价值与市场报价；聪明投资以价值为基础，报价仅供参考。

## Key Concepts
- **市场先生的寓言**：市场先生（情绪化的报价伙伴）每天报一个价格，时而乐观出高价、时而悲观出低价；你只在它报价有利时才交易，而非被迫跟从——他的情绪是你的机会，不是你的命令。
- **均值回归**：1929年高点购入的股票25年才跑赢债券；1941年后高速上涨不可持续——过高价格透支未来。
- **股市小史 1900–1963**：长周期牛熊交替，高位追入代价巨大。

## Mental Models
- "市场先生"框架：把市场报价当可利用的波动，而不是需要跟随的裁判。
- "波动=温度计，不是方向盘"：价格衡量状态，但方向由你的价值判断决定。

## Anti-patterns
- 追涨杀跌：被市场先生情绪绑架，在乐观时高价买入、悲观时低价卖出。
- 把价格波动本身当投资依据，忽视内在价值。
- 高位集中买入（1929教训），透支多年收益。

## Worked Example
假设你持有一只好股票，市场先生某日报价极低——你的选择：①恐慌卖出（错误，被情绪绑架）；②趁低价加仓（正确，利用悲观）。市场先生报价只是你可选的交易机会，价值才是判断基础。

## Key Takeaways
1. 价格波动是指示计，不是决策向导。
2. 悲观时买、乐观时卖——把市场情绪当可利用机会。
3. 区分企业内在价值与市场报价。
4. 高价追入（如1929）代价巨大，长期才恢复。
5. 长期持有代表性普通股，穿越牛熊。
