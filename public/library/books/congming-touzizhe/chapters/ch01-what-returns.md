# 第一章：聪明的投资者将获得什么

## Core Idea
投资与投机的区别是全书基石：**"投资操作是基于全面的分析，确保本金的安全和满意的投资回报。不符合这些要求的操作是投机性的。"** 本书写给两类人——防御型投资者与进攻型投资者。理性投资更多是性格（纪律、耐心）而非智力。三条经受时间考验的准则：投机终将失去钱；别人悲观时买、乐观时卖；调查再投资。

## Frameworks Introduced
- **投资 vs 投机**：投资=基于全面分析、本金安全+满意回报；投机=期望市场波动获利。概念混淆让许多投机者有勇气入场。
- **防御型投资者**（大多数）：首要避免严重错误或损失，其次不必经常决策。严格遵循合理简单的原理。如靠遗产为生的寡妇——必须了解钱用在哪、为什么。
- **进攻型投资者**：愿花时间精心选择合理且有吸引力的投资，承担风险。理性第一原则=**绝不购买没有经过自己研究或不满意的证券**。
- **"理智"的含义**："有知识的理解能力"，更多是性格特点而非脑力、预见力。

## Key Concepts
- **普通股的转变**：从50年前的反对态度变为投资组合不可缺少部分（占比低25%、高75%）。原因：更高收益的错觉、税收优惠、通胀保护。
- **通胀驱动**：美元购买力50年锐减，只持现金/债券者实际财富贬值；合理价格买普通股整体对冲通胀。
- **历史证据**：过去80年长线持有多种代表性普通股回报高于债券（但1929年高点买的股票25年才跑赢债券——高位买入的代价）。

## Mental Models
- "理性=性格"：投资者成功靠纪律、耐心、不受诱惑，而非聪明或好运。
- "从崇高到荒谬仅一步之遥"：从普通股投资到投机也只有一步之遥——投资者潜意识有快速暴富的冲动，要警惕。

## Anti-patterns
- 把投机当投资（期望市场波动获利）。
- 被"高回报幻觉"误导——风险高≠回报高，普通股偶尔更高回报不可靠。
- 过于注重资本增值→投机心理→金融崩溃。

## Worked Example
1914 vs 1964 对比：1914年10万美元投高等级债券可年入5000美元生活宽裕；1964年需42.5万美元（购买力仅33%）。通胀+税收迫使投资者转向普通股对冲，但仍须守住投资纪律而非滑向投机。

## Key Takeaways
1. 投资=全面分析+本金安全+满意回报；不符合即投机。
2. 明确自己是防御型还是进攻型，按相应原则行事。
3. 理性是性格（纪律、耐心），不是智力或预见力。
4. 合理价格买普通股对冲通胀，但高位买入代价巨大。
5. 三条铁律：别投机、悲观时买乐观时卖、调查再投资。
