# 第十章：进攻型投资者的证券选择——评估方法

## Core Idea
进攻型投资者用**评估方法**寻找被低估的证券：比较市场价格与内在价值（收益能力、资产价值），在价格显著低于价值时买入。成长股评估须用保守估计支持，否则无安全边际。

## Frameworks Introduced
- **评估内在价值**：以收益能力（正常化盈利、多年平均收益）与资产（净资产、流动资产）为核心，估计价值区间。
- **市盈率评估**：用合理市盈率（结合成长性与收益稳定性）估计价值；市场对高成长给高PE，但须保守验证。
- **低估识别**：市场价格显著低于估计的内在价值（如2/3或更低）→有安全边际→进攻型机会。
- **成长股的保守评估**：成长股价值依赖未来预期，若估计保守且显示与价格匹配的满意边际，才可作为投资。

## Key Concepts
- **正常化收益**：用跨越周期的多年平均收益（剔除单年异常），而非当前或单年盈利。
- **安全边际随价格变化**：同一证券，价格低则安全边际大，价格高则边际小乃至消失——安全边际取决于你支付的价格。

## Mental Models
- "价格-价值顺差"：价值与价格的差额=安全边际，是进攻型买入的依据。
- "保守估计原则"：当估计与过去操作不同时，必含误差——估计越保守越安全。

## Anti-patterns
- 为高成长预期付过高价格（市场已把未来透支）。
- 用单年/当前高收益估计价值，忽略周期。
- 低估"价格决定安全边际"——再好的公司买贵了也没边际。

## Worked Example
评估一家成长股：用保守的正常化收益×合理市盈率估计内在价值；若当前市价低于该价值且有满意边际→可考虑买入；若市价已透支乐观预期→无安全边际，应回避，即使公司前景好。

## Key Takeaways
1. 用收益能力与资产评估内在价值区间。
2. 价格显著低于价值（如2/3）才有进攻型机会。
3. 成长股评估须保守，否则无安全边际。
4. 用正常化收益而非单年高利润。
5. 安全边际由支付价格决定——好公司买贵了也没边际。
