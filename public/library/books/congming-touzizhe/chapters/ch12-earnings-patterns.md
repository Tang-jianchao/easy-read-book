# 第十二章：股票收益和价格的变动模式

## Core Idea
研究几十年各类证券收益与价格的历史模式，揭示**均值回归与周期性**：市场倾向于欢迎第一个上升浪、恐惧第一次收入减少——把趋势当成永续。投资者需要"金融历史的意识"：理解波动、成长与衰退的周期性，避免被短期模式误导。

## Frameworks Introduced
- **收益与价格的历史模式**：追踪25年各种证券收益的典型模式与价格行为，发现周期性回归。
- **市场对波动的反应**：市场把第一个上升浪当"不断上升的开始"、把第一次收入下降当"完全结束"——系统性过度反应。
- **均值回归**：长期看价格回归与收益能力、资产相称的水平；短期波动围绕价值波动。

## Key Concepts
- **金融历史意识**：投资者最需要又很少具有的品质——了解长期成长与衰退模式，不把短期当长期。
- **波动的常态**：收益与价格波动是正常现象，高位追入、低位割肉是散户最大错误。

## Mental Models
- "波动=均值回归的过程"：价格短期偏离价值，长期回归；波动是机会不是灾难。
- "过度反应识别"：市场对好消息/坏消息的过度反应，创造低估与高估机会。

## Anti-patterns
- 把第一个上升浪当永续牛市、把第一次下降当末日。
- 用短期波动判断长期价值，追涨杀跌。
- 缺乏金融历史意识，重复犯同样的周期错误。

## Worked Example
历史显示：市场情绪化的过度反应（欢迎第一浪、恐惧第一次下滑）使价格反复偏离价值；理解这一模式，投资者可在市场过度悲观时买入、过度乐观时卖出（呼应"悲观时买、乐观时卖"）。

## Key Takeaways
1. 收益与价格有周期性，长期均值回归。
2. 市场对波动过度反应，创造低估/高估机会。
3. 需要金融历史意识，别把短期当长期。
4. 波动是常态与机会，不是灾难。
5. 高位追入、低位割肉是散户最大错误。
