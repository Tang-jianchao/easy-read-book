# 第十三章：收益和价格变化的组合分析

## Core Idea
把**收益与价格放在一起做组合分析**，判断一只证券是低估、合理还是高估：比较"收益能力 vs 所付价格"的关系（盈利收益率与市盈率），识别市场定价与基本面是否脱节，从而找到有安全边际的标的。

## Frameworks Introduced
- **收益-价格关系**：盈利收益率（每股收益/价格）与债券利率比较——股票盈利明显高于债券利率即提供安全边际（如股票收益率9% vs 债券4%，有5%有利边际）。
- **组合分析**：综合收益记录、资产、股息、市盈率多维判断，而非单一指标。
- **低估识别**：收益能力强而价格低→低估；收益弱而价格高→高估。

## Key Concepts
- **盈利收益率 vs 债券利率**：正常条件下，股票期望获利能力应大幅高于现行债券利率（如高出数个点），差额即安全边际来源。
- **留存收益的价值**：企业留存收益再投资与价值增长相关，但市场"顽固地重视分红、不太重视留存收益"。

## Mental Models
- "收益能力 vs 价格" 双维度：把收益与价格并列看，识别定价脱节。
- "超额收益=边际"：股票盈利超过债券利率越多，安全边际越厚。

## Anti-patterns
- 只看价格不看收益能力（追题材）。
- 只看收益不看价格（好公司买贵了也无边际）。
- 忽略盈利收益率与债券利率的相对关系。

## Worked Example
典型场合：股票基于当前价格的收益率9%，债券利率4%→购买者获得5%年均有利边际；10年周期股票盈利率超过债券的典型超额量可达所付价格的50%——这提供实际安全边际，也是"代表性普通股策略不需高质量洞察预测"的原因（前提是以几年平均市价买入并多样化）。

## Key Takeaways
1. 综合收益与价格做组合分析，识别定价与基本面脱节。
2. 股票盈利明显高于债券利率=有安全边际。
3. 低估=收益强价格低；高估=收益弱价格高。
4. 以几年平均市价买入并多样化，可获得"自动的"安全边际。
5. 别只看单一指标，收益+资产+股息+市盈率综合判断。
