# 第七章：进攻型投资者的组合策略——正面方法

## Core Idea
进攻型投资者在避开负面领域后，正面方法集中在三个推荐领域：**廉价证券（被低估的价值）、特别情况（企业重组/并购）、特殊事件套利**。成长股虽诱人但价格常过高，须谨慎。进攻型以"低估价格买有吸引力证券"为目标。

## Frameworks Introduced
- **三个推荐领域（进攻型）**：
  1. **廉价证券**：被市场低估、价格远低于内在价值的股票（如可指示价值的2/3或更低）。
  2. **特别情况**：企业重组、并购、清算、分拆等——基于详尽分析预测确定性事件，如并购差价。
  3. **特殊事件套利**：利用可预测事件（回购、要约）的价格差。
- **成长股的讨论**：成长股因增长预期被市场高估，安全边际常缺失；除非能以保守估计支持的合理价买入。
- **一般市场策略方案的时效**：任何"容易掌握、大多数人能用"的赚钱方法都太简单而很快失效（斯宾诺莎：所有杰出的事都像它们稀有一样困难）。

## Key Concepts
- **进攻型理性第一原则**：绝不购买没经过自己研究或不满意的证券。
- **评估方法**：用市盈率、收益、资产价值等评估内在价值，寻找市场价格与价值之间的顺差。

## Mental Models
- "廉价证券=安全边际的极佳载体"：低估价值股的价格-价值顺差提供厚安全边际（见ch16）。
- "热门方法必失效"：能广泛复制的高收益方法很快被套利到失效——别追逐大众都在用的"秘诀"。

## Anti-patterns
- 盲目追成长股、为预期增长付过高价格（无安全边际）。
- 追逐大众都在用的"赚钱方法"（必失效）。
- 凭消息/题材而非详尽分析操作。

## Worked Example
进攻型投资者以2/3或更低价格买入被低估价值的二等公司普通股（配合多样化），或参与并购/重组的"特别情况"——用详尽分析锁定确定性差价，而非赌市场情绪。

## Key Takeaways
1. 正面方法三领域：廉价证券、特别情况、特殊事件套利。
2. 成长股价格常过高，缺安全边际，须谨慎。
3. 热门方法必失效，别追逐大众秘诀。
4. 进攻型=详析低估价值，非追题材。
5. 绝不买未经自己研究的不满意证券。
