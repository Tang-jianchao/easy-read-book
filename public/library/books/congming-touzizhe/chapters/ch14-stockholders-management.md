# 第十四章：股东与管理层

## Core Idea
股东是企业的所有者，**有权监督管理层**。警惕管理层损害股东利益的行为（自利、不透明、过度扩张），用股东权利约束。投资者应关注管理层是否以股东利益为重，而非仅看股价。

## Frameworks Introduced
- **股东所有权**：股东是企业所有者，应行使监督、质询、投票权利。
- **委托-代理问题**：管理层可能追求自身利益（报酬、扩张、帝国心态）而非股东价值。
- **监督机制**：股东会、投票权、信息披露、审计——作为约束管理层的手段。

## Key Concepts
- **管理层质量是定性因素**：但应以行动（资本配置、股息、透明度）判断，而非口头承诺。
- **过度扩张/帝国心态**：管理层用股东资金进行低回报扩张，损害价值。

## Mental Models
- "股东=所有者"：用所有者视角监督管理层行为。
- "管理层行动>承诺"：看资本配置与分红的实际行动，而非宣传。

## Anti-patterns
- 忽视管理层自利行为与透明度问题。
- 被管理层过度扩张（帝国心态）损害价值而不制止。
- 只看股价涨跌，不监督公司治理。

## Worked Example
投资者作为股东，遇到管理层低回报扩张或信息不透明时，应行使投票/质询权利、要求解释，用公司治理约束——而非仅凭股价走势被动接受。

## Key Takeaways
1. 股东是所有者，有权监督管理层。
2. 警惕委托-代理问题（管理层自利、扩张）。
3. 用股东权利与信息披露约束管理层。
4. 管理层质量看行动（资本配置、分红），非承诺。
5. 公司治理是投资价值的一部分。
