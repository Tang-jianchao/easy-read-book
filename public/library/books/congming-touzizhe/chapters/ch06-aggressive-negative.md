# 第六章：进攻型投资者的组合策略——负面方法

## Core Idea
进攻型投资者首先要知道**什么不该做**（负面方法）。避开的领域：二等债券与优先股、外国政府债券、新发行证券、可转换债券、新发行股的炒作。这些看似高收益的机会往往缺乏真正价值，是"劣质"陷阱。

## Frameworks Introduced
- **负面清单（应避免的领域）**：
  - **二等债券与优先股**：表面利率高、实际风险大，缺乏一等信用的安全保障。
  - **外国政府债券**：政治与汇率风险，收益不匹配风险。
  - **新证券（IPO）**：无历史记录可分析，定价常过高。
  - **可转换债券**：收益/转换价值组合常被高估，条款复杂。
  - **新发行股的炒作**：热门新股首日暴涨是投机泡沫，散户高位接盘。
- **"一个可怕的案例"**：典型新股炒作从狂热到暴跌的教训。

## Key Concepts
- **进攻型≠追逐所有高收益**：真正的进攻型是在可控风险内精选低估证券，而非追热点。
- **无历史记录=无法分析**：新证券缺乏数据支撑安全边际，是投机而非投资。

## Mental Models
- "负面清单法"：先排除明显陷阱（二等债、外债、IPO、可转债、新股炒作），再谈正面选择。
- "新股首日炒作=泡沫信号"：无基本面支撑的暴涨是投机，别接盘。

## Anti-patterns
- 被高利率二等债券/优先股吸引，忽视本金风险。
- 追逐新股、热门题材，高位接盘。
- 买入无法分析历史记录的新证券。

## Worked Example
新股炒作案例：热门新股首日大涨吸引散户，随后因缺乏基本面支撑暴跌——"可怕的案例"警示：无历史数据可分析、定价过高的新证券是投机陷阱，进攻型也应避开。

## Key Takeaways
1. 进攻型先学会"什么不该做"：负面清单防陷阱。
2. 避开二等债券、外国债、新股、可转债、新股炒作。
3. 无历史记录=无法分析=无安全边际。
4. 高收益不等于好投资，风险与收益须匹配。
5. 进攻型=精选低估，不是追逐所有高收益。
