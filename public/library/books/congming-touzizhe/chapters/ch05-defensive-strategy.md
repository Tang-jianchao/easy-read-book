# 第五章：防御型投资者的组合策略

## Core Idea
防御型投资者的核心是**在债券与股票间合理分配，并严守纪律**。股票配置建议在最低25%、最高75%之间。普通股投资原则：合理分散、选大而突出且财务稳健的公司、支付合理价格、长期持有。用"美元成本平均法"（定期定额）降低择时风险。

## Frameworks Introduced
- **债券：股票分配**：债券部分应占一定比例（免税证券适合高税阶层）；股票用于对冲通胀与获得增长。
- **普通股投资原则（防御型）**：①适当但不过度分散（如10-30只）；②只选大型、突出、财务保守的公司；③长期持续支付股息；④市盈率合理（不追求最高增长）；⑤长期持有，耐心等待。
- **成长股与防御型**：成长股定义模糊、价格常过高，防御型应谨慎——以"当前价格支付"而非"预期未来"。
- **美元成本平均法**：定期定额投入（无论行情），摊平成本、强制纪律，无需择时。
- **投资公司/普通信托基金**：可作为分散工具，但注意费率与业绩。

## Key Concepts
- **"大的、突出的和财政保守的公司"**：选择行业领导者、财务稳健、有持续股息记录的公司，而非热门小盘。
- **何谓"风险"**：风险=本金实际损失的可能性（购买力+价格），而非价格波动本身。
- **投资者的个人状况**：配置比例应结合年龄、收入、其他资产、性格。

## Mental Models
- "股债配比 25–75%"：用资产配置而非单押控制风险；比例随个人状况调整。
- "美元成本平均"：定期定额投资，把择时难题交给纪律。

## Anti-patterns
- 过度集中或过度分散；追逐高价成长股。
- 用波动当择时信号，追涨杀跌。
- 忽视其他资产（自有企业、不动产）已具通胀对冲作用。

## Worked Example
防御型投资者（如靠遗产生活的寡妇）：将资金按25-75%在债券与普通股间配置，股票部分选10-30只大型稳健公司、长期持有、定期定额追加；首要目标是避免严重损失，其次不常做决策。

## Key Takeaways
1. 股债配置（25%-75%）是防御型基石，比例结合个人状况。
2. 普通股选大而突出、财务保守、持续分红的公司。
3. 成长股价格常过高，防御型应谨慎。
4. 用美元成本平均法（定期定额）规避择时难题。
5. 风险=本金实际损失，不是价格波动本身。
