# 第三章：1964年股市行情

## Core Idea
评估当下市场的基本状况，警惕"**新时代**"叙事掩盖的高估风险。战后持续的"连续牛市"让投资者以为高回报是常态，但作者警示：过去的高速上涨很可能意味着当前价格已过高，未来难以为继。

## Frameworks Introduced
- **市场基本状况评估**：用长期历史（股市周期、收益水平、价格水平）评估当前行情位置，而非只看近期上涨。
- **"新时代"的新标准**：历史上每轮牛市都有"新时代"叙事（20年代空前牛市），用来合理化过高估值——引号里含警告：任何慎重的读者都不可忽视。
- **从股市周期看价格水平**：以周期与历史比较当前价格是否透支。

## Key Concepts
- **连续牛市陷阱**：1941年后普通股以高于15%复合年率上涨"太好了，不可能是真的"；若持续，每个人都能通过股票致富（如同1929年的错觉）。
- **通胀与财政赤字**：政府干预避免萧条→巨大财政赤字→可能迅速通胀；现金持有者与高价位普通股持有者同样危险。
- **合理应对不确定性**：不确定未来（崩溃 or 通胀）→应遵循理智程序（配置、安全边际），而非押注单边。

## Mental Models
- "新时代=估值泡沫警报"：当市场用"这次不同/新时代"合理化高估值，警惕历史重演（20年代→1929崩溃）。
- "太快太好的上涨=不可持续"：高复合增长预示价格过高，而非未来更光明。

## Anti-patterns
- 用"新时代"叙事为高估价格辩护，忽视周期与历史。
- 把所有资金押注"牛市持续"或"通胀失控"单边情景。
- 被近期高速上涨冲昏头脑，追高入场。

## Worked Example
1941–1960年普通股年复合涨超15%——作者警示"太好了不可能是真的"：过去高速上涨可能预示当前价格过高，而非未来光明。这与1929年"几乎每个人都能靠股票致富"的错觉同构。

## Key Takeaways
1. 用长期周期与历史评估市场位置，别只看近期上涨。
2. "新时代"叙事常是合理化高估值的泡沫信号。
3. 过高价格透支未来，追高风险巨大。
4. 面对不确定未来，用配置与安全边际而非押注单边。
5. 过高估值下普通股也可能有真正风险。
