# 第九章：防御型投资者的证券选择

## Core Idea
防御型投资者的证券选择有**具体、可验证的标准**：债券部分选高等级（政府债、一等公司债、免税市政债）；股票部分只选满足严格定量门槛的大型稳健公司。用清单筛选，不依赖主观判断或热门题材。

## Frameworks Introduced
- **债券选择**：高等级债券（美国政府债、一等公司债券、适合税阶的免税州/市政债）。等级反映安全边际（利息覆盖倍数）。
- **股票选择（防御型7准则）**：
  1. 适当但不过度分散（如10-30只，跨行业）。
  2. 大型、突出、财务保守的公司。
  3. 持续支付股息（如20年）。
  4. 市盈率不过高（如不高于近期平均的合理倍数）。
  5. 股价增长记录合理。
  6. 利润稳定（多年正收益）。
  7. 估值不高于账面/收益的合理倍数。
- **用清单筛选**：以可量化标准逐条核对，筛掉不合格者。

## Key Concepts
- **高质量≠高回报**：一等证券给稳定低风险回报，勿指望超额收益。
- **股息作为信号**：持续派息公司通常经营稳健、财务保守。

## Mental Models
- "防御清单"：用7条可验证标准筛选股票，避免主观与热门。
- "等级=安全边际"：债券等级对应利息覆盖的安全缓冲。

## Anti-patterns
- 追逐热门小盘、题材股（不符合"大而突出财务保守"）。
- 为高增长付过高市盈率（违背准则4）。
- 忽视股息记录与利润稳定性。

## Worked Example
防御型选股清单应用：选出大型稳健公司，检查其20年股息记录、多年正利润、市盈率是否合理、是否财务保守；全部达标才纳入组合，配合债券配置与美元成本平均持有。

## Key Takeaways
1. 债券选高等级（政府/一等公司/免税市政）。
2. 股票用7条可验证标准筛选（大而稳、持续股息、合理市盈率等）。
3. 高质量=稳定低风险，别指望超额回报。
4. 用清单替代主观判断与题材。
5. 股息记录是经营稳健的信号。
