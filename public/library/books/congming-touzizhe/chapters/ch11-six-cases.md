# 第十一章：应用股票分析技术发现贬值的题材——六个案例

## Core Idea
用前面学到的分析方法，通过**六个真实案例**演示如何发现"贬值题材"（被市场低估的证券）。核心是：找到价格显著低于内在价值的机会，用定量分析验证安全边际，识别被误解/被忽视的低估股。

## Frameworks Introduced
- **案例研究方法**：逐案例演示如何用收益记录、资产价值、市盈率评估低估机会，并判断安全边际是否存在。
- **贬值题材的特征**：企业可能前景平平甚至不被看好，但资产/收益支撑的价值远超市价→"议价证券"。
- **安全边际的应用**：低估价值的证券，即使收益率小幅下降也不妨碍满意结果（安全边际覆盖小波动）。

## Key Concepts
- **低估≠坏企业**：可买被低估的二等公司股票，前提是价格远低于价值且购买者有情报、经验与多样化。
- **投机收益≠投机**：在极低价位买入有真实价值的证券，其"大的投机收益"其实是聪明的投资回报。

## Mental Models
- "议价证券=价值远超价格"：价格与指示价值的顺差越大，安全边际越厚。
- "价格暴跌创造机会"：萧条中价格大跌（如跌90%）后，隐含价值远高于市价→真正的投资机会。

## Anti-patterns
- 把"前景差/不受欢迎"误判为"没有投资价值"——低估价值股正是机会。
- 在热门高位追入（无安全边际），而非寻找被忽视的贬值题材。

## Worked Example
不动产债券案例：20年代按面值销售、高度投机；30年代萧条中价格跌至面值10%以下，此时隐含真实价值是市价的四五倍——价格暴跌后反而变成"相当安全"的投资机会，投机收益是对聪明投资的回报。

## Key Takeaways
1. 用定量分析识别价格远低于价值的贬值题材。
2. 低估≠坏企业：被忽视的二等公司是进攻型机会。
3. 安全边际覆盖小波动，容忍收益小幅下降。
4. 价格暴跌可创造真正的投资机会（价值远超市价）。
5. 投机的"大收益"在极低估值买入时可转为投资回报。
