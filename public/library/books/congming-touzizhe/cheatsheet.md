# 速查表 Cheatsheet

> 价值投资决策指南，帮助你在面对投资选择时像格雷厄姆一样行动。以一页为限。

## 核心决策规则

- **任何买入前** → 检查安全边际：价格是否显著低于内在价值（收益能力/资产）？无边际=投机。
- **判定性质** → 是否基于全面分析+本金安全+满意回报+可验证边际？凭股价涨跌下注=投机。
- **你是哪类** → 防御型：严守简单原则、避损失、不常决策；进攻型：精择低估、承担风险、绝不买没研究过的证券。
- **防御选股** → 7准则清单：分散、大而稳、20年股息、合理PE、增长合理、多年正利、估值合理。
- **进攻避雷** → 负面清单：二等债、外国债、新股IPO、可转债、新股炒作全避开。
- **面对波动** → 市场先生报价是机会不是命令：悲观时买、乐观时卖。
- **面对通胀** → 合理价格买普通股对冲购买力下降。
- **作为股东** → 用投票/质询监督管理层，警惕帝国心态与不透明。

## 安全边际速查

| 证券类型 | 安全边际来源 | 判定 |
|---|---|---|
| 债券/优先股 | 利息覆盖倍数、企业价值超债务 | 税前收益≥5倍固定费用 |
| 普通股 | 盈利收益率大幅高于债券利率 | 股票收益率9% vs 债券4%=5%边际 |
| 低估价值股 | 价格-价值顺差 | 价格≤内在价值2/3 |
| 成长股 | 保守估计支持 | 估计保守且与价格匹配 |

## 关键信号（Tells）

| 信号 | 判断 |
|---|---|
| 股票盈利收益率明显高于债券利率 | 有安全边际，可投 |
| 价格远超保守内在价值 | 无边际，回避 |
| 单年/两年高利润 | 别当长期收益能力 |
| "新时代/这次不同"叙事合理化高估值 | 泡沫警报 |
| 热门新股首日暴涨 | 投机，别接盘 |
| 市场价格可指示价值2/3或更低 | 进攻型低估机会 |

## 四大商业原理（最后的话）

1. 知道你正在做什么——了解证券价值如了解自己生意。
2. 别让其他人经营你的业务，除非能理解并控制其行动或坚定信任其忠诚能力。
3. 收益应基于算术而非信心；远离收益小损失大的冒险。
4. 用知识、经验与勇气——数据与推理正确就行动，公众意见不决定对错。

## 全书一句话(Bottom Line)

> 投资的全部秘密浓缩为"安全边际"四个字：只在价格显著低于内在价值、有可验证缓冲时买入，配合多样化与"悲观时买、乐观时卖"的纪律；分清投资(分析+安全+回报)与投机(靠情绪与运气)，防御型守纪律、进攻型精择低估，绝不买没研究过的证券——如此，普通投资者也能取得可信的结果。
